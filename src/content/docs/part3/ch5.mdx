이미지 분류 모델은 입력을 정해진 클래스 중 하나로 예측했습니다. 생성형 AI도 학습 데이터에서 패턴을 찾지만, 정답 클래스 대신 문장·이미지·코드처럼 새로운 결과를 이어서 만듭니다.

## 다음 결과의 가능성을 이어 붙이기

텍스트 생성 모델은 문장을 **토큰**이라는 작은 단위로 나누어 처리하고, 현재까지 주어진 내용인 **컨텍스트**를 바탕으로 다음 토큰의 가능성을 계산합니다. 이 과정을 반복해 긴 답을 만듭니다.

```text
사용자의 입력과 대화 맥락 → 다음 토큰의 확률 계산
→ 토큰 선택 → 다시 다음 토큰 계산 → 문장 생성
```

유창함은 사실 확인의 증거가 아닙니다. 모델은 그럴듯한 표현 패턴을 만들 수 있으므로 존재하지 않는 사실·수치·출처를 제시하는 **할루시네이션**이 생길 수 있습니다.

## 모델과 도구를 구분하기

최근 서비스는 언어·멀티모달 모델에 여러 도구를 결합하기도 합니다.

| 기능 | 실제로 일어날 수 있는 일 |
| --- | --- |
| 검색 | 외부 자료를 찾아 컨텍스트에 제공 |
| 파일 처리 | 문서·표·이미지를 읽어 분석할 정보로 변환 |
| 코드 실행 | 계산·전처리·그래프·모델 학습을 코드로 수행 |
| 이미지 생성 | 생성 모델이 설명에 맞는 이미지를 만듦 |

서비스 이름 하나가 곧 하나의 모델이나 AI 전체를 뜻하지 않습니다. 지원 기능과 내부 구조는 바뀔 수 있으므로 현재의 공식 안내와 실제 결과를 확인합니다.

<Callout kind="caution" title="검색했다고 자동으로 사실이 되지 않는다">검색 결과도 잘못 고르거나 문맥을 잘못 해석할 수 있습니다. 핵심 주장과 수치는 링크가 실제 원자료를 가리키는지, 자료가 주장을 뒷받침하는지 직접 확인합니다.</Callout>

<Callout kind="concept" title="오늘 기억할 내용">생성형 AI는 학습된 패턴과 제공된 컨텍스트로 결과를 생성합니다. 도구가 더해지면 할 수 있는 일은 넓어지지만, **근거를 확인하고 결과의 사용 여부를 판단하는 사람의 역할은 사라지지 않습니다.**</Callout>
