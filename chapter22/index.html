섹션 제목: “이 챕터의 교과 결합”

    인공지능

이 챕터는 [정보] 의 ‘알고리즘·순서도’ 도구로 [인공지능] Agent의 작동 흐름을 분해합니다. AI가 하나의 목표를 받아 여러 단계를 스스로 처리하는 과정을, 우리가 이미 배운 순서도 문법으로 그려 보는 것이 핵심입니다.

🔍 생각 열기

섹션 제목: “🔍 생각 열기”

여러분이 친구에게 이렇게 부탁했다고 해봅시다.

“이번 주말에 볼 만한 영화 하나 골라서, 상영 시간까지 알려줘.”

친구는 어떻게 행동할까요? 아마 이렇게 움직일 겁니다. 먼저 무엇을 원하는지 이해하고(주말, 영화, 상영 시간), 어떻게 할지 계획을 세우고(영화 목록 검색 → 평점 확인 → 상영관 조회), 실제로 검색 앱을 사용해 정보를 찾고, 마지막으로 답이 맞는지 확인한 뒤 알려줍니다.

이 부탁을 챗봇에게 한다면 어떨까요? 예전의 챗봇은 “글쎄요, 최신 정보는 알 수 없어요”라고 답하고 끝났습니다. 하지만 오늘날의 AI Agent는 친구처럼 여러 단계를 스스로 밟아 실제로 일을 처리합니다.

대답하는 AI와 행동하는 AI의 차이는 무엇일까요? 그 비밀은 ‘한 번에 답하기’가 아니라 ‘여러 단계로 나눠 실행하기’에 있습니다.

🎯 이 단원의 학습 목표

섹션 제목: “🎯 이 단원의 학습 목표”
  • 하나의 목표가 주어졌을 때 Agent가 여러 단계의 일을 수행하는 흐름을 설명할 수 있다.
  • Agent의 작동 흐름을 정보 교과의 순서도로 표현할 수 있다.

📚 선수학습 확인

섹션 제목: “📚 선수학습 확인”

이 차시를 시작하기 전에, 앞에서 배운 두 가지를 떠올려 봅시다.

  • 순서도(flowchart) [정보]: 일의 순서를 도형으로 표현하는 방법입니다. 시작/끝은 타원, 처리는 사각형, 판단(조건)은 마름모로 그립니다.
  • 생성형 AI의 프롬프트 [인공지능]: 우리가 지시(프롬프트)를 주면 AI가 그 지시에 맞춰 텍스트를 만들어 냅니다. 하지만 기본 챗봇은 한 번의 질문에 한 번의 답만 합니다.

Agent는 이 두 가지가 합쳐진 것입니다. 프롬프트로 목표를 주면, 알고리즘처럼 여러 단계를 스스로 실행합니다.

🔬 탐구 활동

섹션 제목: “🔬 탐구 활동”

탐구: ‘여행 도우미 Agent’의 발자취를 되짚어라

섹션 제목: “탐구: ‘여행 도우미 Agent’의 발자취를 되짚어라”

실제 Agent 서비스가 하나의 목표를 어떻게 여러 단계로 처리하는지, 그 실행 기록(로그) 을 보고 흐름을 복원하는 활동입니다.

  • 준비물: 아래 실행 기록 카드(교사 배포 또는 화면 제시), 필기구, 순서도 워크시트
  • 소요 시간: 약 12분

상황 카드

섹션 제목: “상황 카드”

사용자 목표: “다음 주 토요일 부산 여행 일정을 짜줘. 날씨 보고 실내/실외 정해서.”

Agent가 남긴 실행 기록이 순서가 뒤섞여 제시됩니다. 여러분의 임무는 이것을 올바른 순서로 배열하는 것입니다.

카드Agent의 실행 기록
A날씨 API를 호출해 토요일 부산 날씨를 조회함 → “비 90%“
B사용자의 목표를 분석함: 장소=부산, 날짜=다음 주 토요일, 조건=날씨 기반
C완성된 실내 위주 일정을 사용자에게 최종 전달함
D”비가 오므로 실내 일정으로 계획을 수정한다”고 판단함
E계획을 세움: ①날씨 확인 ②맑으면 야외 코스 ③비 오면 실내 코스 ④일정 정리
F박물관·아쿠아리움 등 실내 명소를 검색 도구로 조회함

과정

섹션 제목: “과정”
  1. 카드 6장을 Agent가 실제로 밟았을 순서대로 배열해 봅니다.
  2. 각 카드가 “목표 이해 / 계획 / 도구 활용 / 실행·판단 / 결과 확인” 중 어디에 해당하는지 이름표를 붙입니다.
  3. 배열한 순서를 화살표로 이어 한 줄 흐름으로 만듭니다.

결과 예측

섹션 제목: “결과 예측”

“어떤 순서가 나올까요? 그리고 만약 A단계에서 날씨가 ‘맑음’이었다면 어느 카드가 달라졌을까요?”

정답 순서는 B → E → A → D → F → C 입니다.

토의

섹션 제목: “토의”

“왜 Agent는 ‘계획(E)‘을 먼저 세우고 나서 ‘도구(A)‘를 사용했을까요? 계획 없이 바로 검색부터 했다면 어떤 문제가 생겼을까요?”

토의 결과를 한 문장으로 정리해 봅시다. (예: “계획이 있어야 어떤 도구를 언제 쓸지 알 수 있다.”)

💡 핵심 개념

섹션 제목: “💡 핵심 개념”

개념 1. Agent는 목표를 ‘여러 단계’로 나눠 스스로 실행한다 [인공지능]

섹션 제목: “개념 1. Agent는 목표를 ‘여러 단계’로 나눠 스스로 실행한다 [인공지능]”
  • 정의: AI Agent는 사람이 하나의 목표만 주면, 그 목표를 이루기 위한 여러 단계의 일을 스스로 계획하고 실행하는 AI입니다.
  • 비유: 일반 챗봇이 “질문에 답하는 안내 데스크 직원”이라면, Agent는 “심부름을 맡기면 알아서 처리해 오는 비서”와 같습니다. 안내 데스크는 “약국은 3층입니다”라고 알려주지만, 비서는 실제로 약을 사서 가져다줍니다.

탐구 활동에서 확인한 것처럼, Agent는 목표(부산 여행)를 받아 ①이해 → ②계획 → ③도구 활용 → ④실행·판단 → ⑤결과 확인 이라는 흐름을 밟습니다. 이 다섯 단계가 Agent 작동의 뼈대입니다.

flowchart LR
  A[목표 이해] --> B[계획 수립]
  B --> C[도구 활용]
  C --> D[실행 · 판단]
  D --> E{목표<br/>달성?}
  E -->|아니오| B
  E -->|예| F[결과 전달]

[그림 22-1] Agent의 작동 흐름. 목표를 달성하지 못하면 계획으로 되돌아가 다시 시도합니다.

여기서 중요한 점은 판단 후 되돌아가는 화살표입니다. Agent는 한 번 실행하고 끝내지 않습니다. 결과를 확인하고, 부족하면 다시 계획하고 재실행합니다. 이 ‘반복(loop)‘이 대답하는 AI와 행동하는 AI를 가르는 결정적 차이입니다.

개념 2. Agent의 흐름은 정보 교과의 순서도와 똑같다 [정보] [인공지능]

섹션 제목: “개념 2. Agent의 흐름은 정보 교과의 순서도와 똑같다 [정보] [인공지능]”
  • 정의: Agent가 목표를 처리하는 과정은 정보 교과에서 배운 알고리즘의 3요소 — 순차, 선택(조건), 반복 — 으로 완전히 표현됩니다.
  • 비유: Agent의 머릿속 작동은 마치 ‘자동으로 실행되는 순서도’와 같습니다. 우리가 도형으로 그려온 순서도를, AI가 스스로 그리고 실행하는 셈입니다.

탐구 활동의 여행 도우미를 순서도로 옮기면 이렇게 됩니다. 날씨 확인(도구 활용) 뒤에 나오는 “맑음이냐 비냐”는 정보 교과의 선택(조건 분기) 이고, 목표가 이뤄질 때까지 계획으로 돌아가는 것은 반복 입니다.

flowchart TD
  S([시작: 여행 목표 입력]) --> P[계획 세우기]
  P --> W[날씨 API 호출]
  W --> Q{날씨가<br/>맑은가?}
  Q -->|예| O[야외 코스 검색]
  Q -->|아니오| I[실내 코스 검색]
  O --> C[일정 정리]
  I --> C
  C --> E([끝: 일정 전달])

[그림 22-2] 여행 도우미 Agent를 정보 교과 순서도로 표현한 것. 마름모는 조건 분기, 화살표는 실행 순서입니다.

이렇게 Agent의 지능적 작동을 순서도로 그려 보면, “AI가 알아서 한다”는 막연한 말이 명확한 절차로 눈에 보이게 됩니다.

🌉 교과 간 연결 다리

섹션 제목: “🌉 교과 간 연결 다리”

[정보] 의 순서도와 [인공지능] 의 Agent는 서로 다른 곳에서 왔지만, 같은 것을 표현합니다.

순간정보 교과의 도구인공지능의 개념결합된 결과
계획을 세운다알고리즘 설계계획 수립(Planning)목표를 실행 가능한 단계로 분해
날씨를 확인한다입력·처리도구 활용(Tool Use)외부 데이터를 가져와 판단 재료로 씀
맑음/비를 나눈다선택(조건 분기)상황 기반 의사결정조건에 따라 다른 행동 선택
될 때까지 다시 한다반복(loop)자기 점검·재시도결과 확인 후 부족하면 재계획

📖 읽을거리

섹션 제목: “📖 읽을거리”

“생각의 사슬”이 만든 변화

2022년, 연구자들은 AI에게 어려운 문제를 줄 때 “답만 말하지 말고, 생각하는 과정을 단계별로 적어라”라고 시켰습니다. 이 방법을 ‘생각의 사슬(Chain-of-Thought)‘이라 부릅니다. 놀랍게도 AI의 정답률이 크게 올랐습니다.

이 발견이 Agent의 출발점이 되었습니다. 큰 문제를 한 번에 풀려 하지 말고 작은 단계로 쪼개면 AI가 훨씬 잘한다는 것이죠. 오늘날의 Agent가 ‘목표 → 계획 → 실행’으로 나눠 일하는 것도 바로 이 원리입니다. 사실 이것은 우리가 정보 시간에 늘 하던 일 — 큰 문제를 작은 알고리즘으로 분해하기 — 와 정확히 같습니다.

섹션 제목: “✅ 확인 문제”

기본 (개념 확인)

섹션 제목: “기본 (개념 확인)”

1. 다음 중 일반 챗봇과 구별되는 AI Agent의 가장 큰 특징은 무엇입니까? ① 사람의 질문에 문장으로 답한다 ② 하나의 목표를 여러 단계로 나눠 스스로 실행한다 ③ 그림을 그릴 수 있다 ④ 한국어를 이해한다

응용 (적용)

섹션 제목: “응용 (적용)”

3. [그림 22-2]의 여행 도우미 순서도에서, “날씨가 맑은가?”에 해당하는 마름모는 정보 교과의 알고리즘 3요소(순차, 선택, 반복) 중 무엇에 해당합니까? 그리고 그 이유를 한 문장으로 쓰시오.

심화 (사고력·서술형)

섹션 제목: “심화 (사고력·서술형)”

4. 다음 목표를 처리하는 Agent의 흐름을 목표 이해 → 계획 → 도구 활용 → 실행·판단 → 결과 확인 5단계로 나누어 설명하시오. 그리고 이 중 ‘조건 분기(선택)‘가 필요한 단계가 어디인지 밝히시오.

목표: “우리 반 급식 메뉴 중 이번 주에 가장 인기 있었던 메뉴를 조사해서 표로 정리해줘.”

정답 확인

1. ② (Agent의 핵심은 하나의 목표를 여러 단계로 자율 실행하는 것입니다.)

2. ②

3. 선택(조건 분기) 입니다. 이유: 날씨가 맑은지 아닌지에 따라 ‘야외 코스’와 ‘실내 코스’로 실행 경로가 갈라지기 때문입니다.

4. (예시 답안)

  • 목표 이해: 대상=우리 반 급식, 기간=이번 주, 원하는 것=가장 인기 메뉴, 형식=표.
  • 계획: ①급식 메뉴 목록 확보 → ②학생 선호 데이터 수집 → ③메뉴별 집계 → ④가장 높은 값 찾기 → ⑤표로 정리.
  • 도구 활용: 설문 앱이나 급식 데이터베이스를 호출해 선호도 데이터를 가져옵니다.
  • 실행·판단: 메뉴별 득표를 집계하고, “충분한 응답이 모였는가?”를 확인합니다. 부족하면 데이터 수집으로 되돌아갑니다(반복).
  • 결과 확인: 완성된 표가 목표(이번 주, 우리 반, 인기 메뉴)에 맞는지 점검 후 전달.
  • 조건 분기가 필요한 단계: ‘실행·판단’ 단계입니다. “응답이 충분한가?”를 판단해 재수집할지 정리로 넘어갈지 경로가 갈리기 때문입니다.

📌 단원 정리

섹션 제목: “📌 단원 정리”

핵심 개념 요약

  • AI Agent는 하나의 목표를 받아 여러 단계를 스스로 계획·실행하는 AI입니다. ‘대답하는 AI’가 아니라 ‘행동하는 AI’입니다.
  • Agent의 작동 흐름은 목표 이해 → 계획 → 도구 활용 → 실행·판단 → 결과 확인이며, 목표를 이룰 때까지 반복됩니다.
  • 이 흐름은 정보 교과의 순차·선택·반복이라는 알고리즘 원리로 완전히 표현됩니다. [정보] [인공지능]- 대답하는 AI와 행동하는 AI의 결정적 차이는 결과를 확인하고 부족하면 다시 계획으로 되돌아가는 반복 구조에 있습니다.

이번 차시 한 줄 정리

Agent가 목표 하나로 여러 단계를 스스로 밟는 비밀은, 우리가 이미 아는 순서도(순차·선택·반복) 위에서 AI가 판단을 채워 넣는 것입니다.
