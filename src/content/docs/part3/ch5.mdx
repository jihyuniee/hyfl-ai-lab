여러분은 이미 ChatGPT 같은 생성형 AI를 많이 써봤을 겁니다. 그래서 이번 시간은 사용법이 아니라 훨씬 근본적인 질문에서 시작합니다.

<Callout kind="question">
**ChatGPT는 정말 '알고' 대답하는 걸까?**
</Callout>

## 생성형 AI와 LLM

<strong>생성형 AI(Generative AI)</strong>는 텍스트, 이미지, 음성, 영상처럼 **새로운 콘텐츠를 만들어내는 AI**입니다. ChatGPT, Claude, Gemini처럼 대화형으로 텍스트를 생성하는 AI를 <strong>대규모 언어 모델(LLM, Large Language Model)</strong>이라고 부릅니다. LLM도 결국 [1차시](/hyfl-ai-lab/part1/ch3/)에서 배운 딥러닝의 한 종류입니다.

## 답을 만드는 다섯 단계

LLM은 인터넷의 방대한 텍스트를 **학습 데이터**로 삼아, 문장을 <strong>토큰(token)</strong>이라는 작은 조각(단어 또는 단어의 일부)으로 나누고 지금까지의 **문맥**을 참고해 다음 토큰을 계산합니다.

<FlowDiagram
	items={[
		{ ko: '입력을 토큰으로 분해' },
		{ ko: '문맥 처리' },
		{ ko: '다음 토큰 확률 계산' },
		{ ko: '토큰 선택' },
		{ ko: '반복' },
	]}
/>

```
"오늘 날씨가 정말" → 다음 토큰은?
좋다 (확률 62%) · 덥다 (확률 20%) · 이상하다 (확률 8%) ...
```

이 예측은 정해진 정답이 아니라 학습 데이터 속에서 그 문맥 다음에 가장 자주 등장했던 토큰일수록 높은 **확률**을 갖는 계산입니다. LLM은 이 과정을 한 토큰씩 반복하며 문장 전체를 만들어냅니다.

<Callout kind="why">
토큰과 확률적 예측이라는 원리를 배우는 이유는, 생성형 AI가 만들어내는 유창한 문장이 **왜 반드시 사실은 아닌지**를 이해하기 위해서입니다.
</Callout>

<Callout kind="think">
"다음 토큰을 확률적으로 예측해서 이어붙인다"는 설명을 듣고 나면, 처음 질문으로 돌아가볼 수 있습니다. ChatGPT는 세상을 '이해'해서 대답하는 걸까요, 아니면 그럴듯한 다음 토큰을 아주 잘 고르는 걸까요?
</Callout>

## 유창함은 정확성의 증거가 아니다

LLM은 정답 데이터베이스를 검색하는 게 아니라 확률적으로 그럴듯한 다음 토큰을 이어 붙이는 방식이기 때문에, **사실이 아닌 내용을 마치 사실인 것처럼 자신 있게** 만들어내는 경우가 있습니다. 이것을 <strong>할루시네이션(Hallucination, 환각)</strong>이라고 합니다. 문장이 매끄럽고 자신감 있게 쓰여 있다고 해서 그 내용이 사실이라는 뜻은 아닙니다.

<Callout kind="why">
할루시네이션을 배우는 이유는, **AI의 답을 왜 반드시 검증해야 하는지**를 이해하기 위해서입니다. 이 원칙은 다음 시간과 세 프로젝트 전체에서 계속 등장합니다.
</Callout>

<Callout kind="lab" title="실험 — 같은 질문, 다른 답">
1. 같은 사실 질문(예: "○○ 고등학교가 설립된 연도는?")을 ChatGPT에게 **세 번 따로** 물어보고 답을 비교하세요. 매번 똑같나요?
2. 이번엔 창작 질문(예: "고등학생이 주인공인 짧은 이야기를 써줘")을 세 번 물어보고 비교하세요.
3. 두 실험의 결과가 다르게 느껴지나요? **사실 질문에서 답이 오락가락하는 것**과 **창작 질문에서 매번 다른 이야기가 나오는 것** 중 어느 쪽이 더 위험한 상황일까요? 이유를 설명해보세요.
</Callout>

</Callout>
