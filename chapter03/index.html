AI는 어떻게 학습하고 판단하는가

Part 1. 인공지능의 이해와 원리 · 3차시

이 챕터의 교과 결합

섹션 제목: “이 챕터의 교과 결합”
mindmap
  root((AI의 학습과 판단))
    정보
      데이터 입력과 출력
      알고리즘의 흐름
      시뮬레이터 체험
    인공지능
      학습의 원리
      딥러닝의 등장
      특징 추출과 판단
    연결 다리
      데이터를 규칙으로
      규칙을 판단으로

이 챕터는 정보 교과를 주축으로 삼습니다. [정보]는 “입력-처리-출력”이라는 컴퓨터의 기본 구조로 AI를 바라봅니다. 여기에 인공지능 교과의 렌즈 [인공지능]를 겹칩니다. AI는 왜 “프로그래밍된 규칙”이 아니라 “학습한 규칙”으로 움직이는지 살펴봅니다. 두 교과를 잇는 다리는 데이터입니다.

🤔 생각 열기

섹션 제목: “🤔 생각 열기”

여러분의 스마트폰 사진첩을 떠올려 봅시다. 사진첩 앱에 “강아지”라고 검색하면 강아지 사진만 골라서 보여줍니다. 그런데 누구도 여러분의 강아지 사진 하나하나에 “이건 강아지야”라고 이름표를 붙여 준 적이 없습니다.

앱은 어떻게 강아지를 알아볼까요?

프로그래머가 “귀가 두 개, 코가 검고, 털이 있으면 강아지”라고 일일이 규칙을 적어 둔 걸까요? 만약 그렇다면 늘어진 귀, 서 있는 귀, 털 없는 강아지는 어떻게 구별할까요? 오늘은 AI가 규칙을 “직접 배우는” 방식을 파헤쳐 봅니다.

🎯 이 단원의 학습 목표

섹션 제목: “🎯 이 단원의 학습 목표”
  • AI가 데이터를 통해 학습하고 판단하는 기본 원리를 설명할 수 있다.
  • AI 발전의 핵심 전환점인 딥러닝의 등장 의미를 간략히 설명할 수 있다.

선수학습 확인

섹션 제목: “선수학습 확인”

지난 차시에서 우리는 알고리즘(문제를 푸는 절차를 순서대로 정리한 것)과 프로그램(알고리즘을 컴퓨터 언어로 옮긴 것)을 배웠습니다. 전통적인 프로그램은 사람이 “이럴 때는 이렇게 하라”는 규칙을 미리 다 적어 둡니다. 오늘은 이 방식이 통하지 않는 문제를 만나면서, AI가 어떤 다른 길을 택하는지 알아봅니다.

🔬 탐구 활동

섹션 제목: “🔬 탐구 활동”

탐구: 나는 “규칙 프로그래머” — 손글씨 숫자를 규칙으로 구별하기 [정보]

섹션 제목: “탐구: 나는 “규칙 프로그래머” — 손글씨 숫자를 규칙으로 구별하기 [정보]”

  • 준비물: 모눈종이(또는 5×5 격자를 그린 종이) 여러 장, 연필, 모둠별 4명

  • 과정:

    1. 모둠에서 한 명이 5×5 격자에 숫자 1을 손으로 칠합니다. 칠한 칸은 1, 빈 칸은 0으로 적습니다.
    2. 다른 세 명도 각자 자기 방식대로 숫자 1을 칠합니다. (똑바로, 비스듬히, 굵게 등)
    3. 이제 모둠이 함께 “이런 격자면 숫자 1이다”라는 규칙을 글로 적어 봅니다. 예: “가운데 세로줄이 채워져 있으면 1”
    4. 옆 모둠과 종이를 바꿉니다. 우리 모둠의 규칙만 보고, 옆 모둠이 칠한 숫자 1을 우리 규칙으로 맞출 수 있는지 확인합니다.
    5. 이번엔 숫자 7도 함께 넣습니다. 규칙만으로 1과 7을 구별할 수 있는지 다시 시험합니다.

  • 결과 예측: “우리 규칙이 옆 모둠의 숫자 1도 맞출 수 있을까요? 1과 7이 섞이면 어떻게 될까요?”

  • 토의:

    • 사람마다 숫자 1을 다르게 씁니다. 규칙을 얼마나 늘려야 모든 1을 잡아낼 수 있을까요?
    • 규칙을 계속 추가하다 보면 어떤 문제가 생길까요? [정보]
    • 만약 사람이 규칙을 적는 대신, 컴퓨터가 수천 개의 “숫자 1 예시”를 보고 스스로 공통점을 찾게 하면 어떨까요? [인공지능]

이 탐구에서 여러분은 곧 깨닫게 됩니다. 규칙을 손으로 다 적는 방식은 금방 한계에 부딪힙니다. 바로 이 지점에서 AI의 “학습”이 등장합니다.

flowchart LR
  A[손글씨 숫자<br/>예시들] --> B{규칙을 사람이<br/>직접 적기}
  B --> C[예외가 너무 많음<br/>규칙 폭발]
  A --> D{컴퓨터가 예시에서<br/>공통점 찾기}
  D --> E[스스로 판단 규칙<br/>발견]

위: 규칙을 사람이 적는 길과 AI가 학습하는 길의 비교.

📚 핵심 개념

섹션 제목: “📚 핵심 개념”

개념 1. 입력-학습-출력: AI 판단의 기본 구조 [정보] [인공지능]

섹션 제목: “개념 1. 입력-학습-출력: AI 판단의 기본 구조 [정보] [인공지능]”

  • 정의: AI는 데이터(입력) 를 받아, 그 안의 패턴을 익히는 학습 과정을 거쳐, 새로운 데이터에 대한 판단(출력) 을 내놓습니다. 전통 프로그램이 “규칙 → 답”이라면, AI는 “데이터 + 답 → 규칙”을 스스로 만들어 냅니다.

  • 비유: AI 학습은 마치 요리 초보가 레시피 없이 배우는 것과 같습니다. 스승이 만든 김치찌개 100그릇을 맛보며 “이 정도 짜기, 이 정도 매운맛”의 감을 스스로 익히는 것입니다. 레시피(규칙)를 외우는 게 아니라, 예시(데이터)에서 감(패턴)을 뽑아냅니다.

전통 프로그래밍과 AI의 차이를 정리하면 다음과 같습니다.

구분전통 프로그래밍 [정보]머신러닝 [인공지능]
사람이 주는 것규칙(코드)데이터 + 정답
컴퓨터가 만드는 것정답규칙(모델)
“강아지 알아보기”귀·코·털 조건을 직접 코딩강아지 사진 수천 장을 보여줌
예외 처리사람이 일일이 추가데이터가 늘면 스스로 개선
flowchart LR
  subgraph 전통 프로그래밍
    R[규칙] --> P1[프로그램] --> O1[정답]
  end
  subgraph 머신러닝
    D[데이터 + 정답] --> T[학습] --> M[모델 = 규칙]
    M --> O2[새 판단]
  end

위: 전통 프로그래밍은 규칙에서 답이 나오고, 머신러닝은 데이터에서 규칙이 나옵니다.

[그림 3-1] 설명: 왼쪽에는 사람이 톱니바퀴(규칙)를 그려 넣는 그림, 오른쪽에는 컴퓨터가 사진 더미(데이터)를 보며 톱니바퀴를 스스로 조립하는 그림을 나란히 배치합니다.

개념 2. 딥러닝의 등장: AI가 “특징”까지 스스로 찾다 [인공지능]

섹션 제목: “개념 2. 딥러닝의 등장: AI가 “특징”까지 스스로 찾다 [인공지능]”

  • 정의: 딥러닝(deep learning, 깊은 신경망을 이용한 학습)은 사람의 뇌 신경망을 본뜬 구조로, 데이터에서 판단에 필요한 특징(feature)까지 스스로 찾아내는 학습 방식입니다. 여러 층(layer)을 거치며 단순한 정보(선, 점)에서 복잡한 정보(눈, 얼굴)로 나아갑니다.

  • 비유: 딥러닝은 마치 여러 명의 검사관이 줄지어 선 컨베이어 벨트와 같습니다. 첫 검사관은 “선이 있나?”만 봅니다. 다음 검사관은 앞 사람의 결과를 받아 “선이 모여 눈 모양이 됐나?”를 봅니다. 층이 깊어질수록 점점 더 큰 그림을 봅니다.

딥러닝 이전에는 사람이 “어떤 특징을 봐야 하는지”(예: 귀 모양, 코 색깔)를 직접 골라 컴퓨터에 알려 줘야 했습니다. 딥러닝은 이 특징 고르기까지 데이터로부터 자동화했습니다. 이것이 2010년대 AI 대도약의 핵심 전환점입니다.

flowchart LR
  I[입력<br/>강아지 사진] --> L1[1층<br/>선·모서리 감지]
  L1 --> L2[2층<br/>귀·눈 형태 조합]
  L2 --> L3[3층<br/>얼굴 전체 인식]
  L3 --> O[출력<br/>강아지일 확률 92%]

위: 딥러닝의 층을 지나며 단순 특징이 복잡한 판단으로 조립되는 과정.
