## 방금 한 일에 이름 붙이기

| 경험 | 개념 |
| --- | --- |
| 학습에 사용한 사진들 | 데이터 |
| "펴기" / "주먹"처럼 구분한 범주 | 클래스 |
| 사진에 붙인 정답 이름 | 레이블 |
| AI가 사진에서 찾아낸 색·모양·질감의 패턴 | 특징(feature) |
| 학습이 끝난 결과물 | 모델 |

## 머신러닝의 세 가지 유형

- 지도학습: 데이터에 정답을 붙여서 학습시키는 방식.
- 비지도학습: 정답 없이 데이터만 주고, 관계나 패턴을 스스로 찾게 하는 방식.
- 강화학습: 행동을 하게 하고, 그 결과에 보상(또는 벌점)을 주어 전략을 학습시키는 방식.

<Callout kind="think">
방금 만든 Teachable Machine 모델을 떠올려보세요. 여러분은 사진에 "Class 1", "Class 2"라는 정답을 직접 붙여서 학습시켰습니다. 이건 세 가지 유형 중 무엇에 해당할까요?
</Callout>

정답: 지도학습입니다. 지도학습은 다시 두 가지로 나뉩니다.

- 분류(Classification): 정답이 "이것 아니면 저것"처럼 범주로 나뉘는 경우. (예: 펴기/주먹)
- 회귀(Regression): 정답이 연속된 숫자인 경우. (예: 내일 기온, 집값)

비지도학습의 대표적인 방법은 <strong>군집화(Clustering)</strong>로, 비슷한 특성을 가진 데이터끼리 스스로 묶는 것입니다. (예: 쇼핑몰이 정답표 없이 구매 패턴만으로 고객을 몇 개 그룹으로 자동으로 나누는 경우)

## 활동 — 이 문제엔 어떤 학습 유형이 필요할까?

<Callout kind="lab">
아래 문제들을 지도학습(분류/회귀), 비지도학습(군집화), 강화학습 중 하나로 분류하고 이유를 설명하세요.

1. 이메일이 스팸인지 판단하기
2. 공부 시간으로 예상 점수 구하기
3. 관심 분야가 비슷한 학생끼리 묶기
4. 게임 캐릭터가 높은 점수를 얻는 행동 찾기
5. 미세먼지 농도 예측하기
</Callout>

<Callout kind="discuss">
5번 "미세먼지 농도 예측"을 다시 보세요. 결과를 <strong>"좋음/보통/나쁨"</strong>으로 출력하면 무엇일까요? 결과를 <strong>구체적인 수치(㎍/㎥)</strong>로 출력하면 무엇일까요? 같은 문제도 출력 형태에 따라 분류가 될 수도, 회귀가 될 수도 있다는 사실을 짝과 확인해보세요.
</Callout>
