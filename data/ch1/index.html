4. 데이터에서 공공데이터까지

EXPERIENCE Ⅱ · DATA × AI
오늘의 질문우리가 직접 모으지 않은 데이터도 AI 서비스의 출발점이 될 수 있을까?

School Image Lab에서는 사진·음성·포즈 데이터를 직접 모으고, 모델이 그 데이터에서 패턴을 학습하여 새로운 입력을 분류하는 과정을 경험했습니다. 이제 질문의 범위를 학교 밖으로 넓힙니다. 세상의 모든 데이터를 직접 모을 수는 없습니다. 그렇다면 이미 공개된 데이터를 활용해 현실의 문제를 살펴보고 새로운 AI 서비스를 기획할 수 있을까요?

🎯 이번 단원의 미션

데이터의 다양한 형태를 구분하고, 공공데이터의 출처와 구조를 확인한 뒤 파일·API·MCP 중 목적에 맞는 방법으로 데이터를 가져옵니다.

1. 지난 프로젝트를 데이터의 관점으로 다시 보기

섹션 제목: “1. 지난 프로젝트를 데이터의 관점으로 다시 보기”
School Image Lab에서 한 일데이터의 관점에서 보면
해결할 상황을 이미지·음성·포즈로 정했다문제에 맞는 데이터 형태를 선택했다
클래스를 정하고 사례를 모았다정답 레이블이 있는 학습 데이터를 수집했다
일부 데이터를 모델에 학습시켰다데이터에서 분류 패턴을 찾게 했다
새로운 입력으로 테스트했다학습하지 않은 데이터의 결과를 예측했다
잘못 분류된 사례를 살폈다오류와 데이터의 부족·편향을 확인했다
데이터를 보완해 다시 학습했다데이터의 품질을 개선해 결과 변화를 비교했다

📚 AI는 데이터에서 패턴을 학습합니다

AI가 스스로 세상을 이해하는 것이 아닙니다. 어떤 데이터를 어떤 기준으로 모으고 표현했는지에 따라 AI가 배울 수 있는 패턴과 내놓는 결과가 달라집니다.

2. 데이터란 무엇일까?

섹션 제목: “2. 데이터란 무엇일까?”

데이터는 관찰하거나 측정하고 기록한 값입니다. 숫자뿐 아니라 문자, 사진, 소리, 영상, 위치, 날짜도 데이터가 될 수 있습니다. 기록된 데이터에 질문과 맥락을 더해 의미를 해석하면 의사 결정에 활용할 수 있는 정보가 됩니다.

구분예
기록된 데이터2026년 서울의 15~19세 인구: ○○명
맥락을 포함한 정보이전 연도보다 줄었고 감소 폭은 지역마다 다르다
데이터로 확인할 질문어느 지역에서 얼마나 빠르게 감소했는가?
활용 가능성청소년 시설·교육 프로그램 수요를 판단하는 근거

데이터가 많다고 언제나 더 좋은 것은 아닙니다. 해결하려는 질문과 맞지 않거나, 기준이 불분명하거나, 특정 집단이 빠진 데이터라면 많은 데이터도 잘못된 판단으로 이어질 수 있습니다.

3. 모든 데이터가 표처럼 생겼을까?

섹션 제목: “3. 모든 데이터가 표처럼 생겼을까?”
데이터 형태특징예이번 수업에서의 활용
정형 데이터정해진 행과 열에 같은 종류의 값이 들어간다CSV, XLSX, 통계표비교·집계·시각화에 주로 사용
반정형 데이터이름표와 구조는 있지만 고정된 표 모양은 아니다JSON, XML, API 응답필요한 항목을 골라 표로 변환
비정형 데이터고정된 행·열 구조가 없다이미지, 음성, 영상, 문서특징을 추출하거나 분류·생성에 활용

지난 프로젝트의 사진·음성·포즈는 주로 비정형 데이터였습니다. 이번 프로젝트에서는 표 형태의 정형 데이터와 API가 보내는 JSON 같은 반정형 데이터를 주로 사용합니다.

데이터 형태 판별 미션

섹션 제목: “데이터 형태 판별 미션”

다음 자료의 형태를 판단하고, AI 서비스에 사용하려면 어떤 처리가 필요할지 적습니다.

  • 학교 급식 CSV 파일
  • 날씨 API의 JSON 응답
  • 교통사고 통계표
  • 학생이 촬영한 교실 이미지
  • 뉴스 기사 본문
  • 설문 응답 스프레드시트

이 데이터는 [정형·반정형·비정형] 데이터이다. 현재 구조에서 [행·열 확인 / 필요한 항목 추출 / 레이블링 / 숫자 변환 등]이 필요하다.

4. 행 하나는 무엇을 뜻할까?

섹션 제목: “4. 행 하나는 무엇을 뜻할까?”

표를 열면 열 이름보다 먼저 한 행의 단위를 확인합니다. 같은 영화 데이터라도 한 행이 ‘하루의 순위 한 칸’인지 ‘영화 한 편’인지에 따라 가능한 질문과 계산이 달라집니다.

한 행의 단위주로 답할 수 있는 질문
날짜별 영화 순위 한 칸시간에 따라 관객 수와 순위가 어떻게 변했는가?
영화 한 편장르·스크린 수·총 관객은 어떤 관계가 있는가?
한 지역의 한 연도지역별 변화와 차이는 어떠한가?
설문 응답자 한 명응답자의 특성에 따라 답변이 어떻게 다른가?

한 대상이 여러 행에 반복되어 있는데 영화 수나 사람 수로 잘못 합산하면 전혀 다른 결과가 나옵니다. 분석 전에 반드시 “한 행은 무엇인가?”를 자신의 말로 설명합니다.

5. 공공데이터란 무엇일까?

섹션 제목: “5. 공공데이터란 무엇일까?”

공공데이터는 공공기관이 업무를 수행하며 만들거나 취득하여 관리하는 데이터를 국민이 활용할 수 있도록 제공한 것입니다. 인구·교육·기상·교통·환경·보건·경제·문화 등 다양한 분야의 데이터가 공개되어 있습니다.

찾아볼 곳예시 데이터
공공데이터포털기관별 파일 데이터와 오픈 API
KOSIS 국가통계포털인구·교육·경제·복지·환경 통계
기상자료개방포털기온·강수량·관측 지점 자료
NEIS 교육정보 개방 포털학교 기본 정보·급식·학사 일정
영화진흥위원회 KOBIS박스오피스·영화·상영 정보
HRDKorea국가자격·시험·NCS·해외취업 정보

⚠️ 공공데이터라고 자동으로 우리 질문에 맞는 것은 아닙니다

기관 이름만 보지 말고 누가, 무엇을, 어떤 기준으로, 언제 수집했는지 확인합니다. 공개 데이터라도 누락·시차·분류 기준·표본·갱신 주기 때문에 지금의 질문에 적합하지 않을 수 있습니다.

출처의 신뢰도를 확인하는 네 가지 질문

섹션 제목: “출처의 신뢰도를 확인하는 네 가지 질문”
  1. 누가 만들었는가? 책임 있는 기관과 담당 부서가 분명한가?
  2. 어떻게 모았는가? 조사·측정·집계 기준을 확인할 수 있는가?
  3. 공개하고 검증할 수 있는가? 원자료와 이용 조건이 제시되어 있는가?
  4. 계속 관리되는가? 기준 시점과 최근 갱신일을 확인할 수 있는가?

6. 공공데이터를 가져오는 세 가지 방법

섹션 제목: “6. 공공데이터를 가져오는 세 가지 방법”
방법어떻게 가져오는가적합한 상황확인할 것
파일CSV·XLSX 등을 내려받는다구조·결측·중복을 직접 확인하거나 세부 분석할 때파일명·출처·다운로드 날짜·열·단위
API주소와 조건을 보내 JSON 등의 응답을 받는다날짜·지역 등 조건을 바꾸어 최신 데이터를 반복 조회할 때요청 주소·변수·인증키·응답 항목
MCP생성형 AI가 연결된 데이터 도구를 선택해 조회한다일상어로 통계를 탐색하고 표·비교를 빠르게 만들 때AI가 쓴 도구·통계표·조건·단위

MCP가 API와 파일을 없앤 것은 아닙니다. 탐색은 MCP가 빠를 수 있고, 반복 조회에는 API가 알맞을 수 있으며, 데이터 구조와 처리 과정을 직접 통제하려면 파일이 필요할 수 있습니다. 어떤 방법을 썼는가보다 왜 그 방법이 질문에 적절했는가가 중요합니다.

7. 질문을 가지고 데이터를 찾기

섹션 제목: “7. 질문을 가지고 데이터를 찾기”

청소년 문제가 심각해졌어?와 같은 질문은 어떤 데이터를 찾아야 할지 불분명합니다. 다음 네 가지를 넣어 확인 가능한 질문으로 바꿉니다.

대상 + 기간 + 지역·집단 + 확인할 지표

막연한 관심데이터로 확인할 질문필요한 데이터
학생 수가 줄었어?최근 10년간 서울의 고등학교 학령인구는 어떻게 변했는가?연도별·연령별·지역별 인구
청년 취업이 어려워?최근 5년간 20~29세 고용률은 성별로 어떻게 달라졌는가?연도별 청년 고용률
자격증이 진로에 도움 될까?정보 분야 국가기술자격의 최근 응시자 수와 합격률은 어떻게 다른가?종목별 응시자·합격자 수

  1. 관심 적기

    내가 궁금한 현실의 현상이나 문제를 한 문장으로 씁니다.

  2. 측정할 말 찾기

    ‘심각하다’, ‘부족하다’, ‘좋다’를 확인할 수 있는 지표로 바꿉니다.

  3. 필요한 데이터 예상

    결과를 보기 전에 필요한 대상·기간·지역·변수를 적습니다.

  4. 공공데이터 탐색

    기관과 데이터 이름을 찾고 실제로 필요한 변수가 있는지 확인합니다.

  5. 질문 수정

    적절한 데이터가 없거나 기준이 다르면 질문의 범위를 바꿉니다.

DATA CHECK · 가져온 데이터 감식하기

섹션 제목: “DATA CHECK · 가져온 데이터 감식하기”
  • 데이터 제공 기관과 원출처는 어디인가?
  • 언제, 어떤 방법과 기준으로 수집했는가?
  • 한 행은 무엇을 의미하는가?
  • 어떤 열과 단위가 들어 있는가?
  • 같은 대상이 여러 행에 반복되는가?
  • 비어 있거나 중복되거나 이상한 값은 없는가?
  • 우리 질문에 직접 답할 수 있는가?
  • 이 데이터만으로 알 수 없는 것은 무엇인가?

이 순간의 생성형 AI 활용

섹션 제목: “이 순간의 생성형 AI 활용”

☑️ 이번 단원의 완료 기준

  • 지난 티처블 머신 프로젝트를 데이터 수집·학습·예측의 관점으로 설명했다.
  • 정형·반정형·비정형 데이터의 차이를 사례로 설명했다.
  • 공공데이터의 의미와 출처 확인이 필요한 이유를 설명했다.
  • 파일·API·MCP의 차이를 알고 목적에 맞는 수집 방법을 선택했다.
  • 한 행의 단위와 주요 변수·단위·품질·한계를 확인했다.
  • 생성형 AI의 설명을 원자료와 비교해 수정하거나 확인했다.
