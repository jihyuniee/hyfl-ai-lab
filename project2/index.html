Project 2. 생성형 AI와 함께 웹서비스 만들기

설문에서 가장 배우고 싶어 했던 영역(생성형 AI 활용 54.3%, AI 코딩 51.4%, 웹앱 만들기 48.6%)을 모두 담은 프로젝트입니다.

🎯 Mission

학교생활 또는 자신의 진로와 관련된 작은 문제를 해결하는 웹서비스를 생성형 AI와 함께 만들어라.

주제 예시: 학습 계획 코치 · 수행평가 일정 관리 · 외국어 학습 도우미 · 진로 탐색 질문 생성기 · 독서 기록·추천 서비스 · 교내 행사 안내 · 고민 정리 질문 서비스

🧑‍🏫 교사 Tip

초반 프로젝트는 가능하면 단일 index.html 중심으로 구성해서, 학생이 파일 하나 안에서 전체 코드를 눈으로 확인할 수 있게 하는 것을 권장합니다. (이 저장소 자체는 유지보수를 위해 Astro 구조를 계속 사용합니다 — 학생 결과물과는 별개입니다.)

  1. 문제 발견

    학교생활이나 진로에서 겪는 작은 불편함을 찾습니다.

  2. 대상 사용자 정의

    이 서비스는 누구를 위한 것인가요? (나, 같은 반 친구, 전교생 등)

  3. 핵심 기능 결정

    모든 기능을 다 넣으려 하지 말고, 꼭 필요한 기능 1~2개만 정합니다.

  4. 화면 흐름 설계

    사용자가 들어와서 어떤 순서로 화면을 보고 조작하는지 손으로 스케치합니다.

  5. 입력과 출력 정의

    사용자가 무엇을 입력하고, 서비스는 무엇을 보여주나요?

  6. AI에게 첫 구현 요청

    화면 흐름과 입력·출력을 바탕으로 AI에게 첫 번째 코드를 요청합니다.

  7. 코드 실행

    받은 코드를 브라우저에서 직접 실행해봅니다.

  8. 오류 관찰

    에러 메시지나 예상과 다른 동작을 있는 그대로 기록합니다.

  9. AI와 디버깅

    오류 메시지와 상황을 AI에게 설명하고 함께 원인을 찾습니다.

  10. 핵심 코드 이해

    완성된 코드에서 핵심 부분이 어떤 역할을 하는지 스스로 설명할 수 있는지 확인합니다.

  11. 친구 사용성 테스트

    다른 모둠 친구에게 직접 써보게 하고 어려웠던 점을 기록합니다.

  12. 화면과 기능 개선

    테스트에서 나온 의견을 반영해 개선합니다.

  13. 배포

    GitHub Pages 등으로 배포해 실제 링크를 만듭니다.

  14. 성찰

    전체 과정에서 AI가 한 일과 내가 판단한 일을 정리합니다.
