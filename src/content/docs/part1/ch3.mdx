뉴스나 유튜브에서 AI, 머신러닝, 딥러닝이라는 말이 뒤섞여 쓰이는 걸 본 적 있을 겁니다. 셋은 같은 말이 아닙니다.

## AI ⊃ 머신러닝 ⊃ 딥러닝

```
AI (인공지능)
 └─ 머신러닝 (Machine Learning)
     └─ 딥러닝 (Deep Learning)
```

- **AI**는 가장 큰 범주입니다. 규칙을 사람이 직접 입력한 전문가 시스템도, 데이터로 스스로 학습하는 머신러닝도 모두 AI에 속합니다.
- **머신러닝**은 AI 중에서도 **데이터로부터 스스로 규칙(패턴)을 찾아내는 방식**입니다.
- **딥러닝**은 머신러닝 중에서도 사람의 뇌 신경망을 본뜬 **인공신경망**을 여러 층 쌓아 학습하는 방식입니다. 지금의 이미지 인식, 음성 인식, ChatGPT는 대부분 딥러닝을 기반으로 합니다.

## 머신러닝의 핵심 질문

전문가 시스템은 사람이 규칙을 하나하나 입력해야 했습니다. 예를 들어 "이메일에 '무료', '당첨'이 있으면 스팸이다"처럼요. 그런데 사람이 미처 생각하지 못한 경우에는 이 규칙이 통하지 않습니다.

> **사람이 모든 규칙을 알려주지 않았는데, 컴퓨터는 어떻게 새로운 데이터를 판단할까?**

머신러닝의 답: 규칙을 알려주는 대신, <strong>엄청나게 많은 예시(데이터)</strong>를 보여주고 컴퓨터가 스스로 공통된 패턴을 찾게 합니다.

주목할 부분은 마지막입니다. 머신러닝은 한 번 학습하고 끝나지 않습니다. 예측·판단이 얼마나 정확했는지 **평가**하고, 그 결과로 다시 **개선**하는 순환이 계속됩니다. 이 순환을 다음 시간 Teachable Machine 실습에서 직접 경험합니다.

## 규칙 기반 프로그램 vs 머신러닝

| | 규칙 기반 프로그램 | 머신러닝 |
| --- | --- | --- |
| 판단 기준을 만드는 주체 | 사람이 직접 코드로 작성 | 컴퓨터가 데이터에서 스스로 찾음 |
| 새로운 상황 | 미리 정한 규칙에 없으면 처리 불가 | 학습한 패턴으로 추론 가능 |
| 똑똑해지는 방법 | 사람이 규칙을 더 추가함 | 데이터를 더 많이, 더 다양하게 학습함 |
