1. 인공지능이란 무엇일까?

생각을 여는 질문

섹션 제목: “생각을 여는 질문”

💭 오늘의 질문

AI라고 하면 여러분은 무엇이 떠오르나요?

대화형 생성 AI, 번역, 추천, 얼굴 인식, 내비게이션처럼 서로 다른 기술을 우리는 왜 모두 ‘인공지능’이라고 부를까요?

특정 서비스 하나를 인공지능의 대표로 정하지 않습니다. 먼저 인간이 지능을 사용해 하는 일을 생각해보면 AI라는 큰 개념을 이해하기 쉬워집니다.

사람은 어떻게 지능을 사용할까?

섹션 제목: “사람은 어떻게 지능을 사용할까?”

우리는 주변을 보고 알아차리고, 정보를 바탕으로 예상하고, 여러 선택지 가운데 판단하고, 실제 행동으로 옮깁니다.

1 인식 무엇인지 알아보기
→
2 추론·예측 정보와 패턴으로 예상하기
→
3 판단·결정 선택하고 결정하기
→
4 행동 결과를 실제 작업으로 옮기기

이 관점에서 보면 이미지 인식, 추천, 예측, 생성형 AI처럼 모습이 다른 기술을 왜 모두 AI라고 부르는지 이해하기 쉬워집니다.

📚 인공지능의 큰 개념

인공지능(AI)은 인간의 지능적 활동과 관련된 기능을 컴퓨터 시스템이 수행하도록 구현하는 기술과 연구 분야입니다.

인식, 학습, 추론, 예측, 판단, 생성, 문제 해결 등 다양한 기능이 포함될 수 있습니다.

이 말이 AI가 인간과 똑같이 생각하거나 이해한다는 뜻은 아닙니다. 실제 AI 시스템은 데이터, 규칙, 통계·확률, 학습된 패턴, 계산 및 여러 도구를 이용해 결과를 만듭니다.

생활 속에서는 어떤 모습일까?

섹션 제목: “생활 속에서는 어떤 모습일까?”
사례AI가 수행하는 지능적 활동의 예
얼굴·사물 인식이미지에서 특징을 찾아 인식·분류
콘텐츠 추천이용 정보와 패턴을 바탕으로 추천
내비게이션교통 정보 등을 이용해 경로·도착 시간 예측
번역입력된 언어의 내용을 다른 언어로 변환
생성형 AI학습된 패턴을 바탕으로 텍스트·이미지·코드 등 생성
일부 에이전트형 시스템목표에 따라 계획하고 도구를 사용해 여러 단계를 수행

이 시스템들이 모두 같은 방식으로 작동하는 것은 아닙니다. 인공지능은 하나의 기능이나 하나의 앱 이름이 아니라 넓은 기술 분야입니다.

그렇다면 컴퓨터는 어떻게 이런 일을 할까?

섹션 제목: “그렇다면 컴퓨터는 어떻게 이런 일을 할까?”

AI를 구현하는 방법은 하나가 아닙니다. 사람이 규칙을 직접 설계하는 방식도 있고, 데이터에서 패턴을 학습하게 하는 방식도 있습니다.

오늘 우리가 특히 살펴볼 흐름은 다음과 같습니다.

머신러닝 Machine Learning

섹션 제목: “머신러닝 Machine Learning”

머신러닝은 사람이 모든 판단 규칙을 하나하나 작성하는 대신 데이터를 통해 패턴을 학습하도록 하는 방법입니다.

예를 들어 여러 이미지와 정답을 이용해 학습한 분류 모델은 학습 과정에서 찾은 패턴을 이용해 새로운 이미지의 범주를 예측할 수 있습니다.

딥러닝 Deep Learning

섹션 제목: “딥러닝 Deep Learning”

딥러닝은 머신러닝의 방법 가운데 하나로 여러 층의 인공신경망을 이용해 데이터의 특징과 복잡한 패턴을 학습합니다. 이미지·음성·텍스트처럼 복잡한 데이터 처리에 널리 활용되어 왔습니다.

✏️ 먼저 생각하기

지금 이 정의들을 외울 필요는 없습니다.

곧 직접 작은 이미지 분류 모델을 학습시키고 실패시켜보면서 ‘데이터에서 패턴을 학습한다’는 말이 실제로 무엇을 뜻하는지 경험합니다.

AI는 패턴을 찾지만, 결과의 의미는 사람이 해석한다

섹션 제목: “AI는 패턴을 찾지만, 결과의 의미는 사람이 해석한다”

AI는 데이터에서 패턴을 찾고 빠르게 분석·예측할 수 있지만, 그 결과가 현재 상황에서 무엇을 의미하는지, 어떤 선택이 적절한지, 어떤 가치와 책임이 걸려 있는지는 사람이 함께 살펴야 합니다.

예를 들어 이미지 분류 모델이 높은 확률로 어떤 클래스를 예측했다고 해서 바로 좋은 판단이라고 결론 내릴 수는 없습니다.

  • 어떤 데이터로 학습했는가?
  • 새로운 상황에서도 잘 작동하는가?
  • 엉뚱한 배경이나 특징을 학습한 것은 아닌가?
  • 이 결과를 실제 상황에서 사용해도 되는가?

📚 이번 학기의 중요한 관점

AI는 패턴을 찾고 결과를 제시할 수 있습니다. 사람은 그 결과를 맥락 속에서 해석하고, 검증하고, 최종 판단합니다.

서비스 이름과 기술을 구분하기

섹션 제목: “서비스 이름과 기술을 구분하기”

ChatGPT, Gemini, Perplexity 등은 특정 회사가 제공하는 서비스 또는 제품의 이름입니다. 반면 인공지능, 머신러닝, 딥러닝, 대규모 언어 모델(LLM)은 기술이나 모델을 설명하는 개념입니다.

서비스마다 지원하는 기능과 내부 구조는 다르고 시간이 지나며 바뀔 수 있습니다. 따라서 특정 서비스의 기능을 인공지능 전체의 특징으로 일반화하지 않습니다.

오늘 기억할 큰 지도

섹션 제목: “오늘 기억할 큰 지도”

📚 오늘 기억할 네 문장

  1. 인공지능은 인간의 지능적 활동과 관련된 기능을 컴퓨터가 수행하도록 구현하는 넓은 기술 분야이다.
  2. 머신러닝은 사람이 모든 규칙을 직접 주는 대신 데이터에서 패턴을 학습하게 하는 방법이다.
  3. 딥러닝은 여러 층의 인공신경망을 이용하는 머신러닝의 한 방법이다.
  4. AI의 결과가 실제 상황에서 무엇을 의미하는지 해석하고 최종적으로 판단하는 데에는 사람의 역할이 중요하다.

수업에서 바로 확인해보기

섹션 제목: “수업에서 바로 확인해보기”

이제 설명을 더 외우는 대신 직접 모델을 가르쳐봅니다.

컴퓨터가 ‘학습한다’는 것은 실제로 무슨 뜻일까?

작은 이미지 분류 AI를 직접 만들고, 익숙한 데이터와 처음 보는 데이터에서 결과를 비교하고, 일부러 틀리게 만들어봅니다. 그 경험 뒤에 학습 데이터, 테스트 데이터, 일반화, 과대적합이라는 개념에 이름을 붙입니다.
