뉴스나 유튜브에서 AI, 머신러닝, 딥러닝이라는 말이 뒤섞여 쓰이는 걸 본 적 있을 거예요. 셋은 같은 말이 아닙니다. 세 개념은 서로 **포함 관계**에 있습니다.

```
┌─────────────────────────────────────────┐
│  AI (인공지능)                             │
│  ┌─────────────────────────────────┐    │
│  │  머신러닝 (Machine Learning)       │    │
│  │  ┌───────────────────────┐      │    │
│  │  │  딥러닝 (Deep Learning)  │      │    │
│  │  └───────────────────────┘      │    │
│  └─────────────────────────────────┘    │
└─────────────────────────────────────────┘

AI ⊃ 머신러닝 ⊃ 딥러닝
```

- **AI**는 가장 큰 범주입니다. 규칙을 사람이 직접 입력한 전문가 시스템도, 데이터로 스스로 학습하는 머신러닝도 모두 AI에 속합니다.
- **머신러닝**은 AI 중에서도 **데이터로부터 스스로 규칙(패턴)을 찾아내는 방식**을 말합니다.
- **딥러닝**은 머신러닝 중에서도 사람의 뇌 신경망 구조를 본뜬 **인공신경망**을 여러 층 쌓아서 학습하는 방식입니다. 지금의 이미지 인식, 음성 인식, ChatGPT 같은 생성형 AI는 대부분 딥러닝을 기반으로 합니다.

## 머신러닝의 핵심 질문

1차시에서 전문가 시스템은 사람이 규칙을 하나하나 입력해야 했다고 배웠습니다. 예를 들어 "이메일에 '무료', '당첨' 같은 단어가 있으면 스팸이다"처럼요. 그런데 이런 규칙은 사람이 미처 생각하지 못한 경우에는 통하지 않습니다.

머신러닝은 이 문제를 완전히 다른 방식으로 풉니다.

> **사람이 모든 규칙을 알려주지 않았는데, 컴퓨터는 어떻게 판단할까?**

답은 이렇습니다 — 규칙을 알려주는 대신, **엄청나게 많은 예시(데이터)**를 보여주고 컴퓨터가 스스로 공통된 패턴을 찾아내게 하는 것입니다.

```
데이터  →  학습  →  모델  →  새로운 데이터  →  판단
```

1. **데이터**: 정답이 딸린 수많은 예시 (예: 스팸/정상으로 표시된 메일 수만 개)
2. **학습**: 컴퓨터가 데이터 속 패턴을 찾아내는 과정
3. **모델**: 학습이 끝난 결과물. "이런 특징이 있으면 스팸일 확률이 높다"는 판단 기준을 갖게 된 프로그램
4. **새로운 데이터**: 한 번도 본 적 없는 새 메일
5. **판단**: 모델이 새 메일을 보고 스팸인지 아닌지 결정

즉 머신러닝에서 컴퓨터가 '똑똑해진다'는 것은, 사람이 심어준 규칙이 많아지는 게 아니라 **데이터를 많이, 그리고 잘 학습했다**는 뜻입니다.

## 정리

- AI ⊃ 머신러닝 ⊃ 딥러닝의 포함 관계를 갖는다.
- 머신러닝은 사람이 규칙을 입력하는 대신, 데이터로부터 컴퓨터가 스스로 규칙(모델)을 찾아내는 방식이다.
- 데이터 → 학습 → 모델 → 새로운 데이터 → 판단이라는 흐름이 머신러닝의 기본 골격이다.
