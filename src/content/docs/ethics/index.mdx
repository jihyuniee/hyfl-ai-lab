AI 윤리는 금지 목록이 아닙니다. AI가 사람과 사회에 미치는 영향을 살피고 어떤 목적으로 어디까지 사용할지, 결과를 누가 확인하고 책임질지 판단하는 과정입니다.

이미지 분류에서는 동의와 대표성을, 공공데이터 분석에서는 출처·전처리·일반화를, 서비스 설계에서는 데이터 권리·공정성·안전·사람의 개입을 생각했습니다. 이제 흩어져 있던 판단을 정리합니다.

## 1. 데이터와 권리

- 입력한 글·사진·음원·파일을 사용할 권한이 있는가?
- 개인정보·얼굴·목소리·위치·건강·학습 기록이 포함되는가?
- 수집 목적과 보관 기간을 당사자가 알고 동의했는가?
- 서비스에 꼭 필요한 정보만 수집하는가?
- 공공데이터의 이용 조건과 갱신 주기를 확인했는가?
- AI가 만든 결과가 특정 작품을 지나치게 닮거나 권리를 침해하지 않는가?

## 2. 할루시네이션과 검증

생성형 AI는 문맥에 이어질 가능성이 높은 결과를 만들기 때문에 존재하지 않는 사실·수치·출처를 그럴듯하게 제시할 수 있습니다. 검색이나 파일 분석 기능이 있어도 자료 선택·계산·해석에서 오류가 생길 수 있습니다.

1. 답변에서 확인해야 할 사실·수치·인용·출처를 표시합니다.
2. 링크의 존재만 보지 말고 실제 원자료를 엽니다.
3. 작성 기관·발표 시점·대상·수집 방법·단위를 확인합니다.
4. AI가 사용한 열·전처리·계산이 원파일과 맞는지 비교합니다.
5. 확인할 수 없는 내용은 사실처럼 사용하지 않습니다.

## 3. 편향과 빠진 사람

| 편향이 생기는 지점 | 확인할 질문 |
| --- | --- |
| 문제 정의 | 측정하기 쉬운 값만 성공 기준으로 정하지 않았는가? |
| 데이터 수집 | 특정 지역·성별·연령·언어·상황의 자료가 부족하지 않은가? |
| 라벨과 전처리 | 사람의 고정관념이나 임의의 삭제 기준이 들어가지 않았는가? |
| 모델 평가 | 전체 정확도만 보고 특정 집단의 오류를 놓치지 않았는가? |
| 실제 사용 | 학습·분석 때와 다른 환경에 결과를 그대로 적용하지 않았는가? |

## 4. AI의 판단을 설명할 수 있는가?

AI가 높은 확률로 결과를 제시해도 무엇을 근거로 그렇게 판단했는지는 바로 드러나지 않을 수 있습니다. 특히 의료·채용·대출처럼 사람에게 큰 영향을 주는 판단에서는 결과만 제시하는 것으로 충분하지 않습니다. 어떤 데이터와 기준을 사용했는지, 결과에 어떤 한계가 있는지 확인할 수 있어야 합니다.

**설명 가능한 AI**는 AI가 사람처럼 자신의 생각을 말하게 만드는 것이 아닙니다. 모델이 입력의 어떤 특징에 크게 반응했는지, 입력 조건을 바꾸면 결과가 어떻게 달라지는지 등을 사람이 이해하고 검토할 수 있는 형태로 보여 주려는 접근입니다.

<Callout kind="think" title="School Image Lab 다시 보기">우리 모델이 교실과 복도를 잘 구분했다면 정말 공간의 특징을 학습한 것일까요? 아니면 특정 사람·조명·촬영 각도처럼 우리가 의도하지 않은 특징에 반응한 것일까요? 배경과 촬영 조건을 바꿔 테스트하고 결과가 달라지는 이유를 데이터에서 찾아보세요.</Callout>

## 5. AI가 친구처럼 느껴진다면?

대화형 AI는 사용자의 말을 기억하는 것처럼 반응하고, 위로하거나 공감하는 표현을 만들 수 있습니다. 그러나 자연스러운 공감 표현과 실제 감정은 같은 것이 아닙니다. 친밀하게 느껴지는 대화일수록 어떤 정보를 입력하고 있는지, 중요한 판단을 누구에게 맡기고 있는지 더 주의 깊게 살펴야 합니다.

<Callout kind="think" title="선택 토론 · AI와 관계 맺기">
- AI가 위로해 주면 그것을 진짜 공감이라고 할 수 있을까요?
- 개인적인 고민을 말할 때 어떤 정보가 수집되거나 남을 수 있을까요?
- AI와의 대화가 사람과의 관계를 돕는 경우와 방해하는 경우는 무엇일까요?
- 상담이나 중요한 결정을 AI에게 맡겨도 되는 범위는 어디까지일까요?
</Callout>

## 6. 가장 위험한 실패와 사람의 개입

- AI가 틀리면 누가 어떤 피해를 입는가?
- 사용자는 AI 사용 사실과 판단 근거를 알 수 있는가?
- 결과를 수정·거부하거나 사람에게 다시 판단받을 수 있는가?
- 문제가 생기면 누가 설명하고 책임지는가?
- AI를 사용하지 않거나 사용 범위를 줄이는 대안은 없는가?

<Callout kind="reflect" title="AI 윤리의 핵심">기술적으로 가능하다는 사실만으로 해야 할 일이 되지는 않습니다. 목적과 맥락을 살피고, 영향을 받는 사람들의 관점을 비교하며, 선택의 근거를 설명하고 책임지는 것이 사람의 역할입니다.</Callout>
