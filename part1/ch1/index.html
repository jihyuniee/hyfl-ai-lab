1. 인공지능이란 무엇일까?

오늘의 질문

섹션 제목: “오늘의 질문”

💭 오늘의 질문

같은 AI를 사용해도 결과의 깊이와 신뢰도가 달라지는 이유는 무엇일까요?

차이는 AI 모델의 성능에서만 생기지 않습니다. 사용자가 문제를 어떻게 정의했는지, 어떤 맥락과 데이터를 제공했는지, 결과를 어떻게 검증하고 수정했는지도 영향을 줍니다. 이 차이를 이해하려면 먼저 AI가 무엇을 입력받아 어떤 방식으로 판단하고 결과를 만드는지 살펴볼 필요가 있습니다.

우리는 왜 AI를 배우는가?

섹션 제목: “우리는 왜 AI를 배우는가?”

영상 속 데미스 허사비스는 AI를 과학과 사회의 복잡한 문제를 해결하는 도구로 바라봅니다. 영상을 보며 다음 두 가지를 생각해보세요.

  • AI는 기존의 계산 도구나 검색 도구와 무엇이 다를까요?
  • AI가 특히 큰 역할을 할 수 있는 문제에는 어떤 공통점이 있을까요?

🎯 이번 학기의 방향

이번 학기에는 AI의 작동 원리를 이해하고, 목적에 맞게 활용하며, 그 결과를 근거로 검증하고 개선하는 문제 해결 과정을 탐구합니다.

학습 목표

섹션 제목: “학습 목표”

오늘 수업이 끝나면 다음을 할 수 있습니다.

  1. 인공지능을 인식·학습·추론·예측·문제 해결의 관점에서 설명할 수 있다.
  2. 인공지능이 인간처럼 생각하는 것과 지능적으로 보이는 결과를 만드는 것을 구분할 수 있다.
  3. 규칙을 사람이 정하는 방식과 데이터에서 규칙을 학습하는 방식의 차이를 설명할 수 있다.
  4. 튜링 테스트의 의미와 한계를 설명할 수 있다.

같은 AI, 다른 결과

섹션 제목: “같은 AI, 다른 결과”

같은 생성형 AI에 같은 주제를 질문해도 결과는 달라질 수 있습니다. 다음 요소가 결과에 어떤 영향을 주는지 생각해보세요.

  • 문제 정의: 무엇을 해결하려는지 분명한가?
  • 맥락: 대상, 목적, 상황이 충분히 제공되었는가?
  • 데이터와 근거: 판단에 필요한 자료가 제공되었는가?
  • 요청 설계: 조건과 결과의 형태가 구체적인가?
  • 검증과 수정: 첫 결과를 확인하고 후속 질문으로 개선했는가?

좋은 결과는 긴 명령어 하나로 결정되지 않습니다. 문제를 정확히 이해하고, 필요한 정보를 선택하고, 결과를 검토하며 대화를 발전시키는 과정에서 만들어집니다.

1. 인공 + 지능

섹션 제목: “1. 인공 + 지능”

**인공(人工)**은 사람이 만들었다는 뜻이고, **지능(知能)**은 상황을 인식하고 배우며 판단하여 문제를 해결하는 능력을 뜻합니다. 지능적인 활동을 나누어 보면 다음과 같습니다.

1 인식 무엇인지 알아보기
→
2 학습 경험에서 규칙 찾기
→
3 추론·예측 근거로 판단하기
→
4 문제 해결 목표에 맞게 행동하기

예를 들어 지도 앱은 현재 위치와 교통 상황을 인식하고, 과거와 현재의 데이터를 활용하여 이동 시간을 예측하며, 가능한 경로 중 적절한 길을 찾아 문제를 해결합니다.

📚 인공지능의 정의

인공지능(AI)은 컴퓨터가 인식, 학습, 추론·예측, 문제 해결처럼 인간의 지능과 관련된 활동을 수행하도록 만든 기술입니다.

여기서 중요한 말은 ‘인간의 지능과 관련된 활동’입니다. AI가 인간과 똑같이 생각한다는 뜻이 아니라, 계산·확률·규칙·데이터의 패턴을 이용해 지능적으로 보이는 결과를 만든다는 뜻입니다.

모든 자동화 프로그램이 AI일까?

섹션 제목: “모든 자동화 프로그램이 AI일까?”

정해진 시간에 울리는 알람은 사람이 지정한 조건에 따라 작동합니다. 반면 사용자의 수면 패턴을 분석하여 알람 시간을 추천한다면, 데이터에서 패턴을 찾고 예측한다는 점에서 AI의 성격이 더 강합니다.

따라서 ‘컴퓨터가 한다’는 이유만으로 모두 AI라고 부를 수는 없습니다. 다음 질문을 확인해야 합니다.

  • 주변 상황이나 데이터를 인식하는가?
  • 경험이나 데이터에서 패턴을 학습하는가?
  • 새로운 상황에서 판단하거나 결과를 예측하는가?
  • 목표를 달성하기 위해 여러 가능성 중 하나를 선택하는가?

AI와 일반 프로그램의 경계가 언제나 완벽하게 나뉘는 것은 아닙니다. 중요한 것은 이름을 외우는 것이 아니라, 어떤 방식으로 결과를 만드는지 근거를 들어 설명하는 것입니다.

2. AI가 문제를 해결하는 기본 구조

섹션 제목: “2. AI가 문제를 해결하는 기본 구조”

AI 서비스는 겉으로 매우 복잡해 보여도 기본 구조는 비교적 단순합니다.

1 문제 무엇을 해결할까?
→
2 입력 어떤 정보가 필요한가?
→
3 처리 규칙·모델로 판단
→
4 출력 분류·예측·생성·행동
→
5 검증 정확하고 유용한가?
사례입력AI의 처리출력사람이 확인할 것
얼굴 인식카메라 이미지얼굴 특징 비교동일 인물 여부다른 사람을 잘못 인식하지 않는가
번역원문 문장문맥과 언어 패턴 분석번역 문장의미와 상황에 맞는가
추천 시스템시청·검색 기록사용자와 콘텐츠 패턴 분석추천 목록편향된 정보만 반복하지 않는가
의료 영상 보조의료 영상이상 패턴 탐지의심 영역·확률의사가 다른 검사와 함께 판단했는가
생성형 AI질문과 대화 맥락다음에 올 표현을 확률적으로 생성텍스트·이미지 등사실이며 출처를 확인할 수 있는가

⚠️ 출력이 나왔다고 문제가 해결된 것은 아니다

AI의 출력은 판단을 돕는 자료일 수 있지만 언제나 정답은 아닙니다. 좋은 AI 활용에는 결과 생성뿐 아니라 검증, 수정, 책임 있는 최종 판단이 포함됩니다.

3. 사람이 규칙을 정할까, AI가 규칙을 찾을까

섹션 제목: “3. 사람이 규칙을 정할까, AI가 규칙을 찾을까”

초기의 많은 인공지능은 사람이 지식과 규칙을 직접 입력하는 방식이었습니다.

  • 규칙 기반 방식: “만약 이메일 제목에 특정 표현이 있으면 스팸으로 분류한다”처럼 사람이 IF–THEN 규칙을 정합니다.
  • 학습 기반 방식: 많은 스팸·정상 이메일 사례를 보여주고, 컴퓨터가 두 집단을 구분하는 패턴을 데이터에서 찾습니다.
구분규칙 기반학습 기반
규칙을 만드는 주체사람데이터로부터 학습한 모델
장점판단 과정이 비교적 명확함복잡한 패턴을 다룰 수 있음
한계모든 상황의 규칙을 미리 작성하기 어려움데이터의 양과 질, 편향에 영향을 받음
적합한 문제규칙이 분명하고 변화가 적은 문제예외가 많고 패턴이 복잡한 문제

현대의 AI는 주로 학습 기반 방식을 활용하지만, 실제 서비스에서는 규칙과 학습 모델을 함께 사용하는 경우도 많습니다. 다음 차시들에서 머신러닝과 딥러닝이 데이터에서 어떻게 패턴을 학습하는지 살펴봅니다.

4. AI는 정말 ‘생각’할까? — 튜링 테스트

섹션 제목: “4. AI는 정말 ‘생각’할까? — 튜링 테스트”

1950년 앨런 튜링은 “기계가 생각할 수 있는가?”라는 추상적인 질문을, 관찰 가능한 실험으로 바꾸었습니다.

  1. 판정관은 보이지 않는 두 상대와 글로 대화합니다.
  2. 한쪽은 인간이고 다른 한쪽은 컴퓨터입니다.
  3. 판정관이 대화만으로 컴퓨터를 안정적으로 구별하지 못한다면, 그 컴퓨터가 인간과 비슷한 지능적 행동을 보였다고 판단합니다.

이것이 튜링 테스트입니다. 기계의 내부에 ‘마음’이 있는지 확인하는 대신, 대화에서 나타나는 행동을 평가했다는 점에 의미가 있습니다.

💬 튜링 테스트가 증명하지 못하는 것

사람처럼 자연스럽게 말할 수 있다고 해서 다음 능력까지 자동으로 증명되는 것은 아닙니다.

  • 말의 의미를 인간처럼 이해하는가?
  • 말한 내용이 사실인지 스스로 검증하는가?
  • 현실 세계의 경험과 상식을 충분히 가지고 있는가?
  • 자신의 판단에 책임을 질 수 있는가?

따라서 튜링 테스트를 통과하는 것과 인간처럼 이해하고 사고하는 것은 같은 말이 아닙니다.

5. 약인공지능과 강인공지능

섹션 제목: “5. 약인공지능과 강인공지능”
  • 약인공지능(Narrow AI): 특정한 목적과 범위 안에서 작동하는 AI입니다. 번역, 추천, 이미지 분류, 음성 인식, 생성형 AI 등 현재 사용하는 AI는 특정 기능과 학습 범위에 의존합니다.
  • 강인공지능(Artificial General Intelligence): 인간처럼 다양한 분야의 지식을 유연하게 이해하고, 새로운 문제를 스스로 학습하여 해결하는 일반적 지능을 뜻하는 개념입니다.

⚠️ 주의

‘약인공지능’의 약은 성능이 낮다는 뜻이 아닙니다. 한 분야에서는 인간보다 빠르거나 정확할 수 있지만, 정해진 목적과 조건을 벗어나면 능력이 제한된다는 뜻입니다.

핵심 정리

섹션 제목: “핵심 정리”

📚 오늘 반드시 기억할 네 문장

  1. 인공지능은 컴퓨터가 인간의 지능과 관련된 활동을 수행하도록 만든 기술이다.
  2. AI는 인간과 같은 방식으로 생각하지 않아도 지능적으로 보이는 결과를 만들 수 있다.
  3. AI는 문제에 필요한 입력을 처리해 출력을 만들며, 사람은 그 결과를 검증해야 한다.
  4. 학습 기반 AI의 성능과 판단은 학습한 데이터의 양·질·편향에 영향을 받는다.

형성 평가

섹션 제목: “형성 평가”

1. 다음 중 인공지능에 대한 설명으로 가장 적절한 것은?

섹션 제목: “1. 다음 중 인공지능에 대한 설명으로 가장 적절한 것은?”

A. 인터넷에 연결된 모든 프로그램
B. 사람이 하는 모든 일을 대신하는 로봇
C. 인식·학습·추론·예측·문제 해결과 관련된 활동을 수행하도록 만든 기술
D. 사람과 완전히 같은 방식으로 생각하는 컴퓨터

정답과 해설

정답: C
AI는 인간과 같은 방식으로 생각해야 하는 것이 아니라, 인간의 지능과 관련된 활동을 수행하도록 만든 기술입니다.

2. 규칙 기반 프로그램과 학습 기반 AI의 가장 중요한 차이는 무엇인가요?

섹션 제목: “2. 규칙 기반 프로그램과 학습 기반 AI의 가장 중요한 차이는 무엇인가요?”
예시 답안

규칙 기반 방식은 사람이 판단 규칙을 직접 정하고, 학습 기반 방식은 컴퓨터가 데이터에서 판단에 필요한 패턴을 찾습니다.
