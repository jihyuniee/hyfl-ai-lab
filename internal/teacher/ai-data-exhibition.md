# AI × DATA 첫 작품 전시 — DATA QUEEN

사용자 요청으로 9반2팀 DATA QUEEN의 Re:Cloth를 첫 사례로 전시한다. 제공된 활동지에서 공개용 내용을 별도로 정리했으며 원문 파일을 웹사이트에 복사하지 않는다. 원문에 포함된 비밀정보·학번을 공개 변경 파일에서 제외했으며 키 폐기·재발급을 사용자에게 안내했다. 원문 인증 문자열을 이 기록에도 남기지 않는다.

## 위치와 연결

- 작품집: /hyfl-ai-lab/exhibition/ai-data/
- 작품 상세: /hyfl-ai-lab/exhibition/ai-data/data-queen/
- 기존 첫 프로젝트 전시와 두 번째 작품집은 프로젝트 선택 링크로 연결한다.
- 교과서 8단원의 끝에 굵은 작품 보기 링크를 둔다. 목차 항목은 추가하지 않는다.
- 최초에는 한 팀을 전시했다. 2026-11-05에 제공된 활동지로 9반 에픽피자를 추가했으며, 등록된 프로젝트 수와 반별 목록은 데이터에서 계산한다. 다른 반·팀·수상 결과를 가상으로 만들지 않는다.

## 근거 범위

- 팀명·반·번호·이름·역할·문제 정의·조사 데이터·설계 요청·10/15~10/28 진행 기록은 제공된 활동지를 요약했다.
- KOSIS 링크는 활동지에 적힌 원문을 그대로 연결했다. 지역·기간·단위·수치의 독립 검증이 끝난 자료로 표현하지 않았다.
- 의류수거함이 많다는 것과 폐의류가 적다는 것의 관계는 통계적으로 입증된 결론으로 제시하지 않는다.
- 폐의류 수치 증가, 업체 수거 요금·조건, 재활용 증대 같은 독립 검증되지 않은 수치·효과는 전시의 성과로 옮기지 않았다.
- 활동지 STEP 3-2의 원자료 비교·사용자 테스트, 정식 AI 활용 기록은 비어 있다. 원문 설계 요청과 학생 선택은 소개하되 검증 완료로 꾸미지 않는다.

## 현재 웹앱 확인 2026-11-03

https://dataqueen.vercel.app/ 접속 및 Re:Cloth 제목, 배출 가이드·지도·퀴즈·질문 화면 확인.

배출 가이드에서 ‘솜이불’ 입력 → ‘수거 불가 솜이불’과 관할 구청 처리 안내 메시지 표시를 확인했다. 이는 화면 동작 확인이며 지자체 원자료와의 정확성 대조는 아니다.

지도는 카카오맵 연동 예정이라는 안내와 샘플 수거함 목록을 보여준다. 실시간 지도나 실제 수거함 데이터가 연결되었다고 쓰지 않는다. 퀴즈는3문제 안내와 시작 화면을 확인했다. 생성형 AI 답변·추천 API는 검증하지 않았다. 작품은 ‘제작 중’으로 표시한다.

공개용 소개는 학생의 질문과 의사결정이 중심이 되며 수상·점수·사용자 효과를 임의로 부여하지 않는다. 활동지 내용과 현재 구현은 구분한다. 댓글·심사·등록 폼은 이번 요청 범위에 포함하지 않는다.

## 두 번째 프로젝트 — 9반 에픽피자 · 길온 (2026-11-05)

- 제공된 활동지를 요약해 `/exhibition/ai-data/epic-pizza/`에 추가했다. 팀 번호는 활동지에서 확인되지 않아 만들지 않았으며 학번과 활동지 원문은 공개하지 않는다.
- 팀원·역할·문제·데이터 활용·개선 경험은 활동지 STEP 0~5를 근거로 정리했다. 긴 AI 답변과 초기 설계 전체를 완성 기능으로 옮기지 않는다.
- 웹앱 `https://leokim0502.github.io/T1win/`에서 CCTV 위치 지도, 목적·반경·중복 처리 선택, 경로 선택과 CCTV 대수·지점 수 표시를 확인했다. 공개 코드도 읽어 좌표와 카메라 대수를 직접 처리하는 구조를 확인했다. 학생 웹앱 코드는 수정하지 않았다.
- 웹앱 출처 표시는 송파구청 관리 CCTV 정보, `CCTV정보_서울특별시.csv` 중 송파구 행, 기준일 2026-05-01이다. 원자료 URL은 활동지와 웹앱에서 확인되지 않았으므로 링크를 추측해 넣거나 원자료 검증 완료로 표현하지 않는다.
- 활동지 STEP 3-2에는 롯데월드→올림픽공원 17대·5곳, 올림픽공원→몽촌토성 10대·2곳, 잠실야구장→롯데월드 22대·7곳이 일치한다고 기록되어 있다. 모두 팀 기록으로 표시한다.
- 전시 준비 시 롯데월드→올림픽공원을 생활방범·반경 30m·중복 행 제외 해제 상태로 실행한 결과, 보행 경로 후보는 10대·2곳(3.50km)과 38대·12곳(3.56km)이었다. 38대 경로가 선택되었다. 활동지 수치와 다르며, 원인과 원자료 정확성을 확인한 것은 아니다. 조건을 맞춘 재확인이 필요하다고 함께 적고 상태를 ‘검증 중’으로 둔다.
- 활동지와 코드에 있는 ‘카메라 대수가 안전도를 뜻하지 않는다’는 한계를 반영했다. AI 위험도 예측·비상벨/보안등 위치·동별 인구 표시를 구현된 기능으로 소개하지 않는다. 112 전화 연결은 시험하지 않았다.
- 목록에 여러 프로젝트를 표시하고 미리보기 컴포넌트가 각 프로젝트의 주소·제목·고유 모달을 쓰도록 변경했다. 기존 DATA QUEEN은 ID로 조회하며 소개 내용과 주소는 유지한다.

## 7반 주민문화 · 컬처링크 (2026-11-09)

- 제공된 활동지에서 윤주은·정민제의 문제 정의, 자료 조사, 기획 변경, 역할, 개선 기록을 요약했다. 학번과 원문 끝의 인증 문자열은 게시하지 않는다.
- 공개 웹앱에서 국립중앙도서관 검색 결과 1개와 주소, 기획서 등록 항목, 시연용 가상 프로젝트 표시를 확인했다. 게시·투자자 등록·연락 요청은 실행하지 않았다.
- 공개 index.html은 IndexedDB에 projects/investors/requests를 저장한다. 기기 간 공유·실제 투자 매칭·공공 지원 성사로 소개하지 않는다. AI 분석도 확인되지 않아 확장 구상으로 분리한다.
- 앱의 내장 데이터 표시 3,551개와 활동지의 다른 집계 수치를 합치지 않았다. 지역 옵션에 광역 합계·기초 합계가 있어 집계 행·중복 확인이 필요하다고 소개한다. 원자료 URL과 검증된 수치를 추측하지 않는다.
- 학생의 탐구와 설계 결정을 중심으로 기존 네 영역의 상세 페이지와 7반 목록을 추가한다. 상태는 프로토타입이다.

## 7반 진라면신라면 · 키오스크 연습실 (2026-11-09)

- 신재영·홍서진의 활동지에 근거해 고령자 디지털 격차, 조사 자료를 통한 기능 설계, 부모님 의견을 반영한 연습·실전 모드 구분을 소개했다. 학번은 게시하지 않는다.
- 관공서 서류 발급에서 요금 납부 오답 안내, 민원 발급 정답 피드백과 다음 단계, 실전 모드 진입을 브라우저에서 확인했다.
- 현재 공개 코드의 의견은 console.log로 출력하며 서버 저장·운영자 전송으로 확인되지 않았다. 교육 효과는 검증되지 않았으며 AI 추천 전체를 완성 기능으로 쓰지 않는다.
- 활동지의 업종별 난이도 순위 서술에 모순이 있어 확정 순위를 게시하지 않았다. 17.9%와 9,955명은 팀 기록으로 명시했다.
- 상단에 전체·6~10반 이동 메뉴를 넣고 반별 정적 URL을 생성한다. 작품 없는 반은 준비 중 안내를 제공하며 목록·건수는 실제 데이터에서 계산한다.

## 팀 설문 9문항을 전시관에 반영하는 방법 (2026-11-10)

첫 화면은 웹앱의 실제 첫 화면을 크게 보여주는 브라우저 모양 카드다. 작품명은 작은 이름표로, 5번 답변은 큰 제목으로 표시한다. 팀 이름·반, 웹앱 체험, 좋아요·댓글이 아래에 이어진다. 별도 팀 사진이나 답변을 임의로 만들지 않는다.

| 설문 문항 | 공개 데이터 / 화면 위치 |
| --- | --- |
| 1. 반 | `classroom` / 반별 보기·팀 소개 |
| 2. 팀명과 팀원의 학번·이름 | `team`, `members` / 팀명과 공개용 이름만 사용. 학번과 폼 원본은 비공개로 보관 |
| 3. 웹앱 이름 | `title` / 카드의 작품명·브라우저 이미지 대체 텍스트 |
| 4. 웹앱 주소 | `url` / 주소 표시·웹앱 체험 버튼 |
| 5. 한 문장 소개 | `story.oneLineIntro` / 카드의 큰 제목·상세 화면의 큰 제목 |
| 6. 관심을 갖게 된 계기 | `story.motivation` / ‘시작한 이유’ |
| 7. 활용한 공공데이터와 확인한 내용 | `story.dataUse` / ‘데이터에서 발견한 것’ |
| 8. 웹앱의 대상과 기능 | `story.features` / ‘직접 써 보세요’ |
| 9. 가장 기억에 남는 제작 경험 | `story.memory` / ‘만들어 가는 이야기’ |

`src/data/ai-data-projects.json`의 해당 프로젝트에 `story` 객체를 추가한다. 다섯 항목이 실제 답변으로 모두 채워지면 카드 제목과 학생 이야기 형식 상세 화면이 함께 표시된다. 답변이 오기 전에는 기존 질문과 활동지 기반 상세 설명을 유지한다. 기존 팀의 응답을 지어 채우지 않는다. 여러 문단과 줄바꿈은 보존하며 문자열은 HTML로 실행하지 않는다.

Google Forms와 자동 연결된 구조는 아니다. 팀이 확인한 공개용 답변을 교사가 검토해 넣는다. 7번 답변의 통계·출처, 8번의 기능은 학생 진술이며 독립 검증 완료로 바꾸어 표현하지 않는다. 활동지와 실행 확인 기록은 기존 상세 페이지의 대체 분기에 계속 보존한다.

표지는 `public/exhibition/ai-data/covers/<프로젝트 ID>.webp`에 실제 화면을 저장한다. 학생이 첨부한 선택 사진은 공개 동의를 확인한 뒤 별도로 배치하며, 학번이나 비밀키가 노출된 원본을 게시하지 않는다. 현재 표지를 팀 사진으로 자동 교체하지 않는다.
