우리 팀 웹앱에 **질문에 답하기·자료 설명하기·번역하기** 같은 AI 기능을 넣고 싶을 때 활용하는 안내입니다.

## 1. 구글 클래스룸 댓글로 신청하기

**수업의 구글 클래스룸 게시물에 팀명과 넣고 싶은 기능을 댓글로 남겨 주세요.** 선생님이 확인한 뒤 API 사용과 연결에 필요한 사항을 안내합니다.

> 예: ○반 ○팀입니다. 우리 앱에서 검색한 시설 정보를 설명해 주는 챗봇을 넣고 싶습니다. API 사용을 신청합니다.

이 안내의 AI API는 **우리 앱에서 GPT나 Claude에 질문을 보내고 답변을 받아 오는 연결 방식**입니다.

## 2. 챗봇 시작 파일 준비하기

**[챗봇 시작 파일 ZIP 다운로드](/hyfl-ai-lab/templates/ai-chatbot-starter.zip)**

압축을 풀면 질문을 입력하는 화면과 AI에 연결하는 서버 코드가 들어 있습니다. **현재 만들고 있는 앱 파일과 시작 파일을 함께 준비**하세요.

## 3. AI에게 우리 앱에 연결해 달라고 요청하기

ChatGPT나 Claude에 **현재 앱 파일과 시작 파일을 함께 첨부**하고, 우리 앱에서 챗봇이 할 일을 설명하세요.

예를 들어 다음과 같이 요청할 수 있습니다.

> 현재 만들고 있는 웹앱과 챗봇 시작 파일입니다. 기존 기능을 유지하면서, 검색한 시설 정보를 설명해 주는 챗봇을 추가해 주세요. API 키는 서버 환경변수에 보관하도록 해 주세요. 제가 해야 할 설정과 배포 방법을 한 단계씩 안내해 주세요.

‘검색한 시설 정보를 설명해 주는’ 부분을 **우리 팀이 원하는 기능**으로 바꾸면 됩니다. AI가 안내한 순서대로 수정하고, 연결 설정은 선생님의 안내를 받아 진행하세요.

<Callout kind="concept" title="API 키는 어디에 넣나요?">

API 키는 **배포 서비스의 서버 환경변수**에 등록합니다. HTML 코드, 클래스룸 댓글, AI 대화창에 실제 키를 붙여 넣지 마세요.

</Callout>

<details>
<summary>시작 파일의 연결 설정이 필요할 때 펼쳐 보기</summary>

시작 파일은 **Vercel에서 화면과 서버를 함께 실행**하는 예제입니다. GitHub에 압축을 푼 파일과 폴더를 구조대로 올린 뒤, Vercel에서 해당 저장소를 가져옵니다.

1. 프로젝트 설정에서 **Framework Preset: Other**를 선택합니다. 저장소 최상위에 `index.html`과 `package.json`이 있는지 확인합니다.
2. **Build Command**의 Override를 켜고 값을 비워 둡니다.
3. **Environment Variables**에 선생님과 확인한 값을 등록하고 배포합니다.

| 변수 이름 | 등록할 값 |
| --- | --- |
| `AI_PROVIDER` | `openai` 또는 `anthropic` |
| `AI_MODEL` | 선생님과 확인한 모델 이름 |
| `OPENAI_API_KEY` | OpenAI를 사용할 때 등록하는 API 키 |
| `ANTHROPIC_API_KEY` | Claude를 사용할 때 등록하는 API 키 |
| `CHAT_ACCESS_CODE` | 선생님과 정한 앱 이용코드: 영문·숫자·`_`·`-` 조합 16~128자 |

**앱 이용코드**는 챗봇 화면에서 입력하는 값이며, API 키와 별개입니다. 환경변수를 변경한 뒤에는 **Redeploy**로 다시 배포합니다.

기존 앱이 GitHub Pages에 있다면 AI를 호출할 서버 실행 환경도 필요합니다. 위 요청문으로 현재 배포 방법을 AI에 알려 주고 연결 안내를 받으세요. 자세한 설명은 시작 파일의 `README.md`에서 확인할 수 있습니다.

</details>

## 4. 질문을 보내 확인하기

배포된 앱에서 이용코드를 입력하고 짧은 질문을 보내 보세요.

- 질문을 보내면 답변이 표시되는지 확인합니다.
- 우리 앱의 자료를 설명한다면 숫자·이름·날짜가 실제 자료와 맞는지 확인합니다.
- 기존에 만든 검색·지도·버튼도 함께 확인합니다.

오류가 나면 **오류 메시지와 관련 코드를 AI에게 보여 주고 수정**을 요청하세요. API 키 설정이나 사용 한도에 관한 문제는 선생님께 문의하세요.
