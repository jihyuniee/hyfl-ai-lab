세 번의 프로젝트를 끝냈습니다. 여기서부터는 힘을 빼고 갑니다. 평가 부담 없이, 오늘은 이것 가지고 놀아봅시다. 아래 도구 중 원하는 것을 골라 체험하세요. AI Agent는 선택 활동입니다 — 관심 있는 사람만 도전해도 충분합니다.

- 생성형 이미지 — 원하는 이미지를 프롬프트로 만들어봅니다.
- 음성 AI — 텍스트를 음성으로, 음성을 텍스트로 바꿔봅니다.
- 영상 AI — 짧은 프롬프트로 영상을 만들어봅니다.
- NotebookLM — 내가 올린 자료만을 근거로 요약·질문에 답하는 도구를 체험합니다.
- Vibe Coding 미니 챌린지 — Project 2보다 훨씬 작은 규모로, 5분 안에 만들 수 있는 것을 만들어봅니다.
- 멀티모달 AI — 텍스트뿐 아니라 이미지·음성을 함께 이해하는 AI를 체험합니다.
- AI Agent *(선택)* — 여러 단계를 스스로 계획하고 실행까지 하는 에이전트를 체험합니다. 챗봇과 무엇이 다른지 비교해보세요.

## 공통 질문

<Callout kind="lab" title="무엇을 체험하든 이 다섯 가지는 기록하세요">
1. 입력과 출력은 무엇인가?
2. 어떤 상황에서 잘하는가?
3. 어떤 상황에서 실패하는가?
4. 결과를 무엇으로 검증할 수 있는가?
5. AI가 만들고, 인간이 결정해야 하는 부분은 무엇인가?
</Callout>

```
처음 결과  →  발견한 문제  →  바꾼 입력  →  달라진 결과
```
