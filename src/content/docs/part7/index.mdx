윤리는 마지막에만 배우는 별도 목록이 아니었습니다. 이미지 수집에서는 동의와 대표성을, 데이터 분석에서는 출처·전처리·상관과 인과를, 생성형 AI 협업에서는 맥락과 검증을, 서비스 기획에서는 공정성·안전·사람의 개입을 판단해왔습니다.

## 경험을 한 줄로 연결하기

| 경험 | AI가 잘한 일 | 사람이 해야 했던 일 |
| --- | --- | --- |
| 이미지 분류 | 데이터에서 패턴을 찾아 클래스 예측 | 문제·데이터·테스트 설계, 실패 해석, 사용 여부 판단 |
| 공공데이터 분석 | 정리·계산·시각화·관계 탐색 지원 | 질문·출처·전처리 검증, 사실·해석·인과 구분 |
| 생성형 AI 협업 | 검색어·코드·관점·반론·초안 생성 | 목적과 맥락 제공, 원자료 확인, 수정·거부·결정 |
| 서비스 기획 | 기능·시나리오·위험 후보 확장 | 사용자와 문제 선택, 역할·데이터·안전·책임 설계 |

## 최종 프로젝트를 다시 봅니다

- 처음의 문제 가설은 데이터 분석 후 어떻게 달라졌는가?
- 가장 중요한 인사이트는 무엇이며 어디까지 말할 수 있는가?
- 문제 확인 데이터와 AI 학습·입력·운영·평가 데이터를 구분했는가?
- AI가 반드시 필요한 기능과 더 단순한 방법이 나은 기능은 무엇인가?
- 도움을 받는 사람과 피해를 볼 수 있는 사람은 누구인가?
- 결과를 확인·수정·거부하거나 이의를 제기할 수 있는가?
- 최종 판단과 책임은 누구에게 있는가?

<Callout kind="reflect" title="학기 첫 답과 비교하기">처음에는 AI를 무엇이라고 생각했나요? 지금은 AI가 잘하는 일, 한계, 사람의 역할을 어떻게 설명할 수 있나요? 생각이 바뀐 계기가 된 실험·데이터·피드백을 근거로 답합니다.</Callout>

<Callout kind="reflect" title="AI와 함께 나도 성장했는가?">
AI 덕분에 더 빠르게 만든 결과만 나열하지 않습니다. 이제 내가 직접 설명할 수 있는 개념, 새롭게 분해할 수 있게 된 문제, 발견하고 수정한 AI의 오류, 다음에는 스스로 먼저 시도할 수 있는 일을 구체적인 사례로 씁니다.

**“AI가 무엇을 해주었는가?”와 함께 “그 과정에서 나는 무엇을 할 수 있게 되었는가?”를 답합니다.**
</Callout>

<Callout kind="concept" title="이 과목의 마지막 문장">AI는 강력한 엔진이 될 수 있지만 방향을 정하는 운전자는 사람입니다. AI가 더 많은 일을 할수록 사람에게는 **좋은 질문을 만들고, 문제를 작은 단위로 나누며, 데이터와 맥락을 연결하고, 결과를 설명·검증하고, 가치와 영향을 판단하며, 최종 결정을 책임지는 능력**이 더 중요해집니다. AI와 함께 더 많은 것을 만드는 동안 사람도 함께 성장해야 합니다.</Callout>
