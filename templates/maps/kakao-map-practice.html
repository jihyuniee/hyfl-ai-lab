카카오맵 · 지도와 마커 연습

가상 연습 위치 3곳입니다. 실제 자료가 아닙니다.
먼저 지도와 마커 클릭을 확인하고, 출처가 있는 우리 팀의 실제 위치 자료로 교체하세요.

  1. 카카오디벨로퍼스의 내 앱에서 카카오맵 → 사용 설정 → ON을 확인하세요.
  2. 앱 → 플랫폼 키 → JavaScript 키 → JavaScript SDK 도메인에 실제 웹앱 주소를 등록하세요. localhost를 쓴다면 http://localhost:8080처럼 실행 포트도 맞추세요.
  3. 파일 아래의 JavaScript 코드에서 javascriptKey 설정값을 본인의 JavaScript 키로 바꾸고, 저장한 파일을 같은 주소에 다시 배포하세요. REST API 키·어드민 키·Client Secret은 넣지 않습니다.

이 시작 예제는 HTTP(S) 웹 서버에서 실행하도록 만들었습니다. 파일을 더블클릭한 file:// 화면에서는 안내만 표시합니다. 등록한 localhost 서버나 실제 HTTPS 웹앱 주소에서 여세요.

지도 실행 조건을 확인하고 있습니다.
