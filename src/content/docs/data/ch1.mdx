School Image Lab에서는 우리가 데이터를 모아 모델을 학습시켰습니다. 이제는 생성형 AI가 공공기관의 데이터 도구를 직접 사용하도록 연결하고, 현실과 사회의 문제를 탐색합니다.

<Callout kind="mission" title="오늘의 미션">공공기관 MCP를 생성형 AI에 연결하고, 일상적인 질문을 공식 데이터 조회가 가능한 질문으로 바꾸어 결과의 출처·기간·단위를 확인합니다.</Callout>

## 데이터 활용 방식이 달라지고 있습니다

예전에는 공공데이터를 사용하려면 사람이 포털에서 파일을 찾거나, API 키를 발급받아 코드에 연결해야 했습니다. 이제 MCP를 지원하는 생성형 AI에서는 질문을 이해한 AI가 필요한 도구를 선택하고, 공공기관 데이터를 조회한 뒤 표와 설명으로 정리할 수 있습니다.

```text
이전: 데이터 검색 → CSV·XLSX 다운로드 → 정리 → 코드 작성 → 그래프

API 활용: API 키 발급 → 요청 코드 작성 → 응답 가공 → 분석·그래프

MCP 활용: 일상어 질문 → AI가 적절한 도구 선택 → 공식 데이터 조회
          → 표·비교·그래프 요청 → 사람이 출처와 해석 검증
```

<Callout kind="concept" title="MCP는 AI를 위한 공통 연결 규칙입니다">
MCP(Model Context Protocol)는 생성형 AI가 외부의 데이터와 기능을 일정한 방식으로 사용할 수 있게 만든 연결 규칙입니다. MCP 서버는 AI 자체도, 데이터 파일 자체도 아닙니다. **AI가 사용할 수 있는 검색·조회 기능을 설명하고 실행해 주는 도구함**에 가깝습니다.
</Callout>

## API와 MCP는 무엇이 다를까?

| API를 직접 사용할 때 | MCP로 AI가 도구를 사용할 때 |
| --- | --- |
| 사람이 문서를 읽고 API를 선택한다 | AI가 질문에 맞는 도구를 선택한다 |
| 키·URL·요청 변수를 코드에 작성한다 | 일상어로 대상·기간·지역·지표를 요청한다 |
| 응답 데이터를 코드로 가공한다 | AI가 조회 결과를 표나 설명으로 정리한다 |
| 사람은 코드와 결과를 검증한다 | 사람은 질문·출처·조건·결과·해석을 검증한다 |

MCP가 API를 없앤 것은 아닙니다. MCP 서버 안에서는 여러 API가 실제 데이터를 가져오는 데 사용될 수 있습니다. 달라진 점은 **사람이 모든 호출 과정을 직접 코딩하지 않아도 AI가 적절한 도구를 사용할 수 있다는 것**입니다.

## 연결해 볼 공공데이터 도구

| MCP | 탐색할 수 있는 내용 | 서버 주소 |
| --- | --- | --- |
| KOSIS | 인구·교육·경제·복지·환경 등 국가통계 | `https://kosismcp2026.vercel.app/api/mcp` |
| HRDKorea | 국가자격·시험·합격률·NCS·해외취업 정보 | `https://openapi.hrdkorea.or.kr/mcp` |

생성형 AI의 `설정 → 커넥터 → 커스텀 커넥터 추가`에서 수업 주제에 맞는 서버 주소를 등록합니다. 무료 계정의 연결 개수나 메뉴 위치는 서비스 정책에 따라 달라질 수 있습니다. 연결되지 않을 때는 팀 대표 기기에서 실습하거나 기존 포털 검색과 파일 다운로드 방식으로 진행합니다.

<Callout kind="caution" title="주소는 공식 안내에서 확인합니다">MCP 서버는 AI가 외부 기능을 실행하는 통로입니다. 출처를 알 수 없는 주소를 임의로 추가하지 않습니다. 이 수업에서는 교사가 안내한 공공기관 MCP만 사용하고, 개인정보·학교 내부 자료·API 키는 입력하지 않습니다.</Callout>

## 첫 질문을 데이터 질문으로 바꾸기

`청소년 문제가 심각해졌어?`처럼 범위가 넓은 질문은 어떤 통계를 조회해야 할지 불분명합니다. 다음 네 가지를 넣어 질문을 구체화합니다.

> **대상 + 기간 + 지역·집단 + 확인할 지표**

| 막연한 질문 | 조회 가능한 질문 |
| --- | --- |
| 학생 수가 줄었어? | 최근 10년간 서울의 고등학교 학령인구는 어떻게 변했는가? |
| 청년 취업이 어려워? | 최근 5년간 20~29세 고용률은 성별로 어떻게 달라졌는가? |
| 어떤 자격증이 좋아? | 정보 분야 국가기술자격의 최근 응시자 수와 합격률은 어떻게 다른가? |

## MCP 실습

<Steps>
<Step title="도구 확인">연결한 MCP가 제공하는 기능을 분야별로 설명해 달라고 요청합니다.</Step>
<Step title="첫 조회">대상·기간·지역·지표를 포함한 질문으로 공식 데이터를 조회합니다.</Step>
<Step title="조건 바꾸기">기간·지역·집단·비율 중 하나만 바꾸어 결과가 어떻게 달라지는지 비교합니다.</Step>
<Step title="근거 요청">사용한 통계표·제공 기관·기준 시점·단위·조회 조건을 함께 제시하게 합니다.</Step>
<Step title="공식 화면 확인">최종 주장에 사용할 핵심 수치 두 개 이상을 기관의 원 통계표나 공식 페이지에서 다시 확인합니다.</Step>
<Step title="말할 수 없는 것 찾기">현재 자료로 알 수 없는 원인과 추가로 필요한 데이터를 구분합니다.</Step>
</Steps>

```text
[연결한 MCP 이름]의 도구를 사용해 다음 질문에 필요한 공식 데이터를 찾아줘.

질문: [대상·기간·지역·지표가 포함된 질문]

1. 먼저 어떤 통계나 도구를 사용할지 알려줘.
2. 결과를 연도별 표로 정리해줘.
3. 제공 기관, 통계표 이름, 기준 시점, 단위, 조회 조건을 표시해줘.
4. 데이터에서 직접 확인한 사실과 가능한 해석을 구분해줘.
5. 이 데이터만으로 알 수 없는 원인은 따로 표시해줘.
6. 내가 원 통계표에서 다시 확인할 핵심 수치를 골라줘.
```

## 이제 CSV와 엑셀은 필요 없을까?

**항상 먼저 내려받을 필요는 없어졌지만, 완전히 필요 없어진 것은 아닙니다.** 목적에 따라 선택합니다.

| MCP만으로 충분한 경우 | 원파일이 필요한 경우 |
| --- | --- |
| 통계 존재 여부와 큰 흐름을 빠르게 탐색할 때 | 결측치·중복·이상치를 직접 확인할 때 |
| 단순한 연도·지역·집단 비교를 할 때 | 여러 파일을 결합하거나 새로운 변수를 계산할 때 |
| 문제 가설을 세우거나 수정할 때 | AI의 계산과 그래프를 같은 절차로 재현해야 할 때 |
| 공식 수치를 표로 정리할 때 | 원하는 그래프나 세부 분석을 직접 통제해야 할 때 |

프로젝트에서는 **MCP로 넓게 탐색하고 → 핵심 수치를 원 통계표에서 확인하고 → 필요한 팀만 파일을 내려받아 깊이 분석**합니다. 도구 사용 자체보다 질문에 맞는 근거를 선택하고 검증하는 것이 목적입니다.

<Callout kind="checklist" title="MCP 결과 검증 카드">
- 어떤 MCP와 어떤 조회 기능을 사용했는가?
- 데이터 제공 기관과 통계표 이름은 무엇인가?
- 대상·기간·지역·단위가 질문과 맞는가?
- AI가 표에 없는 값이나 설명을 덧붙이지 않았는가?
- 핵심 수치를 원 통계표에서 다시 확인했는가?
- 사실·해석·원인 가설을 구분했는가?
- 이 자료로 말할 수 없는 범위를 밝혔는가?
</Callout>

<Callout kind="concept" title="사람의 역할이 사라진 것이 아니라 이동했습니다">직접 API 호출 코드를 작성하는 부담은 줄어들 수 있습니다. 대신 사람은 더 좋은 질문을 만들고, AI가 선택한 데이터와 조건을 살피며, 공식 근거를 확인하고, 결과의 의미와 한계를 판단해야 합니다.</Callout>
