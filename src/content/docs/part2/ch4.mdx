설명을 더 외우기 전에 작은 이미지 분류 모델을 직접 가르쳐봅니다. 목표는 높은 정확도가 아니라 **모델이 언제, 왜 실패하는지 발견하는 것**입니다.

<Callout kind="mission" title="개인 실험">
서로 구분할 두 가지 클래스를 정하고 이미지를 모아 학습시킨 뒤, 학습할 때와 다른 사람·배경·거리·각도·조명에서 테스트하세요.
</Callout>

<Steps>
<Step title="두 클래스 정하기">사진만 보아도 기준을 일관되게 적용할 수 있는 두 범주를 정합니다.</Step>
<Step title="데이터 모으기">각 클래스의 이미지를 비슷한 수로 수집합니다. 얼굴 등 개인정보가 포함되면 당사자의 동의를 먼저 받습니다.</Step>
<Step title="첫 모델 학습">도구에 두 클래스의 이미지를 넣고 학습합니다. 이 결과가 출발점입니다.</Step>
<Step title="익숙한 조건에서 테스트">학습할 때와 비슷한 사람·배경·거리·조명에서 확인합니다.</Step>
<Step title="새로운 조건에서 테스트">다른 사람·배경·거리·각도·조명으로 조건을 하나씩 바꿉니다.</Step>
<Step title="일부러 틀리게 만들기">무엇을 바꾸면 예측이 흔들리는지 찾아 실패 사례를 기록합니다.</Step>
<Step title="데이터 개선 후 재학습">실패 원인을 추측하고 필요한 다양성을 추가한 뒤 같은 조건에서 다시 비교합니다.</Step>
</Steps>

## 관찰할 것

- 예측 클래스와 표시된 확률
- 바꾼 조건과 결과 변화
- 모델이 실제 대상이 아니라 배경·색·위치 같은 엉뚱한 단서를 본 흔적
- 개선 전후에 **같은 테스트 조건**을 사용했는지

<Callout kind="caution" title="확률을 확신으로 읽지 않기">
화면의 95%는 모델이 현실에서 95% 정확하다는 뜻이 아닙니다. 현재 입력에 대해 모델이 각 클래스에 부여한 상대적 점수에 가깝습니다. 실제 성능은 학습에 쓰지 않은 다양한 데이터로 따로 확인해야 합니다.
</Callout>

<Callout kind="concept" title="AI와 사람의 역할">
**AI**는 주어진 이미지에서 학습한 패턴으로 결과를 냅니다.<br />
**사람**은 구분 기준과 데이터를 정하고, 테스트 조건을 설계하며, 실패 원인을 해석하고 실제 사용 여부를 판단합니다.
</Callout>
