7. DATA TO WEB APP

데이터를 살펴보면 익숙한 상황에서도 새로운 질문이 생깁니다. 이 프로젝트에서는 우리 팀이 해결하고 싶은 문제를 찾고, 자료에서 얻은 발견을 사람들이 직접 활용할 수 있는 웹 서비스로 만들어 갑니다.

이 프로젝트의 목표는 아이디어를 말로만 발표하는 것이 아닙니다. 수업이 끝났을 때 다음 여섯 가지가 남아야 합니다.

문제 정의를 하면서 데이터를 찾을 수도 있고, 분석을 하다가 새로운 인사이트를 얻어 문제 정의를 바꿀 수도 있습니다. 탐구는 직선이 아니라 여러 번 되돌아가는 과정입니다.

문제 정의 ↔ 도메인 지식 탐색 ↔ 데이터 수집 ↔ 분석 → 인사이트 → AI 서비스 설계 → 구현 → 검증·발표

🎯 이번 프로젝트의 미션

재미있고 흥미로운 문제에서 출발하되, 실제 데이터와 AI 활용을 통해 근거 있는 인사이트를 만들고, 최소 하나의 작동하는 웹 서비스로 구현합니다.

📚 한 학습지에 이어 쓰기

공통 실습에서 시작한 프로젝트 통합 학습지를 끝까지 사용합니다. 팀이 이야기하고 시도한 뒤, 중요한 발견과 결정만 해당 부분에 기록합니다. 생각이 달라진 곳에는 날짜와 이유를 덧붙입니다.

1. 프로젝트 산출물 확인하기

섹션 제목: “1. 프로젝트 산출물 확인하기”

완성된 프로젝트는 멋진 화면 하나만으로 판단하지 않습니다. 문제를 이해하고, 데이터를 확인하고, AI를 활용해 분석·설계·구현을 반복한 과정이 함께 보여야 합니다.

데이터 수집 기록출처, 기간, 지역, 단위, 행의 의미, 수집 또는 조회 방법
분석 결과표·그래프·계산 기준, 원자료 대조, 사실과 해석의 구분

☑️ 최소 완성 기준

최소 기능 하나는 실제로 작동해야 합니다. 예를 들어 파일을 읽고 조건에 맞는 결과를 보여 주거나, 사용자의 선택에 따라 데이터 근거를 보여 주는 기능이 있어야 합니다. 더 복잡한 AI 모델이나 API 연결은 선택 확장입니다.

3. 도메인 지식 만들기

섹션 제목: “3. 도메인 지식 만들기”

어떤 분야를 잘 모르면 좋은 질문을 만들기 어렵습니다. 그래서 프로젝트 초반에는 주제를 바로 확정하지 않고, 그 분야의 기본 배경지식을 빠르게 만듭니다.

도메인 지식은 전문가가 되는 것이 아닙니다. 그 분야의 말, 사람, 자료, 기준, 오해를 알아가며 질문을 더 정확하게 만드는 과정입니다.
