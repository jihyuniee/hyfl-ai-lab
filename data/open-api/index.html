6. 데이터가 나오는 주소 읽기

DATA EXPLORATION · OPEN API
오늘의 질문웹앱은 공공데이터를 어떻게 직접 가져올까?

지난 시간에는 KOSIS MCP로 국가통계를 찾고 원자료와 비교했습니다. 이번 시간에는 Open API 주소로 생활 데이터를 요청하고, 응답으로 받은 JSON 값이 웹앱의 화면 요소로 이어지는 과정을 살펴봅니다.

🎯 오늘의 미션

NEIS 급식 API 요청 주소를 만들고 브라우저에서 JSON 응답을 확인합니다. 응답에서 메뉴, 날짜, 칼로리 값을 찾아 기록하고, 이 값이 어떤 앱 기능으로 이어질 수 있는지 정리합니다.

📚 먼저 예상하기

날짜를 바꾸면 어떤 값이 달라질지, 학교 코드를 바꾸면 어떤 값이 달라질지 먼저 예상합니다. 예상한 뒤 API 주소를 실행해 실제 응답과 비교합니다.

1. Open API는 데이터가 나오는 주소입니다

섹션 제목: “1. Open API는 데이터가 나오는 주소입니다”

Open API는 기관이 정한 주소와 조건값을 사용해 데이터를 요청하는 방법입니다. 웹앱은 사용자가 입력한 값을 API 주소의 조건값으로 넣고, 서버가 보내 준 응답 데이터에서 필요한 항목을 골라 화면에 보여 줍니다.

수업에서 보는 것뜻급식 API 예시
요청 주소데이터를 달라고 보내는 주소급식식단정보 API 주소
조건값어떤 데이터를 받을지 정하는 값학교 코드, 날짜, 식사 코드
JSON 응답서버가 보내 주는 데이터학교명, 메뉴, 칼로리정보
웹앱 화면필요한 값을 보기 좋게 보여 주는 곳오늘의 급식 카드, 메뉴 검색 결과

JSON은 반정형 데이터입니다. 이름표와 값이 묶여 있고, 여러 묶음이 계층적으로 들어갈 수 있습니다. 앱은 이름표를 기준으로 필요한 값을 찾아 화면에 표시합니다.

위 값은 구조를 읽기 위한 예시입니다. 실제 학교·날짜의 값은 직접 조회한 응답에서 확인합니다.

2. API 키와 요청값 확인하기

섹션 제목: “2. API 키와 요청값 확인하기”

오늘 예시는 NEIS 교육정보 개방 포털의 급식식단정보입니다. 포털은 현재년도 급식 자료를 제공한다고 안내합니다. 실제 조회 가능한 범위는 원문과 응답에서 확인합니다. 이 자료는 학교 급식의 요리명, 원산지정보, 칼로리정보, 영양정보 등을 일자별로 제공합니다.

  • 원자료: NEIS 급식식단정보

🧑‍🏫 수업용 인증키

수업용 인증키는 교사가 안내한 비공개 공간에서 확인합니다. 공개 교과서와 공개 저장소에는 실제 인증키 대신 수업용_인증키 같은 자리표시자를 사용합니다.

급식 API 요청에 자주 쓰는 값은 다음과 같습니다.

값의미예시
KEYAPI 인증키수업용 인증키
Type응답 형식json
pIndex페이지 번호1
pSize한 번에 받을 개수100
ATPT_OFCDC_SC_CODE시도교육청 코드B10
SD_SCHUL_CODE학교 코드7010259
MLSV_YMD급식일자20210222

API 키는 제공 기관이 발급하는 인증값입니다. 발급받은 키를 요청 주소의 KEY= 뒤에 넣으면 서버가 요청자를 확인하고 데이터를 보내 줍니다. 시도교육청 코드와 학교 코드는 NEIS 포털의 학교기본정보 서비스, 제공 기관의 코드 안내, 수업용 예시 자료에서 확인할 수 있습니다.

3. 요청 주소 만들고 실행하기

섹션 제목: “3. 요청 주소 만들고 실행하기”

아래 프롬프트를 복사한 뒤 빨간 부분을 수업에서 사용할 값으로 바꿉니다. 생성형 AI에는 실제 인증키 대신 YOUR_API_KEY를 제공합니다. 받은 주소의 자리표시자는 교사가 안내한 실습 환경에서 직접 바꿔 실행합니다.

급식 API 요청 주소 만들기 프롬프트 표시된 부분을 우리 팀의 내용으로 바꾸세요.
프롬프트 구조와 각 부분이 필요한 이유 보기

역할·프로젝트 맥락은 AI가 어떤 관점에서 어느 팀의 문제를 다루는지 정합니다.

과업·필수 기능은 만들어야 할 결과와 빠뜨리면 안 되는 동작을 정합니다.

화면·디자인·기술 조건은 실제 사용자와 실행 환경의 제약을 전달합니다.

오류 처리·검증 기준은 실패했을 때의 안내와 완성 여부를 판단하는 기준입니다.

NEIS 급식식단정보 API 요청 주소를 만들려고 해.

기본 주소:
https://open.neis.go.kr/hub/mealServiceDietInfo

바꿀 값:
- 인증키: YOUR_API_KEY (자리표시자를 유지)
- 시도교육청코드: {{예: B10}}
- 학교코드: {{예: 7010259}}
- 급식일자: {{현재 제공 범위에서 조회할 날짜, YYYYMMDD}}
- 식사코드: {{선택, 예: 2 / 모르면 비워 두기}}

고정할 값:
- Type=json
- pIndex=1
- pSize=100

위 값을 사용해서 브라우저 주소창에 붙여 넣을 수 있는 전체 API 요청 주소를 만들어줘.
실제 인증키는 넣지 말고 YOUR_API_KEY를 유지해줘. 받은 주소의 자리표시자는 내가 직접 바꿔 실행할게.
그리고 내가 바꾼 값이 무엇을 의미하는지 표로 정리해줘.

AI가 만들어 준 요청 주소는 다음과 같은 구조입니다.

주소에서 ? 뒤에는 조건값이 이어지고, 여러 조건은 &로 연결됩니다. 조건은 이름=값 형태로 씁니다.

바꿔 볼 값예시확인할 변화
날짜MLSV_YMD=조회할다른날짜다른 날짜의 메뉴가 나오는지 확인
페이지 크기pSize=5, pSize=100한 번에 받는 기록 수 확인
식사 코드MMEAL_SC_CODE=2중식 자료만 나오는지 확인
학교 코드SD_SCHUL_CODE=…다른 학교의 급식 자료 확인

4. JSON 응답에서 받은 값 찾기

섹션 제목: “4. JSON 응답에서 받은 값 찾기”

요청 주소를 브라우저 주소창에 붙여 넣고 실행하면 JSON 응답이 보입니다. 처음에는 전체 구조보다 아래 값을 먼저 찾습니다.

확인할 값JSON에서 찾을 이름표내가 확인한 값
정상 처리 여부RESULT.MESSAGE
학교명SCHUL_NM
급식일자MLSV_YMD
식사명MMEAL_SC_NM
메뉴DDISH_NM
칼로리정보CAL_INFO
영양정보NTR_INFO

아래는 응답 구조를 설명하기 위한 편집 예시입니다. 메뉴와 수치를 실제 조회 결과로 사용하지 않습니다. 실습 날짜는 현재 조회 가능한 날짜로 정합니다.

JSON 부분뜻급식 응답에서 보는 방법
head응답 상태 정보전체 개수, 정상 처리 여부 확인
row실제 데이터 목록학교명, 날짜, 메뉴, 칼로리 확인
하나의 묶음한 건의 급식 기록
[ ]여러 개의 묶음여러 날짜 또는 여러 식사 기록
“이름”: “값”항목 이름과 실제 값“SCHUL_NM”: “한영외국어고등학교”

예시의 정상 응답에서는 mealServiceDietInfo → head → RESULT에 처리 상태가, row에 급식 기록이 있습니다. 데이터 없음·오류 응답에서는 실제 구조와 CODE·MESSAGE를 먼저 확인합니다.

row 안에 실제 급식 데이터가 들어 있습니다. DDISH_NM 안의 <br/>는 줄바꿈 표시입니다. 앱은 이 표시를 기준으로 메뉴를 줄마다 나누어 보여 줄 수 있습니다.

화면·디자인·기술 조건은 실제 사용자와 실행 환경의 제약을 전달합니다.

오류 처리·검증 기준은 실패했을 때의 안내와 완성 여부를 판단하는 기준입니다.

아래 NEIS 급식 API 응답 JSON에서 실제 값을 찾아 표로 정리해줘.

요청 주소:
{{KEY 값을 YOUR_API_KEY로 바꾼 요청 주소}}

응답 JSON:
{{브라우저에 나온 JSON 일부 붙여 넣기}}

찾을 값:
1. 정상 처리 여부
2. 학교명
3. 급식일자
4. 식사명
5. 메뉴
6. 칼로리정보
7. 영양정보

메뉴는 <br/> 기준으로 줄을 나누어 정리해줘.

5. 받은 값을 앱 기능으로 연결하기

섹션 제목: “5. 받은 값을 앱 기능으로 연결하기”

API 응답에서 찾은 값은 웹앱의 화면 요소가 됩니다.

JSON 항목앱 화면에서 보이는 모습
MLSV_YMD급식 날짜
MMEAL_SC_NM조식, 중식, 석식 표시
DDISH_NM메뉴 목록과 알레르기 번호
CAL_INFO칼로리 정보
NTR_INFO영양정보
RESULT.CODE정상 처리, 데이터 없음, 오류 안내

같은 급식 API를 사용해도 만들 수 있는 앱은 달라집니다.

내가 만들고 싶은 기능화면에서 입력할 값주로 사용할 응답 항목
특정 메뉴가 나온 날 찾기메뉴 이름DDISH_NM, MLSV_YMD
칼로리 높은 날 찾기칼로리 기준CAL_INFO, MLSV_YMD
알레르기 번호 찾기알레르기 번호DDISH_NM
날짜별 영양정보 보기날짜 또는 기간NTR_INFO, MLSV_YMD

6. 다음 시간 준비하기

섹션 제목: “6. 다음 시간 준비하기”

다음 시간에는 오늘 확인한 API 키와 JSON 항목을 사용해 작은 HTML 웹앱을 만듭니다. 오늘 기록한 값 중 하나를 골라 앱 기능으로 바꿔 봅니다.

준비할 것예시
만들고 싶은 기능메뉴 이름 검색, 칼로리 기준 검색, 알레르기 번호 검색
사용자가 입력할 값메뉴 이름, 칼로리 기준, 알레르기 번호, 날짜
화면에 보여 줄 값날짜, 식사명, 메뉴, 칼로리정보, 영양정보
확인 방법브라우저 JSON 원문과 앱 화면 결과 비교

⚠️ API 키 관리

실제 API 키가 들어간 주소와 HTML 파일은 공개 게시물, 공개 GitHub 저장소, 공개 GitHub Pages에 올리지 않습니다. 수업 실습에서는 교사가 안내한 범위에서 사용하고, 공개 코드에 키를 자리표시자로 바꾸면 그 상태로는 인증 요청이 실행되지 않습니다. 실제 키를 보호하면서 공개 실행하려면 서버 연결 등 적용할 방법을 선생님과 확인합니다.

🎟️ 오늘의 정리

Open API는 조건값을 넣어 데이터를 요청하는 주소입니다. JSON 응답에서 필요한 값을 찾으면 날짜 선택, 메뉴 검색, 칼로리 표시, 알레르기 번호 확인 같은 웹앱 기능으로 연결할 수 있습니다.
