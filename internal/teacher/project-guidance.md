# 교사용 참고: 프로젝트 설계와 AI 연결

이 문서는 수업 설계·운영 참고입니다. 학생용 웹교과서 페이지로 빌드하지 않습니다. 저장소는 공개되어 있으므로 학생 정보·비밀키·개인 결제 정보는 적지 않습니다.

## 학생 안내와 교사 관찰을 구분하기

학생 안내는 질문·선택·실행·검증을 돕는 언어로 작성합니다. 역량명을 직접 써 내거나 기록을 위한 성취를 연출하도록 요구하지 않습니다. 교사는 실제 과정에서 다음과 같은 판단과 변화를 관찰합니다. 아래 내용은 새 채점표나 추가 제출물이 아닙니다.

| 교육적 의도 | 관찰할 실제 과정 | 기존 활동지 연결 |
| --- | --- | --- |
| 문제해결력 | 문제를 좁히고 실행 결과에 따라 방법을 바꾸는가 | STEP 1·2·3 |
| AI 리터러시 | AI에 맥락을 주고 답변·코드를 확인하여 채택·수정·제외하는가 | STEP 2-4·4 |
| 데이터 리터러시 | 출처·단위·기록 단위·기간을 읽고 분석과 기능을 연결하는가 | STEP 2·3 |
| 공동체 역량 | 사용자의 필요를 이해하고 팀과 협력하며 실제 도움과 한계를 확인하는가 | STEP 1·3·5 |

세특 등 기록은 관찰한 활동과 판단에 근거합니다. 예상되는 효과를 실제 성과로 적거나, 기능의 복잡도와 API 사용 자체를 성취로 간주하지 않습니다. 학생별 선택·수정·검증 사례에서 성장을 찾습니다.

## AI 기능의 범위

핵심은 기존 데이터 웹앱 완성입니다. AI 기능은 기본 앱을 완성한 팀이 필요할 때 선택하며, 공용 연결 서버는 현재 준비 전입니다. 학생은 공개 자료·화면·질문·검증에 집중합니다. 서버 구축과 인증·과금 관리는 교사의 운영 준비 항목입니다. 기존 수업 일정과 STEP·제출·평가 기준은 유지합니다.

## 서버 준비 시 교사가 확인할 것

- 제공사 비밀 API 키는 서버 환경변수 또는 비밀 저장소에서 관리합니다. 학생 HTML·JavaScript·GitHub·AI 대화에 전달하지 않습니다.
- 이용자 인증, 팀별 누적 요청/비용 한도, 입력·출력 길이, 사용 기간, 차단 기능을 서버에서 적용합니다. CORS·허용 도메인·화면 버튼 제한은 인증과 비용 통제의 대체 수단이 아닙니다.
- 관련 공개 자료만 전송하며 개인정보는 받지 않습니다. 원자료와 AI 설명을 구분하고, 근거 부족·연결 실패·한도 도달 때 기본 앱이 계속 작동하도록 합니다.
- 연결 주소·요청/응답 형식·인증 방법·허용 모델·사용 범위가 확정된 뒤 해당 팀에 안내합니다. 서비스가 준비되기 전에는 연결을 보장하지 않습니다.
- 실제 유료 호출과 공개 운영 전에 승인된 범위, 계정 설정과 제공사 공식 문서를 확인합니다. 키 생성·권한 부여는 별도 승인 절차를 따릅니다.

## 기존 시작 파일을 계속 사용하는 경우

`examples/ai-chatbot-starter/` 및 `public/templates/ai-chatbot-starter.zip`의 예제는 보존합니다. 현재 앱과 압축을 푼 예제를 함께 AI에 제공해 기존 기능을 유지하며 합치는 흐름을 사용할 수 있습니다. 이 예제는 교사 공용 서비스나 팀별 누적 할당량 시스템이 아닙니다.

기존 예제는 Vercel에서 화면과 서버를 함께 실행합니다. 교사가 `examples/ai-chatbot-starter/README.md`와 현재 배포 설정을 확인한 뒤 적용합니다. 기존 안내의 환경변수는 다음과 같으며, 실제 값은 문서에 넣지 않습니다.

| 변수 | 용도 |
| --- | --- |
| AI_PROVIDER | openai 또는 anthropic |
| AI_MODEL | 사용할 모델 식별자 |
| OPENAI_API_KEY | OpenAI 비밀키 |
| ANTHROPIC_API_KEY | Anthropic 비밀키 |
| CHAT_ACCESS_CODE | 예제 앱 이용코드, 제공사 키와 별개 |

서버 설정과 과금 통제를 확인한 뒤 시험합니다. 예제의 이용코드만으로 광범위한 공개 운영과 팀별 비용 통제가 완성되는 것은 아닙니다.
