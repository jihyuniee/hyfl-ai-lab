## 생각을 여는 질문

<Callout kind="question">
예전에는 이미지 분류 AI, 번역 AI, 데이터 분석 도구가 따로 있는 느낌이었는데, 왜 요즘은 ChatGPT 같은 AI 하나가 거의 모든 일을 해주는 것처럼 느껴질까요?
</Callout>

이번 시간에는 바로 이 질문을 풀어봅니다.

## 먼저 중요한 구분

ChatGPT 같은 서비스의 중심에는 **대규모 언어 모델(LLM)**이 있습니다. LLM은 딥러닝 기반의 언어 모델로, 아주 많은 텍스트에서 언어의 패턴을 학습합니다.

하지만 오늘날 우리가 사용하는 AI 서비스 전체를 단순히 “LLM 하나”라고 생각하면 부족합니다.

<Callout kind="concept" title="모델과 서비스는 다르다">
LLM은 핵심 모델이고, 실제 AI 서비스는 그 모델에 이미지 이해, 파일 처리, 검색, 코드 실행, 외부 도구 사용 같은 기능이 연결된 더 큰 시스템일 수 있습니다.
</Callout>

## LLM은 어떻게 문장을 만들까?

LLM은 입력 문장을 **토큰(token)**이라는 작은 단위로 나누고, 지금까지의 문맥을 바탕으로 다음 토큰이 무엇일지 확률적으로 계산하며 결과를 만들어갑니다.

<FlowDiagram items={[{ ko: '입력' }, { ko: '토큰으로 나누기' }, { ko: '문맥 처리' }, { ko: '다음 토큰 예측' }, { ko: '반복하여 결과 생성' }]} />

이 과정은 단순해 보이지만, 매우 큰 규모의 데이터와 모델에서 학습되면 설명, 요약, 번역, 글쓰기, 코드 생성, 아이디어 확장처럼 다양한 언어 기반 작업을 수행할 수 있게 됩니다.

## 왜 언어 모델이 이렇게 많은 일을 할 수 있을까?

우리가 하는 많은 지적 작업은 언어와 연결되어 있습니다.

- 문제를 설명하기
- 정보를 정리하기
- 비교하기
- 계획 세우기
- 코드를 작성하기
- 기준을 만들기
- 아이디어를 확장하기
- 결과를 설명하기

그래서 언어를 폭넓게 다루는 모델은 자연스럽게 매우 다양한 작업의 입구가 될 수 있습니다.

## 여기에 멀티모달 능력이 붙었다

최근의 AI는 텍스트만 다루지 않습니다. 이미지, 음성, 영상 등 여러 형태의 정보를 함께 이해하는 방향으로 발전하고 있습니다. 이런 능력을 **멀티모달(multimodal)**이라고 합니다.

예를 들어 하나의 AI 서비스에서 다음과 같은 일이 가능할 수 있습니다.

- 사진을 보고 내용 설명하기
- 표가 담긴 이미지를 읽고 분석하기
- 음성을 듣고 요약하기
- 글과 이미지를 함께 참고해 답하기

즉, AI에게 들어가는 정보의 종류가 훨씬 넓어진 것입니다.

## 그리고 도구를 사용할 수 있게 되었다

오늘날의 AI 시스템은 필요할 때 외부 도구를 사용할 수도 있습니다.

예를 들어 사용자의 목표를 이해한 뒤 상황에 따라

- 검색하기
- 계산하기
- 코드를 실행하기
- 데이터를 분석하기
- 파일을 읽기
- 다른 서비스의 기능을 호출하기

같은 작업을 연결할 수 있습니다.

<FlowDiagram items={[{ ko: '사람의 목표', en: '자연어로 설명' }, { ko: 'AI 모델', en: '이해·추론·생성' }, { ko: '필요한 도구 선택', en: '검색·코드·파일·계산' }, { ko: '결과 통합' }, { ko: '사람의 판단' }]} />

이 때문에 사용자는 여러 프로그램을 각각 직접 다루는 대신 **자연어로 목표를 설명하고 하나의 AI 인터페이스를 통해 여러 작업을 수행하는 경험**을 하게 됩니다.

## 그래서 ‘범용적으로 느껴지는’ 것이다

<Callout kind="concept" title="오늘날 AI가 달라 보이는 이유">
예전에는 특정 문제에 특화된 AI를 각각 사용하는 경험이 많았다면, 오늘날에는 하나의 AI 시스템 안에서 언어·이미지·데이터·코드·도구 사용이 연결되면서 훨씬 다양한 문제를 처리할 수 있게 되었습니다.
</Callout>

다만 이것을 곧바로 **완전한 범용인공지능(AGI)**이라고 부르는 것은 조심해야 합니다. 현재의 AI도 틀릴 수 있고, 실제 상황을 잘못 이해할 수 있으며, 스스로 가치 판단이나 책임을 질 수 없습니다.

## 그렇다면 사람의 역할은 줄어들까?

오히려 질문의 수준이 바뀝니다.

예전에는

> “이 작업을 어떻게 코딩하지?”

가 중요했다면, 이제는 점점

> “내가 해결하려는 진짜 문제는 무엇이지?”
> “AI에게 어떤 일을 맡겨야 하지?”
> “어떤 자료가 필요하지?”
> “이 결과를 믿어도 되나?”
> “잘못되면 어떤 문제가 생기지?”

가 중요해집니다.

<Callout kind="mission" title="이번 학기에서 우리가 연습할 것">
강력한 AI를 사용하는 기술보다 더 중요한 것은 **좋은 문제를 발견하고, AI에게 적절한 역할을 맡기고, 결과를 검증하여 책임 있게 판단하는 능력**입니다.
</Callout>

## 유창함은 정확성의 증거가 아니다

LLM은 문맥에 어울리는 결과를 생성하는 데 매우 능숙하지만, 그 결과가 항상 사실이라는 뜻은 아닙니다. 사실과 다른 내용을 자연스럽게 만들어내는 현상을 **할루시네이션(hallucination)**이라고 합니다.

따라서 AI의 답이 매끄럽다는 이유만으로 믿어서는 안 됩니다.

## 핵심 정리

<Callout kind="concept" title="오늘 기억할 네 문장">
1. LLM은 대규모 언어 데이터를 학습한 딥러닝 기반 언어 모델이다.
2. 오늘날의 AI 서비스는 LLM에 멀티모달 이해와 여러 도구가 연결된 더 큰 시스템일 수 있다.
3. 그래서 하나의 AI가 글, 이미지, 데이터, 코드 등 다양한 문제를 처리하는 것처럼 느껴진다.
4. AI가 강력해질수록 사람에게는 문제 정의, 검증, 판단, 책임의 역할이 더 중요해진다.
</Callout>
