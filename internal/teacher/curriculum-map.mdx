### DATA LAB과 Project 3 설계 메모

DATA LAB에서는 먼저 학급 전체가 같은 공공데이터를 사용해 **질문 → 구조·품질 확인 → 전처리 → 시각화 → 사실과 해석 구분 → 검증 → 인사이트**의 전 과정을 함께 경험합니다. 이후 학생이 관심 분야의 질문으로 확장합니다. 예측 모델은 질문과 데이터가 적절할 때만 선택적으로 사용합니다.

Project 3는 데이터 분석 결과를 억지로 서비스 아이디어의 근거로 사용하는 활동이 아닙니다. **문제 발견 → 대상과 맥락 탐색 → AI 필요성 판단 → 사람과 AI의 역할 설계 → 책임 있는 서비스 기획**의 순서를 따릅니다. 세부 활동지는 실제 주제와 차시에 맞춰 별도 제작하고, 웹앱 구현은 선택·확장 활동으로 둡니다.

## 반영하지 않은 내용

다음처럼 이번 수업 흐름(AI 원리 이해 → 생성형 AI 협업·코딩 → 나만의 AI/웹서비스 제작)에서 벗어나는 단원은 억지로 포함하지 않았습니다.

- 스마트홈·IoT 등 하드웨어 중심 단원
- AI Agent의 심화 이론 (Part 6 Playground의 **선택 활동**으로만 가볍게 다룸)
- 특정 산업 분야별 AI 활용 사례 나열식 단원

교과서의 문장과 그림을 그대로 옮기지 않고, 각 챕터에서 학생 활동과 새로운 설명으로 재구성했습니다.
