11. AI for a Better World

FINAL PROJECT · DESIGN · 6~7차시
오늘의 질문이 문제에서 AI가 할 일과 사람이 판단할 일은 무엇일까?

🎯 AI for a Better World

사람과 사회에 도움이 되는 문제 하나를 선택하고 책임 있는 해결책을 기획하세요. 서비스 기획은 필수, 화면 설계는 권장, 프로토타입과 바이브 코딩은 선택입니다.

  1. 문제와 대상 사용자 확정

    누가 어떤 상황에서 어떤 어려움을 겪는지 구체화합니다.

  2. 원인과 맥락 확인

    관찰·인터뷰·설문·공공데이터·원자료 중 필요한 근거로 내 추측을 점검합니다.

  3. 기존 해결과 빈틈 찾기

    현재 방법이 있는데도 남는 어려움과 그 이유를 설명합니다.

  4. AI 필요성 판단

    AI 없이 더 간단하고 안전하게 해결할 수 없는지 먼저 확인합니다.

  5. 필요한 데이터 설계

    어떤 데이터가 필요하며 동의·대표성·품질·보관 문제는 없는지 검토합니다.

  6. AI의 역할 정하기

    분류·추천·생성·번역·요약·분석·대화 중 문제 해결에 필요한 역할만 선택합니다.

  7. 사람의 역할 정하기

    AI가 결정하면 안 되는 부분, 확인할 사람, 이의 제기와 수정 방법, 최종 책임을 정합니다.

  8. 이용 시나리오 만들기

    사용자 상황 → 입력 → AI가 하는 일 → 결과 → 사람이 확인할 부분 → 기대 변화로 설명합니다.

  9. 위험·공정성·안전 점검

    오류·편향·개인정보·저작권·과도한 의존·악용 가능성과 안전장치를 설계합니다.

  10. 피드백으로 수정

    당사자와 친구의 반론을 받아 문제 정의나 기능을 한 번 이상 수정합니다.

  11. 최종 판단 제시

    만들 가치, AI 사용 범위, 남은 한계를 자신의 근거와 말로 설명합니다.

AI가 정말 필요한지 확인하기

섹션 제목: “AI가 정말 필요한지 확인하기”
  1. 규칙·검색·사람의 안내만으로 더 잘 해결할 수 있는가?
  2. AI를 사용하면 사용자가 구체적으로 무엇을 더 얻는가?
  3. AI가 틀리면 누가 어떤 피해를 입는가?
  4. 필요한 데이터는 적절하고 안전하게 구할 수 있는가?
  5. 사람이 개입하고 결과에 이의를 제기할 방법이 있는가?

AI를 사용하지 않는 편이 더 낫다는 결론도 좋은 문제 해결입니다.
