이 실습에서는 학급 전체가 같은 자료를 사용합니다. 공공데이터를 직접 찾고 내려받아 구조를 확인하고, 정리·시각화·관계 분석·해석·검증의 전 과정을 함께 경험합니다.

<Callout kind="mission" title="공통 미션">교사가 지정한 공공데이터에서 시간에 따른 변화 한 가지와 두 변수의 관계 한 가지를 찾고, 데이터가 말할 수 있는 범위와 말할 수 없는 범위를 설명합니다.</Callout>

## 공공데이터라고 부르는 이유

공공데이터는 공공기관이 업무를 수행하며 생성하거나 관리한 자료 중 국민이 이용할 수 있도록 제공한 데이터입니다. 인터넷에 공개된 모든 자료가 공공데이터인 것은 아닙니다.

자료를 내려받기 전에 다음을 확인합니다.

- 제공 기관과 원자료 링크
- 데이터가 만들어진 목적과 수집 방법
- 대상·지역·기간·갱신일
- 열의 의미와 단위
- 이용 조건과 개인정보 포함 여부

## 실습 도구

| 도구 | 이번 실습에서 할 일 |
| --- | --- |
| 공공데이터포털·기관 포털 | 데이터 검색, 설명 확인, 원파일 다운로드 |
| Google Sheets | 행·열 확인, 정렬·필터, 간단한 계산과 기본 그래프 |
| 생성형 AI의 파일 분석·코드 실행 | 결측치 요약, 전처리 코드, 상관계수·산점도·히트맵·그래프 생성 보조 |
| 활동지 | 질문, 변경 내역, 관찰, 해석, 한계, AI 검증 기록 |

파이썬 문법을 외워 처음부터 코드를 작성하는 것이 목표가 아닙니다. AI가 만든 코드가 **어떤 파일의 어떤 열에 어떤 처리를 했는지 읽고 확인하는 것**이 목표입니다.

## 분석 미션

<Steps>
<Step title="공공데이터 찾기">검색 결과의 요약글만 보지 않고 제공 기관의 설명 페이지와 원파일을 엽니다.</Step>
<Step title="분석 질문 구체화">'늘었을까?'를 대상·기간·지표가 포함된 측정 가능한 질문으로 바꿉니다.</Step>
<Step title="원본 보존하기">원파일과 출처 URL, 내려받은 날짜를 보존하고 분석용 사본을 만듭니다.</Step>
<Step title="구조와 품질 확인">행·열 수, 열 이름, 자료형, 날짜 범위, 결측치·중복값·이상치를 확인합니다.</Step>
<Step title="전처리 결정">질문에 필요한 열을 고르고 자료형·단위·결측값을 처리한 이유와 전후 행 수를 기록합니다.</Step>
<Step title="추이와 비교 시각화">시간 변화는 선그래프, 집단 비교는 막대그래프, 분포는 히스토그램·상자그림처럼 질문에 맞게 고릅니다.</Step>
<Step title="변수 관계 확인">두 수치 변수의 산점도와 상관계수를 확인하고, 여러 변수라면 히트맵으로 후보 관계를 살펴봅니다.</Step>
<Step title="사실을 수치로 쓰기">증감·차이·범위·변동을 기간과 수치를 포함해 씁니다.</Step>
<Step title="해석과 반론 나누기">가능한 설명, 빠진 변수, 다른 설명, 일반화하기 어려운 범위를 구분합니다.</Step>
<Step title="재현하고 검증하기">같은 파일과 절차로 결과를 다시 만들 수 있는지 확인합니다.</Step>
</Steps>

## 상관계수를 읽는 최소 기준

- 1에 가까울수록 두 값이 함께 증가하는 직선 관계가 강합니다.
- -1에 가까울수록 한 값이 증가할 때 다른 값이 감소하는 직선 관계가 강합니다.
- 0에 가깝다고 모든 관계가 없는 것은 아닙니다.
- 상관계수 하나만 보지 말고 산점도와 이상치를 함께 확인합니다.
- 상관관계는 원인을 증명하지 않습니다.

## 이 순간의 AI 활용

```text
이 파일에서 [질문]을 분석하려고 해.
먼저 사용할 열·단위·기간과 결측치 처리 방법을 설명해줘.
그다음 처리 전후 행 수를 보여주고, 질문에 맞는 그래프를 만들어줘.
[열 A]와 [열 B]는 산점도와 상관계수를 함께 제시해줘.
마지막에는 데이터에서 직접 확인한 사실, 가능한 해석, 확인할 수 없는 원인을 구분해 표로 작성해줘.
```

AI에게 한 번에 결과만 요구하면 잘못된 열이나 처리 기준을 사용해도 알아차리기 어렵습니다. **먼저 계획과 처리 내역을 설명하게 하고, 그다음 실행 결과를 받는 이유**가 여기에 있습니다.

<Callout kind="checklist" title="AI 분석 검증표">
- 실제 파일에 있는 열만 사용했는가?
- 기간·대상·단위가 질문과 맞는가?
- 삭제·변경·집계한 값과 이유가 남아 있는가?
- 그래프의 축과 범위가 차이를 과장하거나 숨기지 않는가?
- 상관관계를 인과관계로 바꾸지 않았는가?
- 데이터에 없는 수치·사건·출처를 덧붙이지 않았는가?
- 같은 절차로 결과를 다시 확인할 수 있는가?
</Callout>

<Callout kind="concept" title="사람이 운전대를 잡습니다">AI는 계산·전처리·그래프 제작을 빠르게 돕는 엔진입니다. 질문의 목적을 정하고, 데이터 너머의 맥락을 읽고, 결과의 의미와 가치를 판단하고, 최종 설명을 책임지는 사람은 여러분입니다.</Callout>
