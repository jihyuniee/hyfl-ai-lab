---

이 챕터는 이 수업 전체에서 가장 중요한 챕터입니다.

## 지금 여러분이 하고 있는 것

```
문제  →  AI  →  답  →  제출
```

솔직해집시다. 많은 경우 우리는 이렇게 씁니다. 문제를 AI에게 그대로 던지고, 나온 답을 그대로 가져다 씁니다. 빠르고 편하지만, 이 과정에는 **내 생각이 한 번도 들어가지 않습니다.**

## 이 수업에서 배우려는 것

```
문제  →  내가 생각  →  AI와 대화  →  검토  →  내 생각 추가  →  다시 AI  →  판단  →  결과물
```

차이가 보이나요? 새 흐름에는 '나'가 세 번 등장합니다. **문제를 받았을 때 먼저 스스로 생각하고, AI의 답을 그대로 받아들이지 않고 검토하며, 최종 판단은 내가 내립니다.** AI는 답을 주는 존재가 아니라 **함께 생각하는 상대**가 됩니다.

이건 앞서 배운 할루시네이션과도 연결됩니다. AI가 만들어낸 답이 그럴듯해 보여도 틀릴 수 있다는 걸 알기 때문에, 우리는 더더욱 그 답을 검토하고 판단하는 역할을 손에서 놓으면 안 됩니다.

## 활동 — 같은 질문, 다른 프롬프트

:::tip[함께 해보기]
모둠에서 같은 질문 하나를 정하세요. (예: "청소년 스마트폰 과의존을 줄이는 방법을 알려줘")

**1단계.** 이 질문을 AI에게 그대로 던져서 답을 받아봅니다. 결과를 저장해두세요.

**2단계.** 이번에는 질문을 던지기 전에, 모둠원끼리 먼저 3분 동안 스스로 생각해서 아이디어를 적어봅니다.

**3단계.** 아래처럼 프롬프트에 조건과 맥락을 점점 더 추가하면서 다시 물어보고, 답이 어떻게 달라지는지 비교합니다.

- "청소년 스마트폰 과의존을 줄이는 방법을 알려줘"
- "고등학생이 직접 실천할 수 있는, 스마트폰 과의존을 줄이는 방법을 3가지만 구체적으로 알려줘"
- "우리는 이미 [2단계에서 적은 우리 아이디어]를 생각했어. 이 아이디어의 장단점을 분석하고, 우리가 놓친 부분이 있으면 알려줘"

**4단계.** 세 가지 답을 비교하며 이야기합니다. 프롬프트가 구체적일수록, 그리고 내 생각을 먼저 넣을수록 결과가 어떻게 달라졌나요? 어떤 답이 가장 '우리 것'에 가까웠나요?
:::

## 검토하기 — AI 답을 그대로 믿지 않는 법

AI의 답을 받은 뒤에는 항상 이렇게 질문해보세요.

- 이 답의 **근거**는 뭘까? AI가 실제 자료를 인용했나, 아니면 그럴듯하게 지어낸 것 같은가?
- 내가 이미 알고 있는 사실과 **모순되는 부분**은 없는가?
- 이 답을 **그대로** 쓸 것인가, 내 상황에 맞게 **고쳐서** 쓸 것인가?

## 정리

- 문제를 AI에게 던지고 답을 그대로 받는 것이 아니라, 내 생각 → AI와 대화 → 검토 → 내 판단이 반복되는 과정이 AI와의 진짜 협업이다.
- 프롬프트에 맥락과 내 생각을 더할수록 AI의 답은 '내 것'에 가까워진다.
- AI의 답은 항상 검토와 판단의 대상이지, 최종 결과물이 아니다.
