번외 실습: 카카오맵 띄우기

이 페이지는 지도 기능이 필요한 팀을 위한 선택 실습입니다. 모든 팀이 해야 하는 필수 과제는 아닙니다. 먼저 준비된 실습창에서 지도를 띄워 보고, 우리 프로젝트에 필요하면 자신의 웹앱과 실제 위치 자료로 확장하세요.

🎯 먼저 여기까지 해 봅시다

카카오 배경 지도 + 가상 지점 3개 + 지점을 눌렀을 때 설명이 나오면 첫 실습을 마친 것입니다. 세 지점은 실제 CCTV가 아닌 연습용 위치입니다.

1. 실습창을 열고 등록할 주소 복사하기

섹션 제목: “1. 실습창을 열고 등록할 주소 복사하기”
카카오맵 실습창 새 탭에서 열기 ↗
  1. 위 링크를 엽니다. 실습창은 별도 사이트 로그인 없이 사용할 수 있습니다.
  2. 왼쪽 ‘이 주소를 먼저 등록하세요’ 아래의 주소를 확인합니다.
  3. 주소 옆 복사 버튼을 누릅니다. 자동 복사가 안 되면 선택된 주소를 직접 복사합니다.

정식 교과서 실습창에서 등록할 주소는 다음과 같습니다.

뒤의 /hyfl-ai-lab/labs/kakao-map/ 경로는 등록값에 넣지 않습니다. 교과서와 실습창을 각각 열어 두고, 다음 설정은 카카오디벨로퍼스에서 진행합니다.

직접 확인: 실습창의 주소 표시를 읽고 복사했습니다. 아직 키를 넣지 않았으므로 지도가 보이지 않아도 됩니다.

2. 카카오 앱을 선택하고 ‘사용 설정 ON’ 확인하기

섹션 제목: “2. 카카오 앱을 선택하고 ‘사용 설정 ON’ 확인하기”
  1. 카카오디벨로퍼스에 카카오 계정으로 로그인합니다. 처음이면 개발자 등록을 진행합니다.
  2. 앱에서 사용할 앱을 선택합니다. 아직 없다면 앱 생성 화면에서 이름 등 필수 정보를 입력해 만듭니다.
  3. 선택한 앱의 카카오맵 → 사용 설정 → 상태를 ON으로 바꿉니다.

⚠️ 키가 있어도 카카오맵 사용 설정을 켜야 합니다

이번 실습에서 특히 확인할 설정은 카카오맵 → 사용 설정 → ON입니다. JavaScript 키를 복사하거나 도메인을 등록하는 것과 별도로 확인하세요.

다음과 같은 응답이 나오면 입력한 키가 속한 앱에서 카카오맵 서비스가 비활성화된 상태라는 뜻입니다.

이때는 오류에 해당하는 앱을 열어 카카오맵 사용 설정을 ON으로 바꾼 뒤 실습창에서 다시 연결합니다. 이미 ON이라면 지금 확인하는 앱과 입력한 키의 앱이 같은지 살펴봅니다. 이 오류를 지도 저작권 문제로 해석하지 않습니다.

앱 정보의 카카오맵 무료 쿼터 표시도 확인하세요. 현재 새로 활성화하는 경우 개발자 계정에서 처음 카카오맵 API를 활성화한 앱에 무료 쿼터가 제공됩니다. 두 번째 이후의 새 활성화 앱이나 무료 제공량 초과 사용에는 유료 API 설정이 필요합니다. 기존 앱과 사용량은 통계 → 쿼터 및 현재 이용 조건에서 확인합니다. 유료 사용 설정은 이 실습의 진행 절차에 포함하지 않습니다.

직접 확인: 사용할 앱과 카카오맵 상태 ON을 확인했습니다.

3. JavaScript 키의 SDK 도메인 등록하기

섹션 제목: “3. JavaScript 키의 SDK 도메인 등록하기”
  1. 같은 앱에서 앱 설정 → 앱 → 플랫폼 키로 이동합니다.
  2. JavaScript 키를 선택합니다. 지도 Web SDK에는 이 키를 사용합니다.
  3. 해당 키의 JavaScript SDK 도메인에 1단계에서 복사한 https://jihyuniee.github.io를 추가하고 저장합니다.
  4. 방금 선택한 JavaScript 키의 복사 버튼을 누릅니다.

등록 위치는 선택한 JavaScript 키 안의 SDK 도메인입니다. 앱의 대표 도메인이나 다른 키의 설정만 바꾸지 않았는지 확인하세요. 설정 화면은 카카오 지도 공식 준비 안내에서 함께 볼 수 있습니다.

이번에 확인할 항목맞는 값 또는 상태
사용할 키 종류JavaScript 키
카카오맵 사용 설정ON
처음 실습할 SDK 도메인https://jihyuniee.github.io

JavaScript 키는 웹 지도에서 사용하는 브라우저용 키입니다. REST API 키·어드민 키·서버용 비밀키를 대신 넣지 않습니다. 키 값을 활동지나 오류 화면 설명에 적을 필요는 없습니다.

직접 확인: 같은 앱의 JavaScript 키에 교과서 실습 도메인을 등록하고, 그 키를 복사했습니다.

4. 실습창에 키를 넣고 지도 확인하기

섹션 제목: “4. 실습창에 키를 넣고 지도 확인하기”
  1. 열어 둔 카카오맵 실습창으로 돌아갑니다.
  2. JavaScript 키 입력칸에 복사한 값을 붙여 넣습니다.
  3. 지도 띄우기를 누르고 연결 결과를 기다립니다.
  4. 연결되면 지도 위 마커 또는 연습 지점 A·B·C 카드를 눌러 봅니다. 전체 보기로 세 지점의 범위를 다시 확인할 수 있습니다.
확인할 것직접 볼 결과
배경 지도도로와 지명이 실제로 보임
마커가상 연습 지점 세 곳이 표시됨
클릭선택한 지점의 이름·가상 위치 안내가 열림
출처카카오 로고와 저작권 표시가 가려지지 않음

‘지도 초기화 완료’ 문구만 보고 끝내지 말고 도로·지명이 보이는지 확인하세요. 회색 배경 위에 마커만 있는 경우는 배경 이미지가 제대로 로드되지 않았을 수 있습니다.

직접 확인: 배경·세 지점·클릭 설명·출처가 보이면 첫 실습 완료입니다. 지도가 필요한 팀은 아래 확장 활동을 이어갑니다.

5. 실패하면 카카오의 실제 오류 문구 확인하기

섹션 제목: “5. 실패하면 카카오의 실제 오류 문구 확인하기”

‘지도 연결을 완료하지 못했어요’가 나오면 지도 아래 오류 확인 영역을 봅니다. 설정을 추측해서 여러 번 바꾸기보다, 카카오가 보낸 문구를 확인합니다.

  1. 갈색 카카오 오류 내용 열기 버튼이 보이면 누릅니다. 카카오의 응답이 새 탭에 열립니다.
  2. 새 탭에서 message에 적힌 오류 문구를 복사합니다. 주소창에는 키가 포함되므로 주소 전체를 복사하지 않습니다.
  3. 원래 실습창으로 돌아와 오류 문구 붙여 넣기에 붙입니다. 붙여 넣은 내용의 키 값은 자동으로 가려지고, 문구에 맞는 점검 안내가 나옵니다.
  4. 도움이 더 필요하면 키 없이 오류 복사를 눌러 선생님이나 AI에게 보냅니다. 자동 복사가 제한되면 나타난 진단 내용을 직접 복사합니다.
  5. 안내에 따라 설정을 고친 뒤 지도 띄우기를 다시 누릅니다.

갈색 버튼이 없는 경우는 카카오 파일 요청 전이나 다른 단계에서 멈춘 것일 수 있습니다. 표시된 실패 단계를 읽고 키 없이 오류 복사를 사용하세요. 새 탭에 오류 대신 긴 프로그램 코드가 보이면 그 코드를 붙이지 말고 ‘프로그램 코드가 보인다’고 알려 주세요. 새 탭 요청과 처음 실패한 요청의 결과가 다를 수 있습니다.

실제 응답 또는 현상다음에 확인할 것

흰 화면이나 연결 실패를 곧바로 저작권 문제라고 단정하지 않습니다. 이번 실습에서 확인한 비활성화 오류는 해당 앱의 카카오맵 사용 설정 ON으로 해결하는 경우입니다.

확장 선택 A. 우리 팀 웹앱에 지도 넣기

섹션 제목: “확장 선택 A. 우리 팀 웹앱에 지도 넣기”

이제 지도 기능을 자신의 프로젝트에 넣고 싶은 팀만 진행합니다. 첫 실습은 교과서 실습 주소, 팀 웹앱은 팀의 실행 주소를 등록합니다.

지도가 실행되는 곳JavaScript SDK 도메인에 등록할 값
교과서 실습창 https://jihyuniee.github.io/hyfl-ai-lab/labs/kakao-map/https://jihyuniee.github.io
팀 웹앱 https://my-team.github.io/cctv-map/https://my-team.github.io
로컬 웹 서버 http://localhost:3000/index.htmlhttp://localhost:3000

팀 주소는 예시입니다. 등록값에서는 뒤의 경로를 빼고, localhost는 실제 포트까지 포함합니다. 같은 앱·JavaScript 키를 계속 사용할 수 있다면 그 키의 SDK 도메인에 팀 주소를 추가합니다. 지도 기능을 하나 더 만들 때마다 새 키를 만들 필요는 없습니다. 앱의 이용 조건과 한도는 이어서 적용됩니다.

시작 파일 내려받기

섹션 제목: “시작 파일 내려받기”

아래 index.html 다운로드로 한 파일짜리 시작 예제를 받습니다. 지금 사용한 키 입력 실습창과 달리, 이 파일은 코드를 직접 수정해 팀 웹앱으로 만드는 출발점입니다. 현재 프로젝트 원본은 따로 보관합니다.

지도 한 장과 가상 지점 3개부터 확인하세요.

아래 예제는 실제 CCTV 자료를 포함하지 않습니다. 지도가 보이고 지점을 눌렀을 때 설명이 열리는지 확인한 뒤, 우리 팀의 데이터를 연결합니다.

카카오맵 시작 예제

카카오맵 사용 설정 ON, JavaScript 키와 웹앱 도메인 등록이 필요합니다.

index.html 다운로드

코드의 const javascriptKey = 'YOUR_JAVASCRIPT_KEY'; 한 줄에서 YOUR_JAVASCRIPT_KEY를 본인의 JavaScript 키로 바꾸세요. REST API 키·어드민 키·Client Secret은 넣지 않습니다.

카카오디벨로퍼스에서 카카오맵 → 사용 설정 → ON을 확인하고, 앱 → 플랫폼 키 → JavaScript 키 → JavaScript SDK 도메인에 실행할 웹앱 주소를 등록하세요. localhost는 포트까지 맞춥니다.

내려받은 index.html을 코드 편집기로 열어 수정하고, 등록한 HTTPS 웹앱 주소 또는 localhost 웹 서버에서 실행하세요. 이 시작 예제는 웹 서버에서 실행하도록 만들어서, 더블클릭한 file:// 화면에서는 안내만 표시합니다. 지도에 표시되는 로고와 저작권 정보는 유지하세요.

GitHub Pages에 올리기

섹션 제목: “GitHub Pages에 올리기”

이미 팀 웹앱 주소가 있다면 기존 배포 방법을 사용합니다. 처음이라면 다음 순서로 주소를 만듭니다.

  1. GitHub의 + → New repository에서 공개 가능한 연습용 Public 저장소와 README를 만듭니다.
  2. Add file → Upload files로 index.html을 저장소 맨 위에 올리고 Commit changes를 누릅니다.
  3. Settings → Pages → Build and deployment → Source를 Deploy from a branch로 선택합니다.
  4. Branch: main / (root)를 선택하고 Save합니다.
  5. 배포가 끝나면 Visit site로 실제 주소를 확인합니다. 아직 열리지 않으면 Actions의 배포 상태를 봅니다.

자세한 절차는 기존 교과서의 배포 안내에서 볼 수 있습니다. 팀 주소의 도메인을 카카오에 추가한 뒤, 파일의 다음 줄에서 자리표시자만 자신의 JavaScript 키로 바꿉니다.

수정한 파일을 같은 저장소에 다시 올려 배포하고, 팀 웹앱 주소에서 배경·가상 세 지점·클릭을 확인합니다. AI 미리보기나 file:// 직접 열기는 외부 지도 인증·실행이 제한될 수 있으므로, 실제 배포 주소로 확인합니다.

빈 값을 0으로 바꾸면 왜 안 될까요?

JavaScript의 Number('')는 0이 됩니다. 0은 위도·경도 범위 안에 있지만, 원자료에 없던 좌표를 새로 만들어 넣으면 실제와 다른 위치가 생깁니다. 빈 값인지 먼저 확인하고, 값이 있을 때 숫자로 바꿔 검사해야 합니다.

이 연습은 숫자와 범위만 검사합니다. WGS84 위도는 −90~90, 경도는 −180~180입니다. 검사를 통과해도 실제 위치가 맞는지는 원자료·좌표계·지도와 따로 대조해야 합니다. 선택과 결과는 저장되지 않습니다.

전국CCTV표준데이터 또는 지자체 공개 자료에서 CSV와 항목 설명을 확인합니다. 원본을 보관하고, 프로젝트에 필요한 지역·목적을 정합니다. 자료가 크면 그 범위를 별도 CSV로 추리고 사용한 범위를 표시합니다. 한글이 깨지면 인코딩을 확인하고 편집한 자료는 CSV UTF-8로 저장합니다.

# 만들어야 할 기능
1. 기존 지도와 정상 작동하는 기능을 유지하고, 사용자가 CSV를 직접 고르는 파일 선택 버튼을 추가해줘. 선택한 파일은 브라우저에서 읽고 서버에 전송하거나 저장하지 마.
2. 선택한 CSV의 전체 행을 읽어. AI에게 보인 일부 샘플만 하드코딩하거나 전체 데이터로 취급하지 마. 전국 자료에서 특정 지역만 추렸다면 그 범위를 화면에 표시해줘.
3. CSV의 BOM, 따옴표 안 쉼표와 줄바꿈, 빈 값을 올바르게 처리해줘. 단순 split(',')로 파싱하지 마. 한글이 깨진 경우 인코딩을 확인할 수 있게 안내해줘.
4. 실제 열 이름을 바탕으로 위도·경도 열을 연결하고, 열이 없으면 사용자가 다시 선택하거나 확인할 수 있게 해줘. WGS84 위도·경도인지 확인되지 않았다면 확인 필요로 알리고 임의로 좌표계를 가정하지 마.
5. 빈 문자열·공백·숫자로 바뀌지 않는 값·범위 밖 좌표를 0으로 바꾸지 마. 파일의 전체 데이터 행 수, 현재 조건에 해당하는 행 수, 유효 좌표가 있는 행 수와 제외된 행 수를 구분해서 보여줘. 머리글은 데이터 행으로 세지 마.
6. 유효한 WGS84 좌표를 new kakao.maps.LatLng(위도, 경도)에 넣고 kakao.maps.Marker로 표시해줘. 여러 위치는 kakao.maps.LatLngBounds에 extend한 뒤 map.setBounds로 보이게 하고, 한 위치만 있으면 적절한 중심·확대 수준을 사용해줘. 유효 좌표가 없을 때는 빈 bounds로 지도를 이동하지 마. 마커를 누르면 InfoWindow에 실제 주소·설치 목적·대수·기준일을 보여줘. 설치 목적 열이 있으면 목적 선택 필터와 전체 보기를 제공하고, 없으면 그 필터는 생략해줘. CSV의 텍스트는 DOM 요소의 textContent로 넣어 HTML이 실행되지 않게 해줘.
7. 가상 연습 지점은 실제 자료 결과와 섞지 마. 실제 파일을 고르거나 파일·필터가 바뀔 때 기존 마커마다 setMap(null)을 호출하고 열린 정보창도 닫아줘. 새 결과를 그린 뒤 지도와 같은 자료의 위치 목록을 제공해줘.
8. 같은 좌표에 여러 행이 있으면 그 사실을 알리고, 행 수·서로 다른 설치 지점 수·카메라 대수를 혼동하지 않게 해줘. 자료에 대수 열이 없으면 대수를 만들어내지 마.
9. 파일 미선택, 데이터 없음, 잘못된 열, 좌표 누락, 필터 결과 0건, 지도 배경 로드 실패를 각각 이해하기 쉬운 말로 안내해줘. 확인하지 않은 수치를 '0건'으로 확정하지 마.

# 지도와 실행 조건
- HTML·CSS·JavaScript를 포함한 하나의 index.html로 작성하고 GitHub Pages 같은 정적 호스팅에서 실행되게 해줘. 지도 영역에는 명시적인 높이를 줘.
- SDK는 https://dapi.kakao.com/v2/maps/sdk.js?appkey=YOUR_JAVASCRIPT_KEY&autoload=false 를 사용하고, SDK 로드 후 kakao.maps.load 콜백 안에서 지도 객체를 만들어줘. 카카오 지도만 사용해줘.
- JavaScript 키는 코드의 YOUR_JAVASCRIPT_KEY 자리표시자로 남겨 내가 직접 입력하게 해줘. REST API 키·어드민 키·서버용 비밀키를 넣지 마. 등록할 JavaScript SDK 도메인은 학생 웹앱의 프로토콜·호스트·사용 중인 포트이며, 뒤의 경로는 제외한다.
- 위도·경도가 이미 있는 CSV이므로 주소를 다시 좌표로 바꾸는 API는 필요하지 않다. 카카오 로고와 저작권 표시는 가리거나 제거하지 마.
- CCTV CSV 업로드에는 공공데이터 API 인증키가 필요하지 않다. 이번 기능에 실시간 API·서버·데이터베이스를 새로 추가하지 마.
- 지도 출처와 데이터 출처·기준일을 표시하고, 공개된 위치 자료로 실시간 영상·운영 상태·안전 보장을 제공한다고 표현하지 마.

# 결과 형식
수정한 index.html 전체와 변경 내용을 알려줘. 직접 확인하지 않은 결과를 성공했다고 쓰지 말고, 원자료 3행과 비교할 방법·빈 좌표 처리·파일 재선택 테스트를 안내해줘.

AI에 CSV를 첨부한 것과 웹앱이 파일을 읽는 것은 별개입니다. 샘플 몇 행을 하드코딩하지 않고 선택한 파일 전체를 읽어 계산해야 합니다. CSV 파일 선택 방식에는 별도의 공공데이터 API 키나 서버 저장이 필요하지 않습니다. 새로 접속하면 파일을 다시 고를 수 있으며, CSV를 공개 저장소에 올릴 필요는 없습니다.
