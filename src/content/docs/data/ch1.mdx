School Image Lab에서는 사진·음성·포즈 데이터를 직접 모아 AI 모델을 학습시켰습니다. 이번에는 학교 밖으로 시야를 넓혀 봅니다. 이미 공개되어 있는 데이터를 찾아보고, 그 데이터가 어떤 형태로 제공되는지 살펴봅니다.

<Callout kind="mission" title="오늘의 미션">공공데이터가 무엇인지 이해하고, 관심 분야와 관련된 데이터를 직접 찾아 **출처·데이터 형태·제공 방식·기준 시점**을 기록합니다.</Callout>

```text
직접 수집한 데이터 떠올리기
→ 데이터 형태 구분하기
→ 공공데이터의 의미 이해하기
→ 공공데이터 포털 둘러보기
→ 데이터 하나 찾고 기록하기
→ AI 도움을 받고 원자료로 확인하기
```

## 1. 직접 모은 데이터와 공개된 데이터

지난 프로젝트에서는 우리 팀이 필요한 데이터를 직접 모았습니다. 사진을 찍고, 음성을 녹음하고, 포즈를 촬영해 모델이 학습할 사례를 만들었습니다.

하지만 세상의 모든 데이터를 우리가 직접 모을 수는 없습니다. 인구, 날씨, 교통, 문화, 교육, 경제처럼 이미 기관에서 조사하거나 관리한 자료를 활용하면 더 넓은 현상을 살펴볼 수 있습니다.

| 구분 | 지난 프로젝트 | 이번 단원 |
| --- | --- | --- |
| 데이터 출발점 | 우리가 직접 수집한 사진·음성·포즈 | 공공기관이 공개한 자료 |
| 주로 살핀 것 | 모델이 입력을 잘 분류하는가 | 데이터가 어떤 현상을 보여 주는가 |
| 먼저 확인할 것 | 클래스, 사례 수, 오류 사례 | 출처, 기준 시점, 항목, 단위, 한계 |

## 2. 데이터는 어떤 모양일까?

데이터는 모두 같은 모양으로 생기지 않았습니다. 지난 프로젝트에서 사용한 사진·음성·포즈와 공공데이터포털에서 자주 만나는 CSV 파일은 형태가 다릅니다.

| 데이터 형태 | 쉽게 말하면 | 예 |
| --- | --- | --- |
| 정형 데이터 | 행과 열이 정해져 있는 표 형태의 데이터 | CSV, XLSX, 통계표 |
| 반정형 데이터 | 구조는 있지만 고정된 표 모양은 아닌 데이터 | JSON, XML, API 응답 |
| 비정형 데이터 | 정해진 행과 열 구조가 없는 데이터 | 사진, 음성, 영상, 문서 본문 |

지난 프로젝트의 사진·음성·포즈는 주로 **비정형 데이터**였습니다. 공공데이터를 탐색할 때는 표 형태의 **정형 데이터**와 API 응답 같은 **반정형 데이터**를 자주 만나게 됩니다.

### 형태 판별 연습

자료를 볼 때 먼저 “이 데이터가 어떤 모양으로 되어 있는가?”를 생각합니다.

| 자료 예시 | 데이터 형태 | 이유 |
| --- | --- | --- |
| 학교 급식 CSV 파일 | 정형 데이터 | 날짜, 학교명, 메뉴처럼 행과 열로 정리되어 있다 |
| 날씨 API의 JSON 응답 | 반정형 데이터 | 이름표와 구조는 있지만 일반 표 모양은 아니다 |
| 학생이 촬영한 교실 이미지 | 비정형 데이터 | 행과 열로 나뉜 표가 아니라 이미지이다 |
| 설문 응답 스프레드시트 | 정형 데이터 | 한 사람의 응답이 한 행으로 정리될 수 있다 |

## 3. 공공데이터란 무엇일까?

공공데이터는 공공기관이 업무를 하며 만들거나 관리하는 데이터 중 이용자가 활용할 수 있도록 제공한 데이터입니다. 인구, 교육, 기상, 교통, 환경, 보건, 경제, 문화 등 여러 분야의 자료가 공개되어 있습니다.

공공데이터라고 해서 자동으로 우리 질문에 맞는 데이터라는 뜻은 아닙니다. 어떤 기관이, 어떤 기준으로, 언제의 자료를 제공하는지 확인해야 합니다.

<Callout kind="caution" title="출처부터 확인합니다">데이터를 찾으면 가장 먼저 제공 기관, 기준 시점, 수집 또는 집계 기준, 이용 조건을 확인합니다. 제목만 보고 바로 결론을 내리지 않습니다.</Callout>

### 공공데이터를 볼 때 묻는 질문

- 누가 제공하는 데이터인가?
- 언제 기준의 데이터인가?
- 어떤 기준으로 수집하거나 집계했는가?
- 어떤 항목과 단위가 들어 있는가?
- 이 데이터로 알 수 있는 것은 무엇인가?
- 이 데이터로는 알 수 없는 것은 무엇인가?

## 4. 어디에서 찾아볼 수 있을까?

공공데이터는 여러 사이트에서 제공됩니다. 같은 주제라도 기관마다 제공하는 항목, 기간, 지역 단위가 다를 수 있습니다.

| 찾아볼 곳 | 주소 | 살펴볼 수 있는 자료 예 |
| --- | --- | --- |
| 공공데이터포털 | data.go.kr | 여러 공공기관의 파일 데이터와 오픈 API |
| KOSIS 국가통계포털 | kosis.kr | 인구·경제·사회·교육 등 국가 통계 |
| 기상자료개방포털 | data.kma.go.kr | 기온·강수량 등 기상 관측 자료 |
| NEIS 교육정보 개방 포털 | open.neis.go.kr | 학교 기본 정보·급식·학사 일정 등 교육 관련 API |
| 영화진흥위원회 KOBIS | kobis.or.kr | 박스오피스·영화·상영 정보 |
| 지방자치단체 또는 공공기관 홈페이지 | 기관별로 다름 | 지역별 행정·교통·환경·문화 관련 공개 자료 |

### 검색어를 바꿔 가며 찾기

| 관심 분야 | 검색어 예시 |
| --- | --- |
| 학교생활 | 학교 급식 공공데이터, 학사 일정 API, 학교 기본 정보 |
| 문화 | 영화 관객 수 통계, 공연 시설 현황, 도서관 대출 통계 |
| 환경 | 미세먼지 관측 자료, 기온 변화 데이터, 생활 폐기물 통계 |
| 교통 | 교통사고 통계, 지하철 승하차 인원, 버스 정류장 위치 |
| 진로·직업 | 직업별 고용 통계, 자격시험 통계, 산업별 취업자 수 |
| 지역사회 | 인구 변화, 청소년 인구, 공공시설 현황 |

## 5. 데이터를 만나는 방법

데이터를 찾을 때는 자료가 어떤 방식으로 제공되는지 확인합니다. 방법마다 장점과 확인할 점이 다릅니다.

| 방법 | 의미 | 확인할 것 |
| --- | --- | --- |
| 파일 | CSV·XLSX 등을 내려받아 확인한다 | 파일명, 출처, 다운로드 날짜, 열 이름, 단위 |
| API | 조건을 넣어 필요한 데이터를 응답으로 받는다 | 요청 주소, 변수, 인증키 필요 여부, 응답 항목 |
| 웹 화면 | 통계표나 검색 화면에서 조건을 선택해 조회한다 | 조회 조건, 기간, 지역, 단위, 표 제목 |
| AI 도구 활용 | 검색어를 넓히거나 자료 후보를 정리하는 데 도움을 받는다 | AI가 제시한 출처가 실제로 존재하는지, 조건과 단위가 맞는지 |

AI 도구는 데이터를 대신 검증해 주는 출처가 아닙니다. 공공데이터를 더 빠르게 찾고 이해하도록 돕는 보조 도구로 사용합니다.

## 6. 오늘 활동 · 공공데이터 포털 탐험

선생님이 제시한 미션 또는 자신의 관심 분야 중 하나를 골라 공공데이터를 찾아봅니다. 오늘의 핵심은 데이터를 완벽하게 분석하는 것이 아니라, 실제로 존재하는 데이터를 찾고 기본 정보를 확인하는 것입니다.

<Step title="데이터 형태 표시하기">찾은 자료가 정형·반정형·비정형 중 어디에 가까운지 표시합니다.</Step>

## 7. 생성형 AI 활용하기

생성형 AI는 검색어를 넓히고, 데이터 설명을 이해하고, 기록을 정리하는 데 도움을 줄 수 있습니다. 단, AI가 말한 데이터 이름, 기관, 수치, 해석은 실제 사이트에서 다시 확인합니다.

```text
나는 고등학교 인공지능 원리탐구 수업에서 공공데이터를 탐색하고 있어.

관심 분야: [나의 관심 분야]
궁금한 점: [내가 궁금한 점]

1. 이 주제와 관련된 공공데이터 검색어를 한국어로 제안해줘.
2. 찾아볼 만한 공식 사이트 후보를 알려줘.
3. 데이터가 정형·반정형·비정형 중 어디에 가까운지 판단할 때 볼 점을 알려줘.
4. 이 데이터로 알 수 있는 것과 알 수 없는 것을 구분해줘.
5. 확실하지 않은 내용은 단정하지 말고 "확인 필요"라고 표시해줘.
```

<Callout kind="caution" title="AI 답변은 원자료와 비교합니다">AI가 알려 준 데이터 이름과 기관이 실제 사이트에 있는지 확인합니다. 기준 시점, 단위, 수치는 데이터 페이지에 적힌 내용을 우선합니다.</Callout>

## 8. 오늘의 완료 기준

<Callout kind="checklist" title="수업이 끝날 때 남길 것">
- 공공데이터의 의미를 자신의 말로 간단히 설명할 수 있다.
- 정형·반정형·비정형 데이터의 차이를 예로 설명할 수 있다.
- 공공데이터 포털에서 관심 분야와 관련된 데이터를 하나 이상 찾아보았다.
- 데이터 이름, 제공 기관, 데이터 형태, 제공 방식, 기준 시점 또는 갱신일을 기록했다.
- 이 데이터로 알 수 있는 것과 알 수 없는 것을 각각 1가지 이상 적었다.
- AI가 제안한 내용 중 실제 사이트에서 확인한 것을 표시했다.
</Callout>
