01 / 시작한 이유

왜 이 문제에 관심을 갖게 되었나요?

저희는 친구들이나 스터디 모임원들과 만날 약속을 잡을 때마다 "어디서 만날까?"로 한참 동안 의견이 갈리고 시간이 많이 소요되는 문제를 해결하고 싶었습니다. 서로 사는 곳이나 출발역이 다르면 특정 한 사람에게 유리하거나 불리해지는 경우가 많았습니다. 마땅한 중간 지점을 찾기 어려운 경우 성수나 홍대와 같은 극도로 붐비는 번화가에서 만날 수밖에 없어서 효율성이 저하되고 매번 비슷한 장소에서 모임을 갖는 불편함이 있었습니다. 따라서 저희는 누구나 납득할 수 있는 '공평한 중간 지점'을 객관적으로 찾아주는 도구가 필요하다고 생각해 프로젝트를 시작했습니다.

02 / 데이터에서 발견한 것

어떤 공공데이터를 활용했고, 무엇을 확인했나요?

저희는 서울교통공사와 공공데이터포털에서 제공하는 ‘지하철역 위치(좌표) 데이터’와 ‘역간 이동 시간·노선 정보 데이터’를 활용했습니다. 출발역의 위치 좌표와 지하철 이동 시간을 바탕으로 중간 만남 역을 계산하도록 만들었습니다.

03 / 직접 써 보세요

우리 웹앱으로 무엇을 할 수 있나요?

각자 출발하는 지하철역 이름을 입력하면, 역의 위치 좌표와 지하철 이동 시간을 바탕으로 중간 만남 역을 추천받을 수 있습니다.

팀원들의 실제 집 근처 역을 입력했을 때, 이동 시간이 비슷하면서도 환승이 편리한 역이 중간 지점으로 추천되는 것을 직접 확인했습니다.

04 / 만들어 가는 이야기

만드는 과정에서 가장 기억에 남는 일은 무엇인가요?

가장 힘들었던 점은 지금까지 고생해서 짜둔 기획과 코드를 한순간에 전부 갈아엎고 처음부터 다시 시작해야 했던 순간입니다. 제출 기한은 다가오는데 데이터가 나와주지 않아 대안을 찾고 수없이 토론했습니다. 팀원들과 머리를 맞대고 고민한 끝에, "주제를 바꾸더라도 공공데이터를 활용해 사람들의 실제 문제를 해결하려는 취지는 잃지 말자"고 결단했습니다. 방향을 전환한 후에는 단순한 직선거리가 아니라 공공데이터의 역 간 소요 시간을 기반으로 진짜 이동 시간이 균등해지는 알고리즘을 구현하는 데 집중하여 문제를 해결했습니다.
