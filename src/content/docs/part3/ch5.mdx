## 생각을 여는 질문

<Callout kind="question">
요즘의 AI 서비스는 왜 글쓰기뿐 아니라 이미지 이해, 검색, 데이터 분석, 코딩 같은 여러 작업을 한곳에서 수행할 수 있을까요?
</Callout>

이 질문에 답하려면 먼저 **모델**과 **서비스**를 구분해야 합니다. 대규모 언어 모델(LLM)은 언어를 처리하고 생성하는 핵심 모델의 한 종류이고, 실제 서비스는 여기에 이미지·음성 같은 입력을 처리하는 기능, 검색, 코드 실행, 파일 처리 같은 도구를 연결할 수 있습니다.

## 생성형 AI와 LLM

<strong>생성형 AI(Generative AI)</strong>는 학습한 패턴을 바탕으로 텍스트, 이미지, 음성, 영상, 코드 등 새로운 결과를 만들어내는 AI를 넓게 가리킵니다.

<strong>대규모 언어 모델(LLM, Large Language Model)</strong>은 매우 많은 텍스트를 바탕으로 언어의 통계적·구조적 패턴을 학습하고, 주어진 문맥에 이어질 토큰을 예측하는 방식으로 텍스트를 생성하는 모델입니다. LLM은 딥러닝 기술을 이용합니다.

<Callout kind="caution" title="서비스와 모델은 같은 말이 아니다">
ChatGPT, Gemini, Perplexity 같은 것은 사용자에게 제공되는 서비스 또는 제품의 이름입니다. 서비스는 하나의 모델만으로 이루어지지 않을 수 있으며, 검색·파일 처리·코드 실행·외부 도구 같은 기능이 함께 사용될 수 있습니다.
</Callout>

## LLM은 어떻게 문장을 만드는가

텍스트를 처리할 때 LLM은 입력을 <strong>토큰(token)</strong>이라는 단위로 나누고, 지금까지의 문맥을 바탕으로 다음 토큰의 확률을 계산합니다. 이 과정을 반복하면서 문장을 생성합니다.

<FlowDiagram items={[{ ko: '입력', en: '문장·질문' }, { ko: '토큰화', en: '작은 단위로 나누기' }, { ko: '문맥 처리', en: '앞의 내용 반영' }, { ko: '다음 토큰 예측', en: '확률 계산' }, { ko: '반복 생성', en: '문장 완성' }]} />

이 설명은 LLM의 핵심 생성 원리를 단순화한 것입니다. 실제 모델은 매우 많은 매개변수와 복잡한 신경망 계산을 사용합니다.

## 그런데 왜 이미지도 보고 데이터도 분석할까

LLM 자체의 언어 생성 능력과 실제 AI 서비스의 전체 기능을 구분해야 합니다.

### 1. 멀티모달 모델

일부 최신 모델은 텍스트뿐 아니라 이미지, 음성, 영상 등 여러 형태의 입력을 처리하도록 설계됩니다. 이를 **멀티모달(multimodal)**이라고 합니다.

예를 들어 공식 문서에서 Google의 Gemini 계열 모델은 텍스트·이미지·영상·오디오 등의 입력을 처리하는 멀티모달 기능을 제공한다고 설명합니다.

### 2. 도구 사용

AI 서비스는 필요에 따라 검색, 코드 실행, 계산, 파일 처리, 외부 API 같은 도구와 연결될 수 있습니다.

예를 들어 ChatGPT의 공식 도움말에는 업로드한 스프레드시트를 분석하고 Python 기반 계산과 시각화를 수행할 수 있는 데이터 분석 기능이 설명되어 있습니다. Gemini API 공식 문서에도 Google Search, Code Execution 등 도구 연결 기능이 안내되어 있습니다.

### 3. 검색과 정보 결합

일부 서비스는 웹 검색을 중심 기능으로 사용합니다. Perplexity는 공식 도움말에서 웹을 검색한 뒤 출처를 제시하며 답변을 구성하는 AI 기반 검색 서비스로 설명됩니다.

<Callout kind="concept" title="핵심 구분">
현대 AI 서비스가 여러 일을 할 수 있는 이유를 단순히 “LLM이 모든 것을 할 수 있기 때문”이라고 설명하면 정확하지 않습니다.

실제 서비스는 **언어 모델 + 멀티모달 처리 + 검색 + 코드 실행 + 파일 처리 + 외부 도구** 등을 조합할 수 있습니다.
</Callout>

## 그러면 현재 AI는 범용인공지능(AGI)일까

<strong>AGI(Artificial General Intelligence, 범용인공지능)</strong>는 연구자와 기관에 따라 정의가 조금씩 다릅니다. Google DeepMind의 연구에서는 AGI를 성능, 일반성, 자율성 같은 기준으로 평가하려는 틀을 제안하고 있습니다.

현재의 상용 AI 서비스를 곧바로 “완성된 AGI”라고 단정하는 것은 적절하지 않습니다. 현재 시스템의 능력이 넓어지고 있는 현상과 AGI라는 연구 개념은 구분해서 이해해야 합니다.

## 유창함은 정확성의 증거가 아니다

LLM은 문맥에 맞는 토큰을 생성하기 때문에 자연스럽고 설득력 있는 문장을 만들 수 있습니다. 그러나 생성된 내용이 자동으로 사실이 되는 것은 아닙니다. 실제로 존재하지 않는 정보, 잘못된 수치, 부정확한 출처 등을 만들어낼 수 있습니다.

이러한 오류를 흔히 <strong>할루시네이션(hallucination)</strong>이라고 부릅니다. 중요한 사실을 사용할 때는 원문과 신뢰할 수 있는 출처를 직접 확인해야 합니다.

## 활동: 같은 목표, 다른 서비스 구조

<Callout kind="lab" title="AI 서비스를 기능 단위로 분석하기">
ChatGPT, Gemini, Perplexity 또는 다른 AI 서비스 하나를 선택합니다. 인기 순위를 비교하는 활동이 아닙니다. 공식 도움말이나 제품 설명에서 확인할 수 있는 기능만 조사하세요.

1. 핵심적으로 어떤 문제를 해결하려는 서비스인가?
2. 텍스트 외에 어떤 입력을 지원하는가?
3. 검색, 코드 실행, 파일 분석 같은 도구를 사용하는가?
4. 결과의 출처나 근거를 어떤 방식으로 확인할 수 있는가?
5. 확인할 수 없는 내부 구조는 무엇인가?

확인한 사실과 자신의 추정을 반드시 구분해서 작성합니다.
</Callout>

## 핵심 정리

<Callout kind="concept" title="오늘 기억할 네 문장">
1. 생성형 AI는 새로운 콘텐츠를 만들어내는 AI를 넓게 가리킨다.
2. LLM은 언어를 처리하고 생성하는 딥러닝 모델의 한 종류이다.
3. 실제 AI 서비스는 LLM뿐 아니라 멀티모달 처리, 검색, 코드 실행, 파일 처리 등 여러 기능을 조합할 수 있다.
4. 현재 AI 서비스의 능력 확대와 AGI라는 연구 개념은 구분해서 이해해야 한다.
</Callout>
