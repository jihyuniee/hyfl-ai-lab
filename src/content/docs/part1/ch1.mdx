AI라고 하면 대화형 생성 AI를 먼저 떠올리기 쉽습니다. 하지만 AI는 글을 만드는 것뿐 아니라 사람과 사물을 알아보고, 길과 시간을 예측하고, 작물과 의료 영상을 분석하고, 경기와 환경 데이터를 살피는 데에도 활용됩니다.

이 단원에서는 많은 용어를 외우기보다, 서로 다른 사례를 왜 모두 인공지능이라고 부르는지 큰 지도를 먼저 만듭니다. 다음 단원에서 직접 이미지 분류 모델을 가르치며 머신러닝의 작동 원리를 자세히 살펴봅니다.

## 사람은 지능을 사용해 어떤 일을 할까?

사람은 주변을 **보고·듣고·읽어 알아차리고**, 경험에서 배우며, 정보를 바탕으로 앞으로의 일을 예상하고, 여러 선택지 가운데 판단하여 행동합니다.

<div class="ai-function-map" aria-label="사람과 AI가 수행할 수 있는 지능적 기능">
	<div><span>기능</span><strong>인식</strong><p>무엇인지 알아보기</p></div>
	<div><span>기능</span><strong>학습</strong><p>경험과 정보에서 배우기</p></div>
	<div><span>기능</span><strong>추론·예측</strong><p>정보로 가능성 예상하기</p></div>
	<div><span>기능</span><strong>판단·문제 해결</strong><p>선택하고 해결하기</p></div>
</div>

예를 들어 길을 건널 때 사람은 신호등과 자동차를 인식하고, 지금의 상황을 추론하며, 건너도 되는지를 판단합니다. AI는 이처럼 인간의 지능과 관련된 활동 가운데 일부를 컴퓨터가 수행하도록 만든 기술입니다.

위 네 항목은 AI가 **할 수 있는 기능**을 나누어 본 것이며, 모든 AI가 반드시 1번부터 4번까지 차례로 실행한다는 뜻은 아닙니다. 학습은 모델을 만드는 동안 이루어지고, 실제 사용 중에는 이미 학습된 모델이 새로운 입력에 결과를 내는 **추론**이 주로 일어납니다.

<Callout kind="concept" title="인공지능 AI">
**인공지능(AI)은 인식·학습·추론·예측·판단·생성·문제 해결처럼 인간의 지능적 활동과 관련된 기능을 컴퓨터 시스템이 수행하도록 구현하는 기술과 연구 분야입니다.**
</Callout>

AI가 사람과 똑같이 생각하거나 이해한다는 뜻은 아닙니다. AI 시스템은 사람이 설계한 규칙, 데이터에서 학습한 패턴, 통계와 확률, 계산, 검색이나 코드 실행 같은 도구를 이용해 결과를 만듭니다.

## AI 시스템이 환경과 상호작용하는 흐름

AI가 포함된 시스템을 입력부터 결과까지 살펴보면 **입력·인식 → 처리·판단 → 출력·행동**의 흐름으로 설명할 수 있습니다. 여기서 ‘행동’은 로봇이 움직이는 것만 뜻하지 않습니다. 화면에 추천 결과를 보여 주거나, 경고음을 내거나, 파일을 분류하는 것도 시스템의 출력입니다.

| 흐름 | 하는 일 | 이번 이미지 분류 프로젝트의 예 |
| --- | --- | --- |
| 입력·인식 | 카메라·마이크·파일 등으로 환경의 정보를 디지털 데이터로 받음 | 카메라가 이미지를 입력받음 |
| 처리·판단 | 규칙·탐색·추론·기계학습 모델 등으로 결과를 계산함 | 학습된 분류 모델이 클래스별 값을 계산함 |
| 출력·행동 | 결과를 화면·소리·장치·다른 프로그램으로 전달함 | 클래스와 확률을 화면에 표시함 |

센서로 환경을 받아들이고, 목표에 따라 무엇을 할지 판단하며, 출력 장치나 프로그램을 통해 행동하는 전체 시스템을 **지능 에이전트**의 관점으로 설명할 수 있습니다. 다만 모든 AI가 로봇처럼 물리적 센서와 모터를 갖는 것은 아닙니다. 온라인 추천 시스템처럼 이용 기록을 입력받고 화면의 콘텐츠 배치를 바꾸는 소프트웨어 에이전트도 있습니다.

<Callout kind="concept" title="기능 목록과 작동 흐름을 구분합니다">
**인식·학습·추론·예측·생성·문제 해결**은 AI가 수행할 수 있는 기능을 설명합니다. **입력·인식 → 처리·판단 → 출력·행동**은 AI가 포함된 시스템이 정보를 받아 결과를 내는 흐름을 설명합니다. 두 설명은 서로 경쟁하는 정의가 아니라 서로 다른 질문에 답합니다.
</Callout>

## AI는 무엇을 보고, 예측하고, 해결할까?

AI는 한 가지 일만 하는 기술이 아닙니다. 하나의 시스템 안에서도 다음 기능이 함께 쓰일 수 있습니다.

<div class="ai-function-map ai-function-map--six" aria-label="AI가 수행하는 여러 기능">
	<div><span>보기</span><strong>인식·분류</strong><p>얼굴·사물·음성 알아보기</p></div>
	<div><span>찾기</span><strong>검색·탐색</strong><p>정보·경로·다음 수 찾기</p></div>
	<div><span>예상</span><strong>추론·예측</strong><p>시간·위험·수요 예상하기</p></div>
	<div><span>고르기</span><strong>추천·판단</strong><p>후보를 비교해 제안하기</p></div>
	<div><span>만들기</span><strong>생성</strong><p>글·이미지·코드 만들기</p></div>
	<div><span>해결하기</span><strong>문제 해결</strong><p>여러 단계를 계획·수행하기</p></div>
</div>

예를 들어 내비게이션은 위치와 교통 정보를 읽고, 가능한 길을 탐색하며, 도착 시간을 예측하고, 적절한 경로를 추천합니다. 생성형 AI는 언어·이미지의 패턴을 이용해 새로운 결과를 만들 수 있습니다. 겉모습은 달라도 정보를 바탕으로 지능적 기능을 수행한다는 공통점이 있습니다.

| 스마트폰 | 얼굴·음성·사진·사용 기록 | 잠금 해제, 음성 인식, 사진 검색, 콘텐츠 추천 |
| 교통 | 위치·교통량·도로 영상 | 빠른 길 탐색, 도착 시간·혼잡 예측 |

| 생성형 AI | 질문·지시·텍스트·이미지·파일 | 글·이미지·음악·코드·분석 초안 생성 |

## 자동으로 작동하면 모두 AI일까?

정해진 시간에 울리는 알람과 자판기는 자동으로 작동하지만, 일반적으로 AI라고 부르지 않습니다. 사람이 정한 조건과 규칙을 그대로 실행하기 때문입니다.

반면 많은 AI는 사람이 모든 규칙을 하나하나 작성하기 어려운 문제에서, 데이터의 사례를 이용해 판단에 도움이 되는 패턴을 찾습니다. 이를 **학습 기반 방식**이라고 합니다. 다만 모든 AI가 학습으로만 작동하는 것은 아니며, 실제 AI 시스템에는 규칙과 학습 모델이 함께 쓰일 수 있습니다.

| 비교 | 규칙 기반 방식 | 학습 기반 방식 |
| --- | --- | --- |
| 판단 기준은 어떻게 생길까? | 사람이 규칙을 직접 작성한다. | 많은 사례에서 패턴을 학습한다. |
| 강점 | 기준이 비교적 분명하고, 이유를 설명하기 쉽다. | 복잡한 이미지·음성·언어처럼 규칙을 전부 쓰기 어려운 문제를 다룰 수 있다. |
| 한계 | 새로운 상황마다 규칙을 추가·수정해야 할 수 있다. | 데이터의 품질과 범위에 따라 틀리거나 편향될 수 있다. |

<Callout kind="think" title="생각해 볼 문제 — 규칙이 많아도 AI일까?">
의사가 만든 10만 개의 ‘만약 ~이면, ~일 가능성이 높다’ 규칙으로 환자를 분석하는 프로그램이 있습니다. 이 프로그램은 새 데이터를 학습하지는 않지만 진단을 돕습니다.

- 이 프로그램을 AI라고 부를 수 있을까요?
- 스팸 메일을 거르는 데에는 사람이 규칙 5,000개를 작성한 시스템과, 수백만 건의 메일을 학습한 시스템 가운데 어느 쪽이 더 적절할까요?
- 두 방식을 함께 사용한다면 어떤 장점이 있을까요?
</Callout>

초기 AI에는 사람이 규칙을 직접 설계하는 방식도 포함되었습니다. 오늘날에는 이미지·음성·언어처럼 모든 규칙을 미리 쓰기 어려운 문제에서 학습 기반 방식이 널리 활용됩니다. 따라서 AI를 단순히 ‘학습하는 프로그램’으로만 한정하기보다, **어떤 정보를 바탕으로 어떤 판단을 만들며 그 한계는 무엇인지** 살펴보는 것이 중요합니다.

## 말이 유창하면 이해하는 것일까?

1950년 앨런 튜링은 글로만 대화했을 때 상대가 사람인지 컴퓨터인지 구별하기 어렵다면, 그 컴퓨터를 ‘생각한다’고 볼 수 있는지 질문했습니다. 이것이 **튜링 테스트**입니다.

하지만 자연스러운 말과 실제 이해·책임은 같은 일이 아닐 수 있습니다. AI가 그럴듯하지만 틀린 설명을 만들거나, 중요한 판단의 이유를 충분히 설명하지 못할 수도 있기 때문입니다.

<Callout kind="think" title="짝 토의 — 유창함·이해·책임">
어떤 AI가 시험 문제를 거의 모두 맞히고 질문에도 자연스럽게 답합니다. 그러나 이유를 설명하라고 하면 그럴듯하지만 틀린 답을 만들기도 합니다.

**이 AI는 내용을 이해한 것일까요, 결과를 잘 만들어 낸 것일까요?**

두 사람의 의견을 나눈 뒤, ‘유창하게 말하는 것’과 ‘이해하고 책임지는 것’이 어떻게 다른지 활동지에 적어 보세요.
</Callout>

지금 우리가 사용하는 AI는 대부분 특정 일을 잘 수행하는 **약인공지능(좁은 AI)** 입니다. ‘약’은 성능이 낮다는 뜻이 아닙니다. 사람처럼 어떤 분야에서든 스스로 이해하고 배우며 책임 있게 판단하는 **강인공지능**은 아직 실현되지 않았습니다.

- **인공지능**은 가장 넓은 개념입니다. 사람이 규칙을 직접 설계한 방식과 데이터에서 학습하는 방식을 모두 포함할 수 있습니다.
- **머신러닝**은 사람이 모든 판단 규칙을 직접 작성하는 대신, 데이터에서 패턴을 학습하도록 하는 방법입니다.
- **딥러닝**은 이미지·음성·텍스트처럼 복잡한 데이터를 다루는 데 널리 쓰이는 머신러닝의 한 방법입니다.

지금은 포함 관계와 큰 뜻만 기억하면 충분합니다. 다음 단원에서 사진과 정답을 이용해 모델을 직접 학습시키며, ‘데이터에서 학습한다’는 말의 실제 의미를 확인합니다.

## AI와 사람의 역할

AI는 많은 정보를 빠르게 분석하고 패턴을 찾아 결과를 제시할 수 있습니다. 그러나 무엇을 해결할지 정하고, 어떤 데이터를 사용할지 결정하고, 결과가 실제 상황에서 적절한지 검토하며, 최종 사용을 책임지는 일은 사람의 역할입니다.

<Callout kind="concept" title="오늘 기억할 네 문장">
1. 인공지능은 인간의 지능적 활동과 관련된 기능을 컴퓨터가 수행하도록 구현하는 넓은 분야이다.
2. AI는 인식·검색·학습·추론·예측·판단·생성·문제 해결 등 여러 기능을 수행할 수 있다.
3. 머신러닝은 데이터에서 패턴을 학습하는 방법이고, 딥러닝은 머신러닝의 한 방법이다.
4. AI의 결과를 해석·검증하고 실제 사용을 판단하는 데에는 사람의 역할이 필요하다.
</Callout>
