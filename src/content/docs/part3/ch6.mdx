좋은 협업은 특별한 프롬프트 공식을 외우는 데서 시작하지 않습니다. 먼저 **내가 무엇을 알고 싶고, 왜 필요한지, 현재 어떻게 생각하는지**를 세우는 데서 시작합니다.

<div class="human-loop"><div><b>중심 잡기</b><span>목적·질문·내 생각</span></div><i>→</i><div><b>융합하기</b><span>관점·대안·반론·초안</span></div><i>→</i><div><b>성찰하기</b><span>근거·오류·영향·최종 판단</span></div></div>

## 협업의 다섯 단계

1. **목적을 쓴다**: 어떤 결정을 위해 무엇이 필요한가?
2. **맥락을 제공한다**: 대상, 조건, 이미 확인한 자료, 원하는 결과 형식을 알려준다.
3. **확장을 요청한다**: 다른 관점, 반론, 대안, 빠진 질문을 요청한다.
4. **검증한다**: 핵심 사실·수치·인용은 원자료에서 확인하고 오류·누락·편향을 찾는다.
5. **내 결과로 수정한다**: 받아들인 것과 거부한 이유를 밝히고 최종 판단을 직접 쓴다.

## 질문을 바꾸면 협업이 바뀐다

| 단순 요청 | 사고를 확장하는 요청 |
| --- | --- |
| 해결책 알려줘 | 내가 생각한 원인 세 가지에서 빠진 관점과 반론을 제시해줘 |
| 이 데이터 분석해줘 | 사용한 열·결측 처리·그래프 선택을 먼저 설명하고 분석해줘 |
| 글 써줘 | 내 주장과 근거를 유지한 채 약한 논리를 지적하고 수정안을 제안해줘 |
| 이게 맞아? | 확인이 필요한 주장과 확인할 원자료의 종류를 구분해줘 |

<Callout kind="caution" title="최종 판단을 맡기지 않기">진로·건강·법률·안전처럼 결과의 영향이 큰 문제일수록 AI는 선택지를 정리하고 질문을 넓히는 역할에 머물러야 합니다. 상황을 아는 사람과 전문가가 최종 판단해야 합니다.</Callout>

<Callout kind="concept" title="오늘 기억할 내용">AI의 첫 답을 잘 받는 능력보다 **목적을 세우고, 다른 관점을 끌어내고, 근거를 확인하며, 제안을 수정하거나 거부하는 능력**이 더 중요합니다.</Callout>
