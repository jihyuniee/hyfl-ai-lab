# AI × DATA 첫 작품 전시 — DATA QUEEN

사용자 요청으로 9반2팀 DATA QUEEN의 Re:Cloth를 첫 사례로 전시한다. 제공된 활동지에서 공개용 내용을 별도로 정리했으며 원문 파일을 웹사이트에 복사하지 않는다. 원문에 포함된 비밀정보·학번을 공개 변경 파일에서 제외했으며 키 폐기·재발급을 사용자에게 안내했다. 원문 인증 문자열을 이 기록에도 남기지 않는다.

## 위치와 연결

- 작품집: /hyfl-ai-lab/exhibition/ai-data/
- 작품 상세: /hyfl-ai-lab/exhibition/ai-data/data-queen/
- 기존 첫 프로젝트 전시와 두 번째 작품집은 프로젝트 선택 링크로 연결한다.
- 교과서 8단원의 끝에 굵은 작품 보기 링크를 둔다. 목차 항목은 추가하지 않는다.
- 현재 한 팀만 전시하며 다른 반·팀·수상 결과를 가상으로 만들지 않는다.

## 근거 범위

- 팀명·반·번호·이름·역할·문제 정의·조사 데이터·설계 요청·10/15~10/28 진행 기록은 제공된 활동지를 요약했다.
- KOSIS 링크는 활동지에 적힌 원문을 그대로 연결했다. 지역·기간·단위·수치의 독립 검증이 끝난 자료로 표현하지 않았다.
- 의류수거함이 많다는 것과 폐의류가 적다는 것의 관계는 통계적으로 입증된 결론으로 제시하지 않는다.
- 폐의류 수치 증가, 업체 수거 요금·조건, 재활용 증대 같은 독립 검증되지 않은 수치·효과는 전시의 성과로 옮기지 않았다.
- 활동지 STEP 3-2의 원자료 비교·사용자 테스트, 정식 AI 활용 기록은 비어 있다. 원문 설계 요청과 학생 선택은 소개하되 검증 완료로 꾸미지 않는다.

## 현재 웹앱 확인 2026-11-03

https://dataqueen.vercel.app/ 접속 및 Re:Cloth 제목, 배출 가이드·지도·퀴즈·질문 화면 확인.

배출 가이드에서 ‘솜이불’ 입력 → ‘수거 불가 솜이불’과 관할 구청 처리 안내 메시지 표시를 확인했다. 이는 화면 동작 확인이며 지자체 원자료와의 정확성 대조는 아니다.

지도는 카카오맵 연동 예정이라는 안내와 샘플 수거함 목록을 보여준다. 실시간 지도나 실제 수거함 데이터가 연결되었다고 쓰지 않는다. 퀴즈는3문제 안내와 시작 화면을 확인했다. 생성형 AI 답변·추천 API는 검증하지 않았다. 작품은 ‘제작 중’으로 표시한다.

공개용 소개는 학생의 질문과 의사결정이 중심이 되며 수상·점수·사용자 효과를 임의로 부여하지 않는다. 활동지 내용과 현재 구현은 구분한다. 댓글·심사·등록 폼은 이번 요청 범위에 포함하지 않는다.
