# School Image Lab 전시 기록

2026-11-03 제공받은 9월 제출 자료를 정리해 공개한다. AI × DATA 전시는 보류 상태를 유지한다.

- 총 47팀: 6반 9팀, 7반 9팀, 8반 9팀, 9반 10팀, 10반 10팀.
- 중복 제출(7반 예예, 10반 오서연윤서하·해결해조·서듀 등)은 한 팀으로 합쳤다.
- 6반 동채팀은 뒤에 별도로 제출된 전체 URL을 반영했다.
- 10반 해결해조는 9월 11일의 완전한 GitHub Pages 주소를 반영했다.
- 7반 예서현의 호스트 끝 마침표는 제거했다. 원문 주소는 submittedUrl 필드에 보존했다.
- 학생 학번은 공개 전시 데이터에 넣지 않았다. 팀명과 이름은 제공 자료를 따랐다. 6반 바른자세 팀의 원문 학번 불일치는 이름과 반을 변경할 근거로 사용하지 않았다.
- 원본 웹앱 HTML에서 확인한 표제를 작품명으로 사용했다. 제목이 ‘프로젝트명’이거나 페이지를 읽을 수 없는 경우 팀명 기반 표제로 표시했다.
- 짧은 소개는 원본 웹앱의 소개·표제를 요약했다. 소개가 확인되지 않는 라을라·졸리당은 임의 내용을 작성하지 않았다.
- 2026-11-03 HTTP 요청에서 46팀 페이지 응답 200, 8반 졸리당은 404였다. 404 작품도 전시에 보존한다.
- HTTP 200을 카메라·모델·결과의 정상 작동으로 표현하지 않는다. 제출 당시 학생 보고와 현재 페이지 응답을 별도 표시한다.
- 아직 제공되지 않은 네 질문의 답변과 검증 결과는 꾸며 넣지 않는다. 학생 작성 후 데이터 파일의 question/dataFinding/demonstration/verification 필드를 채울 수 있다.

## 위치

전시: /hyfl-ai-lab/exhibition/school-image-lab/

작품 데이터: src/data/school-image-lab.json

교과서 상단 SiteTitle 옆에 작은 ‘학생 작품’ 링크를 둔다. 교과서 목차·수업 순서는 바꾸지 않는다. 전시는 별도 레이아웃이며, 등록·평가·GitHub 이슈 연동을 추가하지 않는다. 학생 웹앱은 외부 새 창으로 열고 iframe으로 자동 실행하지 않는다.

## 미리보기와 수업 연결

작품 카드의 미리보기 버튼을 누를 때만 별도 iframe을 만든다. 47개 웹앱을 자동으로 불러오지 않는다. 닫거나 Escape로 나가면 iframe을 제거한다. iframe은 카메라·마이크·위치·자동재생 권한을 위임하지 않으며, 실제 체험은 원본 웹앱 새 창 링크로 제공한다. HTTP 404로 기록된 작품의 미리보기 버튼은 비활성화한다. 미리보기 로드 성공을 모델 정상 작동으로 표시하지 않는다.

전시 상단에 문제 정의·데이터 설계·새 조건에서의 테스트·오류 개선·사람의 판단이라는 프로젝트 의미를 소개한다. School Image Lab 단원 도입에 ‘이 프로젝트의 작품 보기’ 링크를 HTML strong으로 표시한다. 기존 remark 플러그인이 텍스트 노드의 별표를 처리하므로 굵기는 실제 렌더링 결과로 확인한다.

## 카드 화면 미리보기와 동료평가

2026-11-03 제공된 반별 동료평가 결과를 peerRank/peerJoint에 기록했다. 6반 2조·1조·동채팀, 7반 희재·유도/엽떡(공동2등), 8반 쩝쩝박사팀·급식수호대·졸리당, 9반 팀 휴식·팀명뭐하제인·콩나물국, 10반 오서연윤서하·IN AND OUT·해결해조를 표창 대상으로 반영한다. 전체47팀 중15팀이며, 표시명 차이는 기존 팀과 구성원을 대조해 연결했다. 명단의 권다온/권다은 차이는 순위 반영을 위한 이름 변경 근거로 사용하지 않고 기존 제출 명단을 보존했다.

우수팀을 목록 앞쪽에 정렬하고 반 안에서는 순위순으로 배치한다. 공동 순위끼리는 기존 제출 순서만 사용한다. 별표에는 ‘동료평가 우수팀’, 범례에는 ‘동료평가에서 우수한 성적을 거둔 팀’을 표시한다. 세부 정보에서 반별 순위를 볼 수 있다. 반 사이의 통합 점수나 전체 순위를 만들지 않는다.

카드의 실제 웹앱 화면은 축소 iframe으로 표시한다. IntersectionObserver로 화면에 들어온 카드만 실행하고 동시에 최대3개를 유지한다. 화면 밖·검색으로 숨긴 카드는 iframe을 제거한다. 썸네일의 입력/포커스는 막고 카메라·마이크·자동재생 권한도 위임하지 않는다. 클릭하면 기존 큰 미리보기를 제공한다. 실제 웹앱 화면을 사용하며 가상의 스크린샷이나 생성 이미지로 대체하지 않는다.
