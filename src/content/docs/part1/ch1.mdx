## 생각을 여는 질문

<Callout kind="question">
“인공지능이 뭐야?”라고 물었을 때 가장 먼저 ChatGPT가 떠오르나요?

그렇다면 얼굴 인식, 유튜브 추천, 번역, 내비게이션, 스팸 필터도 왜 모두 인공지능이라고 부를까요?
</Callout>

우리가 가장 자주 만나는 AI가 ChatGPT 같은 생성형 AI이기 때문에 **AI = GPT**처럼 느끼기 쉽습니다. 하지만 ChatGPT는 인공지능 전체가 아니라, 인공지능이라는 훨씬 큰 분야 안에 있는 하나의 서비스입니다.

이번 학기에는 특정 AI 서비스의 사용법을 배우는 데서 멈추지 않습니다. **AI가 무엇을 할 수 있는지 이해하고, 그것을 어떤 문제에 어떻게 활용할 것인지 판단하는 힘**을 기릅니다.

## 학습 목표

1. 인공지능을 특정 서비스가 아닌 큰 기술 개념으로 설명할 수 있다.
2. 생활 속 AI가 수행하는 다양한 지능적 활동을 사례와 연결할 수 있다.
3. 문제 해결 과정에서 AI와 사람이 맡아야 할 일을 구분할 수 있다.

---

## 왜 이것들을 모두 AI라고 부를까?

사람은 주변을 보고 알아보고, 경험에서 배우고, 다음 상황을 예상하고, 여러 선택지 중 하나를 고르고, 새로운 것을 만들어 문제를 해결합니다.

컴퓨터가 이런 활동의 일부를 수행하도록 만든 기술을 인공지능이라고 부릅니다.

<Callout kind="concept" title="인공지능의 정의">
인공지능(AI)은 컴퓨터가 인식, 학습, 추론·예측, 생성, 문제 해결처럼 인간의 지능과 관련된 활동을 수행하도록 만드는 기술 전체를 가리킵니다.
</Callout>

### 생활 속 사례

| 우리가 사용하는 것 | AI가 하는 일 |
| --- | --- |
| 스마트폰 얼굴 인식 | 사람의 얼굴을 인식·분류 |
| 유튜브·넷플릭스 | 관심 가질 콘텐츠를 추천 |
| 지도 앱 | 교통 상황과 도착 시간을 예측 |
| 번역 서비스 | 언어를 분석하고 다른 언어로 변환 |
| 스팸 필터 | 정상 메일과 스팸을 분류 |
| ChatGPT 같은 생성형 AI | 글·코드·아이디어 등을 생성하고 여러 작업을 지원 |

즉, **AI의 모습은 하나가 아닙니다.** 해결하려는 문제에 따라 AI가 맡는 역할도 달라집니다.

## 자동으로 움직이면 모두 AI일까?

정해진 시간에 울리는 알람은 사람이 만든 규칙을 그대로 실행합니다. 반면 사용자의 수면 기록을 분석해 적절한 기상 시간을 추천하는 서비스는 데이터에서 패턴을 찾아 새로운 결과를 만듭니다.

자동화와 AI는 겹칠 수 있지만 같은 뜻은 아닙니다. AI인지 판단할 때는 서비스 이름보다 **결과가 어떤 방식으로 만들어지는가**를 살펴보는 것이 중요합니다.

## AI는 왜 문제 해결 도구일까?

AI를 배우는 목적은 AI보다 더 빨리 계산하거나 모든 코드를 직접 작성하기 위해서가 아닙니다.

우리가 해결하고 싶은 문제가 있을 때 AI는 많은 자료를 정리하고, 패턴을 찾고, 아이디어를 확장하고, 여러 해결안을 비교하는 데 도움을 줄 수 있습니다.

하지만 다음은 사람이 정해야 합니다.

- 누구의 어떤 문제를 해결할 것인가?
- 이 문제가 정말 해결할 가치가 있는가?
- AI가 실제로 필요한가?
- AI의 결과를 믿어도 되는가?
- 잘못되었을 때 어떤 피해가 생길 수 있는가?
- 최종 결정에 누가 책임질 것인가?

<Callout kind="mission" title="이번 학기의 관점">
AI를 단순히 답을 대신 만들어주는 존재가 아니라, 사람이 더 어려운 문제에 도전하도록 돕는 **문제 해결 도구**로 바라봅니다.
</Callout>

## 핵심 정리

<Callout kind="concept" title="오늘 기억할 세 문장">
1. AI는 ChatGPT라는 하나의 서비스가 아니라 지능적 활동을 컴퓨터가 수행하도록 만드는 큰 기술 분야다.
2. AI는 인식·분류·예측·추천·생성 등 서로 다른 방식으로 문제 해결을 돕는다.
3. AI가 강력해질수록 사람에게는 문제를 정의하고 결과를 판단하며 책임지는 능력이 더 중요해진다.
</Callout>
