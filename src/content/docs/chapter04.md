지난 시간까지는 이론이었습니다. 이번 시간은 순서를 뒤집습니다. **먼저 컴퓨터를 학습시켜보고, 그 다음에 방금 한 일이 무엇이었는지 이름을 붙입니다.**

## 맛보기 실습 — Teachable Machine으로 1시간 만에 모델 만들기

:::tip[함께 해보기 — Teachable Machine]
[Teachable Machine](https://teachablemachine.withgoogle.com/)에 접속해서 **이미지 프로젝트**를 새로 만드세요. 아래 중 하나를 골라 나만의 분류기를 만들어봅니다.

- 손 펴기 ✋ / 주먹 ✊
- 안경 있음 👓 / 안경 없음
- 물병 / 필통

**진행 순서**

1. Class 1, Class 2에 이름을 붙인다 (예: "펴기", "주먹").
2. 웹캠으로 각 클래스마다 사진을 최소 30장 이상 찍는다. 각도와 배경을 조금씩 바꿔가며 찍어본다.
3. **Train Model** 버튼을 눌러 학습시킨다.
4. 웹캠 앞에서 직접 테스트해보고, 얼마나 잘 맞히는지 확인한다.
5. 옆 친구에게 와서 같은 동작을 해보게 하고 다시 테스트한다.

친구가 테스트했을 때 결과가 어땠나요? 나에게는 잘 맞았는데 친구에게는 틀렸다면, 왜 그럴까요? 이 질문은 잠시 넣어두었다가 [Part 3 프로젝트](/hyfl-ai-lab/chapter05/)에서 제대로 다룹니다.
:::

## 방금 한 일에 이름 붙이기

방금 여러분은 컴퓨터에게 "이 사진은 Class 1, 저 사진은 Class 2"라고 **정답을 알려주면서** 학습시켰습니다. 머신러닝은 이렇게 컴퓨터에게 정답을 주는 방식이냐, 주지 않는 방식이냐, 아니면 시행착오를 통해 점수를 주는 방식이냐에 따라 세 가지 유형으로 나뉩니다.

### 지도학습 (Supervised Learning)

**데이터에 정답(레이블)을 붙여서 학습시키는 방식.** 방금 만든 Teachable Machine 모델이 정확히 여기에 해당합니다. "이 사진 = Class 1"이라고 정답을 알려줬으니까요.

지도학습은 다시 두 가지로 나뉩니다.

- **분류(Classification)**: 정답이 "이것 아니면 저것"처럼 범주로 나뉘는 경우. (예: 스팸/정상, 펴기/주먹)
- **회귀(Regression)**: 정답이 연속된 숫자인 경우. (예: 내일 기온 예측, 집값 예측)

### 비지도학습 (Unsupervised Learning)

**정답(레이블) 없이 데이터만 주고, 데이터 사이의 관계나 패턴을 스스로 찾게 하는 방식.** 대표적인 방법이 **군집화(Clustering)**로, 비슷한 특성을 가진 데이터끼리 스스로 묶는 것입니다. 예를 들어 쇼핑몰이 고객 데이터를 성별·나이 같은 정답표 없이 구매 패턴만으로 몇 개의 그룹으로 자동으로 나누는 경우가 여기 해당합니다.

### 강화학습 (Reinforcement Learning)

**정답을 알려주는 대신, 행동을 하게 하고 그 결과에 보상(또는 벌점)을 주는 방식.** AI는 보상을 최대화하는 방향으로 행동을 조금씩 개선해갑니다. 게임을 스스로 플레이하며 실력을 키우는 AI, 로봇이 걷는 법을 시행착오로 익히는 경우가 여기 해당합니다.

## 정리 표

| 유형 | 정답(레이블) | 대표 방법 | 예시 |
| --- | --- | --- | --- |
| 지도학습 | 있음 | 분류 / 회귀 | Teachable Machine, 스팸 필터, 집값 예측 |
| 비지도학습 | 없음 | 군집화 | 고객 그룹 자동 분류 |
| 강화학습 | 없음 (대신 보상) | 행동 → 보상 | 게임 AI, 로봇 제어 |

:::note[생각해보기]
방금 만든 Teachable Machine 모델은 지도학습 중에서도 분류일까요, 회귀일까요? 왜 그렇게 생각하나요?
:::

## 정리

- 이번 시간에는 이론보다 먼저 Teachable Machine으로 직접 분류 모델을 만들어봤다.
- 정답(레이블)을 주고 학습시키는 것이 **지도학습**이며, 그 안에 분류와 회귀가 있다.
- 정답 없이 패턴을 스스로 찾는 것이 **비지도학습**(군집화), 시행착오와 보상으로 학습하는 것이 **강화학습**이다.
