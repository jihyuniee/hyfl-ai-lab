## 시작 전, 큰 지도만 확인하기

오늘 모든 용어를 외울 필요는 없습니다. 지금 우리가 어디에 있는지만 확인합니다.

```text
인공지능 AI
└─ 머신러닝 Machine Learning
   └─ 딥러닝 Deep Learning
```

- **인공지능(AI)**: 컴퓨터가 인식, 분류, 예측, 추천, 생성 등 지능과 관련된 작업을 수행하도록 만드는 기술과 연구 분야입니다.
- **머신러닝(ML)**: 사람이 모든 판단 규칙을 직접 작성하는 대신, 데이터에서 패턴을 학습하도록 하는 방법입니다.
- **딥러닝(DL)**: 머신러닝의 방법 가운데 하나로, 여러 층의 인공신경망을 이용해 복잡한 패턴을 학습합니다.

<Callout kind="think">
이 정의를 지금 완벽하게 기억하려 하지 마세요. 직접 모델을 학습시킨 뒤 다시 읽으면 의미가 달라질 수 있습니다.
</Callout>

## 개인 실험 · 내가 AI의 선생님이 되어보자

[Teachable Machine](https://teachablemachine.withgoogle.com/)을 이용해 두 개의 클래스를 구분하는 작은 이미지 분류 모델을 만듭니다.

예: 손 펴기/주먹 · 펜/지우개 · 물병/필통 등

<Steps>
	<Step title="분류 문제 정하기">사진만 보고 비교적 구별할 수 있는 두 가지 대상을 정합니다.</Step>
	<Step title="첫 학습 데이터 모으기">각 클래스의 사진을 직접 촬영합니다. 처음에는 완벽한 데이터를 만들려고 하지 않습니다.</Step>
	<Step title="첫 번째 모델 학습">수집한 데이터로 모델을 학습시킵니다.</Step>
	<Step title="익숙한 조건에서 테스트">학습 데이터를 찍을 때와 비슷한 사람·거리·배경·조명에서 결과를 확인합니다.</Step>
	<Step title="새로운 조건에서 테스트">다른 친구, 다른 거리, 다른 각도, 다른 배경이나 조명에서 다시 테스트합니다.</Step>
	<Step title="AI를 일부러 틀리게 만들기">모델이 잘못 판단하는 조건을 찾아 기록합니다. 실패 사례가 오늘 가장 중요한 자료입니다.</Step>
	<Step title="원인 추측하기">왜 틀렸는지 생각합니다. 특정 사람이나 배경만 보았는지, 각도가 부족했는지, 두 클래스의 데이터 양이 다른지 살펴봅니다.</Step>
	<Step title="데이터 개선 후 재학습">가설에 따라 데이터 한 가지를 바꾸고 같은 조건에서 다시 테스트합니다.</Step>
</Steps>

## 경험한 것에 이름 붙이기

설명부터 외우지 않고 먼저 모델을 만들고 실패시켜보았습니다. 이제 방금 경험한 상황에 필요한 개념의 이름을 붙여봅니다.

### 학습 데이터 Training Data

모델이 패턴을 배우는 데 사용한 데이터입니다. 방금 여러분이 모델을 학습시키기 위해 촬영한 이미지들이 학습 데이터에 해당합니다.

### 테스트 데이터 Test Data

모델이 학습한 패턴이 새로운 데이터에서도 잘 작동하는지 확인하기 위한 데이터입니다.

<Callout kind="concept" title="중요한 원칙">
학습할 때 본 사진을 잘 맞히는 것만으로는 모델이 실제로 잘 학습했다고 말하기 어렵습니다. **학습에 사용하지 않은 새로운 데이터에서도 잘 작동하는지 확인해야 합니다.**
</Callout>

### 일반화 Generalization

학습할 때 보지 못했던 새로운 입력에서도 적절한 결과를 만드는 능력을 **일반화**라고 합니다.

> 좋은 모델은 학습한 사진을 단순히 기억하는 데서 끝나지 않고, 새로운 상황에서도 학습한 패턴을 활용할 수 있어야 합니다.

### 과대적합 Overfitting

학습 데이터에서는 매우 잘 작동하지만 새로운 데이터에서는 성능이 크게 떨어지는 현상을 **과대적합**이라고 합니다.

예를 들어 한 사람, 한 장소, 한 배경에서만 비슷한 사진을 반복해서 학습하면 그 조건에 지나치게 맞춰질 수 있습니다. 실제 모델의 성능에는 데이터의 양뿐 아니라 다양성, 품질, 학습 방법 등 여러 요소가 영향을 줍니다.

<Callout kind="caution" title="AI는 내가 의도한 것만 배우는 것이 아니다">
가위 사진은 항상 창문 앞에서, 바위 사진은 항상 모니터 앞에서 촬영했다면 모델이 손 모양뿐 아니라 배경과 함께 나타난 패턴을 판단에 이용할 수 있습니다.

그래서 **어떤 데이터를 어떻게 모으는가**가 중요합니다.
</Callout>

## 데이터 → 학습 → 모델 → 테스트 → 개선

```text
문제 정의
   ↓
학습 데이터 수집
   ↓
학습
   ↓
모델
   ↓
새로운 데이터로 테스트
   ↓
오류 발견
   ↓
데이터·방법 개선
   ↓
다시 학습하고 테스트
```

머신러닝은 한 번 학습시키고 끝나는 과정이 아닙니다. 새로운 데이터에서 실패하는 상황을 확인하고 그 원인을 분석하며 개선하는 과정이 중요합니다.

## 오늘은 지도학습 중 '분류'를 경험했습니다

여러분은 이미지마다 "펜", "지우개"처럼 정답 범주를 붙여 모델을 학습시켰습니다. 이처럼 정답이 있는 데이터를 이용하는 방식을 **지도학습(Supervised Learning)**이라고 합니다.

오늘처럼 결과가 여러 범주 가운데 하나로 나뉘는 문제를 **분류(Classification)**라고 합니다.

머신러닝에는 이 밖에도 정답 없이 데이터의 구조나 패턴을 찾는 비지도학습, 행동의 결과에 따른 보상을 이용해 전략을 학습하는 강화학습 등 다양한 방법이 있습니다. 이번 시간에는 세 유형을 외우는 것보다 **직접 경험한 이미지 분류가 어떤 방식인지 이해하는 것**에 집중합니다.

## AI와 사람은 어떤 일을 했을까?

| AI가 한 일 | 사람이 한 일 |
| --- | --- |
| 이미지의 수치적 특징 처리 | 무엇을 구분할지 문제 정의 |
| 데이터에서 반복되는 패턴 학습 | 클래스와 데이터 수집 기준 결정 |
| 새로운 이미지의 범주와 가능성 제시 | 실패 조건을 찾고 원인 가설 세우기 |
| 같은 방식으로 빠르게 예측 | 결과의 의미와 실제 사용 가능성 판단 |

<Callout kind="reflect" title="학습의 주인은 누구인가">
AI가 모델을 학습했지만, **학습 목표를 정하고 결과를 해석하며 개선 방향을 판단한 것은 사람**입니다.
</Callout>
