1. 인공지능이란 무엇일까?

인간의 지능적 활동에서 출발해 AI, 머신러닝, 딥러닝의 큰 개념을 질문과 사례로 이해합니다.

먼저, 이것도 AI일까?

💭 생각을 여는 질문

다음 기능 가운데 AI라고 생각하는 것을 골라보세요. 정답부터 찾기보다, 왜 그렇게 생각했는지 기준을 한 가지 말해보는 것이 더 중요합니다.

💬 짝과 1분 이야기

‘자동으로 작동한다’는 것과 ‘인공지능이다’라는 것은 같은 뜻일까요?

내가 AI를 구분할 때 사용한 기준은 무엇이었는지 친구와 비교해봅시다.

아직 정답을 확정하지 않아도 됩니다. 오늘은 먼저 AI를 구분할 수 있는 기준을 만들어봅니다.

인공 + 지능, 말뜻부터 살펴보기

인공(人工)은 사람이 만들었다는 뜻이고, 지능(知能)은 정보를 받아들이고 배우며, 추론하고 판단하여 문제를 해결하는 능력을 뜻합니다.

그렇다면 사람이 지능을 사용한다는 것은 구체적으로 어떤 일을 하는 것일까요?

1. 인식무엇인지 알아보기
2. 추론·예측정보와 패턴으로 예상하기
3. 판단·결정선택하고 결정하기
4. 행동·문제 해결결과를 실제 작업으로 옮기기

여기에 학습도 매우 중요합니다. 사람은 경험과 정보를 통해 배우고, 그 경험을 다음 판단에 활용합니다. 이 과정이 언제나 하나의 고정된 순서로 일어나는 것은 아닙니다.

📚 인공지능(AI)이란?

인공지능(AI)은 인간의 지능적 활동과 관련된 기능을 컴퓨터 시스템이 수행하도록 구현하는 기술과 연구 분야입니다.

인식, 학습, 추론, 예측, 판단, 생성, 문제 해결 등 다양한 기능이 포함될 수 있습니다.

AI가 인간과 똑같이 생각한다는 뜻은 아닙니다. 실제 AI 시스템은 데이터, 규칙, 통계·확률, 학습된 패턴, 계산과 여러 도구를 이용하여 결과를 만듭니다.

✏️ 한 문장으로 바꿔 말해보기

‘인공지능’을 아직 교과서 문장 그대로 외우지 마세요. “컴퓨터가 어떤 일을 할 때 우리는 그것을 지능적인 활동이라고 볼 수 있을까?”를 생각하며 자기 말로 설명해봅시다.

자동으로 움직이면 모두 AI일까?

상황 A — 정해진 알람

IF 현재 시간이 오전 7시라면
THEN 알람을 울린다.

사람이 미리 정한 조건을 그대로 실행합니다. 입력된 시간이 같으면 언제나 같은 방식으로 작동합니다.

상황 B — 나에게 맞춰 시간을 정하는 알람

어떤 시스템이 평소 기상 시간, 오늘 첫 일정, 예상 이동 시간, 최근 수면 패턴을 살펴보고 “오늘은 6시 42분쯤 깨우는 것이 좋겠다”고 예상한다면 어떨까요?

💬 두 알람의 차이는 무엇일까?

A와 B는 모두 자동으로 작동합니다. 그런데 두 시스템은 어떤 정보를 사용하고, 결과를 어떻게 결정하는지에서 어떤 차이가 있을까요?

⚠️ AI = 반드시 스스로 학습하는 프로그램?

그렇지는 않습니다. AI를 구현하는 방법에는 사람이 지식과 판단 규칙을 직접 설계하는 규칙 기반 방식도 있고, 데이터를 이용해 패턴을 학습하는 학습 기반 방식도 있습니다.

따라서 ‘데이터를 학습하는가?’는 현대 AI를 이해하는 매우 중요한 기준이지만, AI 전체를 가르는 유일한 기준은 아닙니다.

AI는 규칙을 어떻게 알게 될까?

컴퓨터가 어떤 판단을 하려면 결국 어떤 기준으로 결과를 정할 것인지가 필요합니다.

A. 사람이 규칙을 직접 만든다면

IF 제목에 ‘당첨’이 있고
   본문에 ‘무료’라는 단어가 여러 번 나오면
THEN 스팸으로 분류한다.

B. 여러 사례를 보여주고 패턴을 찾게 한다면

스팸 메일 사례 + 정상 메일 사례
          ↓
        학습
          ↓
       분류 모델
          ↓
새로운 메일 → 스팸일 가능성 예측
비교규칙 기반 방식학습 기반 방식
판단 기준사람이 규칙을 직접 설계데이터에서 패턴을 학습
사람이 주로 준비하는 것지식과 규칙데이터와 학습 방법
새로운 상황 처리작성된 규칙의 범위에 크게 의존학습한 패턴을 바탕으로 새로운 입력을 예측
중요한 질문규칙을 빠뜨리지는 않았을까?어떤 데이터로 무엇을 학습했을까?
💭 누가 규칙을 만들었을까?

A와 B의 가장 큰 차이를 한 문장으로 말해보세요. 사람이 직접 규칙을 적은 것과, 데이터에서 패턴을 찾도록 한 것은 어떻게 다를까요?

인공지능 → 머신러닝 → 딥러닝

인공지능을 구현하는 모든 방법이 머신러닝은 아닙니다. 머신러닝은 인공지능을 구현하는 중요한 방법 가운데 하나입니다.

┌──────────────── 인공지능 AI ────────────────┐
│                                               │
│      ┌──────── 머신러닝 ML ─────────┐         │
│      │                              │         │
│      │    ┌── 딥러닝 DL ─────┐      │         │
│      │    │                  │      │         │
│      │    └──────────────────┘      │         │
│      └──────────────────────────────┘         │
│                                               │
└───────────────────────────────────────────────┘

머신러닝 Machine Learning

머신러닝은 사람이 모든 판단 규칙을 하나하나 작성하는 대신 데이터를 통해 패턴을 학습하도록 하는 방법입니다.

데이터 → 학습 → 모델 → 새로운 입력 → 예측·분류·추천

예를 들어 고양이와 강아지 이미지와 정답을 이용해 학습한 모델은 학습 과정에서 얻은 패턴을 이용하여 처음 보는 이미지가 어느 범주에 가까운지 예측할 수 있습니다.

딥러닝 Deep Learning

딥러닝은 머신러닝의 방법 가운데 하나로, 여러 층의 인공신경망을 이용해 데이터의 특징과 복잡한 패턴을 학습하는 방법입니다.

✏️ 큰 지도 확인
  1. 모든 AI는 딥러닝일까요?
  2. 모든 머신러닝은 딥러닝일까요?
  3. 딥러닝은 인공지능이라는 큰 분야 안에 포함될까요?

컴퓨터가 ‘학습한다’는 말은 무슨 뜻일까?

머신러닝에서 학습은 보통 주어진 데이터에서 반복적으로 나타나는 관계와 패턴을 찾아, 새로운 입력에 대한 결과를 더 잘 만들어내도록 모델의 내부 값을 조정하는 과정을 뜻합니다.

즉, 컴퓨터가 교과서를 읽고 의미를 사람처럼 깨닫는다는 뜻으로 ‘학습’이라는 말을 사용하는 것은 아닙니다.

✏️ 곧 직접 확인합니다

곧 작은 이미지 분류 모델을 직접 학습시키고, 일부러 실패하게도 만들어보면서 ‘데이터에서 패턴을 학습한다’는 말이 실제로 무엇을 뜻하는지 확인합니다.

1950년, 앨런 튜링이 던진 질문

영국의 수학자 앨런 튜링(Alan Turing)은 1950년 논문에서 훗날 튜링 테스트라고 불리게 된 ‘모방 게임’의 아이디어를 제안했습니다.

나  ←── 글로만 대화 ──→  벽 너머의 상대

상대는 사람일 수도 있고 컴퓨터일 수도 있다.
나는 대화만 보고 그것을 구별해야 한다.

대화를 충분히 나눈 뒤에도 사람이 상대가 컴퓨터인지 사람인지 잘 구분하지 못한다면, 우리는 그 컴퓨터의 지능을 어떻게 바라봐야 할까요?

💬 사람처럼 말한다 = 이해한다?

사람처럼 매우 자연스럽고 유창하게 말하는 것과, 그 말의 의미를 실제로 이해하는 것은 같은 일일까요?

  • 같다고 생각한다면, 왜 그런가요?
  • 다르다고 생각한다면, 무엇이 더 필요할까요?

튜링 테스트는 ‘지능이 무엇인가’라는 어려운 질문을 관찰할 수 있는 행동을 통해 생각해보게 했다는 점에서 중요한 의미가 있습니다. 하지만 사람처럼 그럴듯한 답을 만들어내는 능력만으로 이해, 의식, 책임까지 모두 증명되는 것은 아닙니다.

지금 우리가 사용하는 AI는 어떤 AI일까?

현재 우리가 일상에서 사용하는 AI는 대부분 특정한 목적과 범위의 작업을 수행하도록 만들어진 AI입니다. 흔히 좁은 AI(Narrow AI) 또는 전통적으로 약인공지능이라고 부릅니다. ‘약’이라는 말은 성능이 낮다는 뜻이 아닙니다.

좁은 AI의 예잘하도록 만들어진 작업의 예
얼굴 인식 시스템이미지 속 얼굴의 특징을 비교·인식
추천 시스템사용자의 이용 패턴을 바탕으로 콘텐츠 추천
번역 AI언어 사이의 문장 변환
바둑 AI바둑 상태를 분석하고 다음 수 선택
생성형 AI텍스트·이미지·코드 등 다양한 결과 생성

반면 사람처럼 여러 분야와 새로운 상황을 폭넓게 이해하고 다양한 문제를 스스로 배우며 해결할 수 있는 범용적인 지능은 보통 범용 인공지능(AGI) 또는 문맥에 따라 강인공지능이라는 말로 이야기합니다.

💭 생성형 AI는 여러 일을 하는데?

‘여러 작업을 할 수 있다’는 것과 ‘사람처럼 세상을 폭넓게 이해하는 범용지능을 가졌다’는 것은 같은 말일까요?

AI가 결과를 내놓으면 그대로 믿어도 될까?

AI는 데이터에서 패턴을 찾고 빠르게 분석·예측할 수 있습니다. 그러나 결과가 나왔다는 것과 그 결과가 좋은 판단이라는 것은 다릅니다.

  • 어떤 이미지로 학습했는가?
  • 학습할 때 보지 못했던 새로운 사진에서도 잘 작동하는가?
  • 대상 자체가 아니라 배경이나 촬영 환경을 잘못 학습한 것은 아닌가?
  • 이 결과가 틀렸을 때 어떤 문제가 생기는가?
  • 실제 상황에서 이 결과를 사용해도 되는가?
📚 이번 학기의 중요한 관점

AI는 패턴을 찾고 결과를 제시할 수 있습니다. 사람은 그 결과가 무엇을 의미하는지 맥락 속에서 해석하고, 검증하며, 최종적으로 판단해야 합니다.

서비스 이름과 기술 이름을 구분하기

ChatGPT, Gemini, Perplexity 등은 회사가 제공하는 서비스 또는 제품의 이름입니다. 반면 인공지능, 머신러닝, 딥러닝, 대규모 언어 모델(LLM)은 기술이나 모델을 설명하는 개념의 이름입니다.

서비스의 기능과 내부 구조는 시간이 지나면서 달라질 수 있습니다. 따라서 특정 서비스 하나의 특징을 인공지능 전체의 특징이라고 생각하지 않습니다.

오늘의 정리

📚 오늘 기억할 네 문장
  1. 인공지능은 인간의 지능적 활동과 관련된 기능을 컴퓨터가 수행하도록 구현하는 넓은 기술 분야이다.
  2. AI를 만드는 방법에는 사람이 규칙을 직접 설계하는 방식도 있고, 데이터를 통해 패턴을 학습하는 방식도 있다.
  3. 머신러닝은 데이터에서 패턴을 학습하는 AI의 중요한 방법이고, 딥러닝은 머신러닝의 한 방법이다.
  4. AI가 만든 결과를 실제 상황에서 어떻게 해석하고 사용할지는 사람이 검증하고 판단해야 한다.
🎟️ 활동지에 자기 말로 정리하기

1. 인공지능이란 ______________________________ 이다.

교과서 문장을 그대로 옮기기보다 오늘 처음 AI를 배우는 사람에게 설명한다는 생각으로 한 문장을 만들어보세요.

2. AI와 일반 프로그램을 구분하려 할 때, 무엇을 확인해보면 좋을까요?

  • 어떤 정보를 입력으로 사용하는가?
  • 결과는 어떤 방식으로 결정되는가?
  • 사람이 모든 판단 규칙을 직접 정했는가?
  • 데이터에서 패턴을 학습하는가?
  • 새로운 상황에서도 예측이나 판단을 해야 하는가?

한 가지 질문만으로 모든 AI를 완벽하게 구분할 수는 없습니다. 시스템이 어떤 지능적 기능을 어떤 방식으로 구현하고 있는지 함께 살펴보는 것이 중요합니다.

다음 시간으로 이어지는 질문

“AI는 데이터에서 패턴을 학습한다.”

그런데 컴퓨터가 학습한다는 것은 실제로 무슨 뜻일까요? 다음 활동에서는 작은 이미지 분류 AI를 직접 만들고 데이터를 보여주고, 모델을 학습시키고, 처음 보는 데이터로 확인하고, 일부러 틀리게도 만들어봅니다.

그 경험 뒤에 학습 데이터, 테스트 데이터, 일반화, 과대적합이라는 개념에 이름을 붙입니다.
