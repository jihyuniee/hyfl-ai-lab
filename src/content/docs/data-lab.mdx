<Callout kind="mission" title="공통 미션">같은 사회 현상을 서로 다른 질문으로 조회하고, 조건에 따라 달라지는 결과를 비교한 뒤 공식 통계로 핵심 수치를 검증합니다.</Callout>

## 먼저 예측합니다

AI를 연결하기 전에 개인의 예상부터 기록합니다.

1. 어떤 변화가 나타날 것이라고 예상하는가?
2. 그 판단에 필요한 지표는 무엇인가?
3. 전국 평균과 우리 지역은 같을 것인가?
4. 결과가 예상과 다르면 무엇을 바꿔 생각해야 하는가?

## 탐정 미션

<Steps>
<Step title="큰 질문 분해">주어진 사회 문제를 데이터로 확인할 수 있는 작은 질문 세 개로 나눕니다.</Step>
<Step title="질문별 지표 후보 찾기">MCP로 관련 통계가 존재하는지 탐색하고 지표의 정의를 비교합니다.</Step>
<Step title="조건 하나씩 바꾸기">기간·지역·연령·성별·절대값과 비율 중 하나를 바꾸어 결과 차이를 확인합니다.</Step>
<Step title="표와 그래프 요청">같은 데이터를 표와 적절한 그래프로 표현하고 그래프 선택 이유를 설명하게 합니다.</Step>
<Step title="증거 카드 만들기">출처·통계표·기간·단위·조회 조건·핵심 수치를 한 장에 기록합니다.</Step>
<Step title="원 통계표 교차 확인">발표에 사용할 핵심 수치 두 개 이상을 공식 페이지에서 다시 확인합니다.</Step>
<Step title="주장 범위 정하기">확인한 사실, 가능한 해석, 알 수 없는 원인, 추가로 필요한 자료를 나눕니다.</Step>
</Steps>

## 같은 질문처럼 보여도 결과가 달라집니다

| 선택 | 확인할 점 |
| --- | --- |
| 사람 수와 비율 | 전체 인구가 달라지면 같은 현상도 다르게 보일 수 있다 |
| 전국과 특정 지역 | 전국 평균이 지역의 차이를 가릴 수 있다 |
| 1년과 10년 | 짧은 변동과 장기 추세를 구분해야 한다 |
| 전체와 연령·성별 집단 | 전체 값만으로 집단별 차이를 설명할 수 없다 |
| 합계와 평균 | 집단의 규모와 분포를 함께 살펴야 한다 |

<Callout kind="concept" title="그래프가 만들어졌다고 분석이 끝난 것은 아닙니다">그래프는 선택한 지표·기간·비교 대상·축의 범위를 보여 주는 표현입니다. 어떤 조건을 선택했는지에 따라 같은 데이터도 다른 인상을 줄 수 있습니다.</Callout>

## 사실·해석·원인 가설 구분하기

| 구분 | 의미 | 문장 시작 |
| --- | --- | --- |
| 확인한 사실 | 표와 그래프에서 직접 확인한 수치·차이·변화 | “자료에 따르면…” |
| 가능한 해석 | 그 변화가 사람과 사회에 가질 수 있는 의미 | “이는 …와 관련될 수 있다.” |
| 원인 가설 | 왜 나타났는지에 대한 추가 확인이 필요한 추측 | “가능한 원인으로 …를 생각할 수 있으나…” |
| 확인 불가 | 현재 자료에 포함되지 않아 판단할 수 없는 내용 | “이 자료만으로는 …를 알 수 없다.” |

두 값이 함께 증가하거나 감소해도 하나가 다른 하나의 원인이라고 바로 결론 내릴 수 없습니다.

## 결과가 이상할 때 되묻기

```text
방금 사용한 도구와 조회 조건을 다시 보여줘.
통계표 이름, 항목, 단위, 기간, 지역을 빠짐없이 적어줘.
원자료에 있는 값과 네가 계산한 값을 구분해줘.
계산했다면 계산식과 사용한 값을 보여줘.
서로 다른 기준의 통계를 섞지 않았는지 점검해줘.
확실하지 않은 내용은 추측하지 말고 확인 필요로 표시해줘.
```

<Callout kind="caution" title="MCP도 자동 정답 기계는 아닙니다">공식 데이터에 연결되어도 AI가 질문을 잘못 이해하거나 부적절한 통계표를 선택하고, 단위를 혼동하거나 해석을 과장할 수 있습니다. 연결된 데이터의 신뢰성과 AI가 내린 해석의 신뢰성은 같은 문제가 아닙니다.</Callout>

## 공통 미션 산출물

- 처음 예상과 데이터 질문 세 개
- 사용한 MCP와 조회 기능
- 조건을 바꾸어 비교한 결과
- 표 또는 그래프 한 개
- 출처·통계표·기간·단위·조회 조건이 담긴 증거 카드
- 원 통계표에서 교차 확인한 핵심 수치
- 확인한 사실·가능한 해석·확인할 수 없는 내용
- 처음 생각에서 수정한 점

<Callout kind="checklist" title="통과 기준">
- 일상적인 관심을 대상·기간·지역·지표가 있는 질문으로 바꾸었다.
- AI가 어떤 공공데이터 도구를 사용했는지 확인했다.
- 질문 조건을 하나 이상 바꾸어 결과를 비교했다.
- 핵심 수치와 단위를 원 통계표에서 다시 확인했다.
- 사실·해석·원인 가설을 구분했다.
- 데이터로 알 수 없는 내용을 정직하게 밝혔다.
</Callout>
