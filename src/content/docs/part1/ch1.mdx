사람은 주변을 **인식**하고, 정보와 경험으로 **학습**하며, 결과를 **추론·예측**하고, 여러 선택지 중 하나를 **판단**해 문제를 해결합니다.

<Callout kind="concept" title="인공지능의 큰 개념">
**인공지능(AI)은 인간의 지능적 활동과 관련된 기능을 컴퓨터 시스템이 수행하도록 구현하는 기술과 연구 분야입니다.**

인식·학습·추론·예측·판단·생성·문제 해결 등이 포함될 수 있습니다. AI가 사람과 똑같이 생각한다는 뜻은 아닙니다.
</Callout>

## 같은 AI, 다른 방법

| 방법 | 핵심 | 예 |
| --- | --- | --- |
| 규칙 기반 | 사람이 조건과 처리 규칙을 직접 정함 | 정해진 금칙어를 찾는 필터 |
| 학습 기반 | 사례 데이터에서 판단에 유용한 패턴을 찾음 | 여러 이미지로 학습한 분류 모델 |

정해진 시각에 울리는 알람처럼 사람이 정한 조건만 그대로 실행하는 프로그램을 모두 AI라고 부르지는 않습니다. 다만 AI에도 사람이 설계한 규칙이 사용될 수 있으므로, **규칙이 있느냐 없느냐만으로 AI를 완벽하게 구분할 수는 없습니다.**

## AI·머신러닝·딥러닝

<div class="concept-nesting"><div>인공지능 AI<div>머신러닝 ML<div>딥러닝 DL</div></div></div></div>

- **머신러닝**: 사람이 모든 판단 규칙을 직접 쓰는 대신 데이터에서 패턴을 학습하게 하는 방법
- **딥러닝**: 여러 층의 인공신경망을 이용하는 머신러닝의 한 방법

## 곧 경험할 흐름

```text
데이터 → 학습 → 모델 → 새로운 입력 → 분류 결과
```

모델은 정답을 저장한 사전이 아니라 학습 데이터에서 찾은 패턴을 이용해 새로운 입력의 결과를 예측합니다. 어떤 데이터로 학습했는지가 중요한 이유입니다.

<Callout kind="concept" title="오늘 기억할 내용">
1. AI는 하나의 앱이 아니라 넓은 기술 분야다.
2. 머신러닝은 데이터에서 패턴을 학습하게 하는 방법이다.
3. 딥러닝은 머신러닝의 한 방법이다.
4. 결과의 의미와 사용 여부는 사람이 맥락 속에서 판단한다.
</Callout>
