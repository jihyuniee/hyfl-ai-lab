Teachable Machine 모델 학습

Part 3: Project 1. Teachable Machine AI 웹앱 프로젝트 · 12차시 / 총 37차시

이 챕터의 교과 결합

섹션 제목: “이 챕터의 교과 결합”
mindmap
  root((모델 학습))
    정보
      데이터 입력
      학습 실행
      결과 확인
    인공지능
      지도학습 원리
      클래스와 라벨
      신뢰도 해석
    연결다리
      데이터에서 모델로
      정확도 시각화

이 챕터는 정보 교과의 데이터 처리 절차와 인공지능 교과의 지도학습 원리를 결합합니다. 지난 차시에 모은 데이터를 실제 모델로 바꾸는 순간, 두 교과가 만납니다.

🔍 생각 열기

섹션 제목: “🔍 생각 열기”

여러분이 어린 동생에게 “고양이”와 “강아지”를 구별하는 법을 가르친다고 해 봅시다. 사진을 여러 장 보여주며 “이건 고양이”, “이건 강아지”라고 반복해서 알려줄 것입니다. 몇 장을 보여줘야 동생이 스스로 구별할 수 있을까요?

컴퓨터도 똑같습니다. Teachable Machine에 사진을 보여주고 “이건 A”, “이건 B”라고 알려주면, 컴퓨터가 스스로 구별하는 법을 배웁니다. 이 과정을 학습(training)이라고 부릅니다.

가로지르는 질문 “동생에게 사진 3장만 보여줬을 때와 30장을 보여줬을 때, 구별 실력은 왜 달라질까요? 이 차이를 설명하려면 [인공지능]의 학습 원리와 [정보]의 데이터 개념이 모두 필요합니다.”

🎯 이 단원의 학습 목표

섹션 제목: “🎯 이 단원의 학습 목표”
  • Teachable Machine에 수집한 데이터를 입력하여 분류 모델을 학습시킬 수 있다. [정보]
  • 지도학습에서 클래스와 라벨의 역할을 설명하고, 학습 결과의 신뢰도를 해석할 수 있다. [인공지능]

📌 선수학습 확인

섹션 제목: “📌 선수학습 확인”

지난 차시(11차시)에서 우리는 분류 모델을 위한 데이터를 수집했습니다. 각 클래스마다 이미지를 여러 장 촬영하거나 업로드했습니다. 이때 배운 두 가지를 기억해 봅시다.

  • 클래스(class): 컴퓨터가 구별해야 할 그룹입니다. 예를 들어 “마스크 착용”과 “마스크 미착용”은 두 개의 클래스입니다.
  • 데이터의 질: 밝기, 각도, 배경이 다양할수록 좋은 데이터입니다.

오늘은 이 데이터를 실제로 모델로 바꾸는 작업을 합니다.

🧪 탐구 활동

섹션 제목: “🧪 탐구 활동”

탐구: 데이터 양에 따라 모델은 얼마나 똑똑해질까?

섹션 제목: “탐구: 데이터 양에 따라 모델은 얼마나 똑똑해질까?”

  • 준비물: 인터넷이 연결된 컴퓨터, 웹캠, Teachable Machine 웹사이트(teachablemachine.withgoogle.com)

  • 과정:

    1. 클래스를 2개 만들고, 각 클래스에 데이터를 5장씩만 넣어 학습시킵니다.
    2. 학습된 모델에 새로운 장면을 보여주고, 화면 하단의 신뢰도 막대를 관찰합니다.
    3. 같은 클래스에 데이터를 각 30장씩 추가로 넣고 다시 학습시킵니다.
    4. 다시 같은 장면을 보여주고 신뢰도 막대를 관찰합니다.

  • 결과 예측: “데이터가 적을 때(5장)와 많을 때(30장), 신뢰도 막대의 움직임은 어떻게 다를까요?”

  • 토의:

    • “왜 데이터가 많아지면 예측이 더 안정적일까요?” [인공지능]
    • “데이터를 무조건 많이 넣으면 항상 좋을까요? 어떤 데이터를 넣느냐도 중요하지 않을까요?” [정보]

탐구에서 확인한 것처럼, 모델의 성능은 데이터의 양과 질에 함께 달려 있습니다. 이제 학습이 실제로 어떤 원리로 작동하는지 살펴봅니다.

flowchart LR
  A[데이터 5장] --> B[학습] --> C[신뢰도 불안정]
  D[데이터 30장] --> E[학습] --> F[신뢰도 안정]

데이터 양에 따라 학습 결과의 안정성이 달라지는 과정을 나타낸 순서도입니다.

💡 핵심 개념

섹션 제목: “💡 핵심 개념”

개념 1: 지도학습과 학습(training) [인공지능]

섹션 제목: “개념 1: 지도학습과 학습(training) [인공지능]”

  • 정의: 지도학습(supervised learning)은 정답(라벨)이 붙은 데이터를 컴퓨터에 보여주며 규칙을 스스로 찾게 하는 방법입니다. Teachable Machine의 클래스 이름이 바로 라벨(label)입니다.

  • 비유: 지도학습은 마치 답이 적힌 문제집으로 공부하는 것과 같습니다. 문제와 정답을 함께 보며 풀이 규칙을 익히는 것처럼, 컴퓨터도 이미지와 클래스 이름을 함께 보며 구별 규칙을 익힙니다.

컴퓨터는 학습 중에 각 이미지의 특징(색, 모양, 밝기 패턴)을 수치로 바꾸고, 어떤 특징이 어떤 클래스와 연결되는지를 계산합니다. 이 계산의 결과물이 바로 모델(model)입니다.

flowchart LR
  A["이미지 + 라벨"] --> B[특징 추출]
  B --> C[규칙 계산]
  C --> D[모델 완성]

라벨이 붙은 데이터가 모델로 변환되는 지도학습의 흐름입니다.

개념 2: 신뢰도(confidence) 해석 [정보] [인공지능]

섹션 제목: “개념 2: 신뢰도(confidence) 해석 [정보] [인공지능]”

  • 정의: 신뢰도는 모델이 “이 장면은 A 클래스일 확률이 몇 퍼센트인가”를 나타내는 값입니다. 모든 클래스의 신뢰도를 더하면 100%가 됩니다.

  • 비유: 신뢰도는 마치 일기예보의 강수 확률과 같습니다. “비 올 확률 80%“가 확신에 찬 예보이듯, 신뢰도 80%는 모델이 꽤 확신하는 상태입니다.

신뢰도가 두 클래스에서 50% 대 50%로 나온다면, 모델이 헷갈리고 있다는 뜻입니다. 이럴 때는 데이터를 더 넣거나, 헷갈리는 상황의 데이터를 보강해야 합니다.

🌉 교과 간 연결

섹션 제목: “🌉 교과 간 연결”

[정보]는 “데이터를 어떻게 입력하고 절차대로 실행하는가”에 집중합니다. [인공지능]은 “그 데이터로부터 컴퓨터가 무엇을 어떻게 배우는가”를 설명합니다. 두 교과는 신뢰도라는 하나의 숫자에서 만납니다.

예를 들어 신뢰도 막대가 흔들릴 때, [정보]의 눈으로는 “데이터를 더 수집해 다시 입력하자”는 절차적 해결책이 보입니다. [인공지능]의 눈으로는 “클래스 간 특징이 겹쳐 모델이 경계를 못 긋고 있다”는 원리적 진단이 나옵니다. 두 관점을 합쳐야 문제를 제대로 고칠 수 있습니다.

다교과 관점 비교

섹션 제목: “다교과 관점 비교”
쟁점 / 현상정보의 관점인공지능의 관점
클래스 이름 짓기데이터를 분류·저장하는 폴더 이름모델이 학습할 정답(라벨)
신뢰도 50:50입력 데이터가 부족하다는 신호클래스 특징이 겹쳐 경계가 모호함
학습 버튼 클릭정해진 절차의 실행 단계규칙을 계산해 모델을 생성하는 순간

공통 어휘 정리

섹션 제목: “공통 어휘 정리”
인공지능 용어정보 용어일상어
라벨(label)클래스 이름정답표, 이름표
학습(training)모델 생성 실행가르치기

🛠️ 따라하기: Teachable Machine 모델 학습시키기

섹션 제목: “🛠️ 따라하기: Teachable Machine 모델 학습시키기”

지난 차시에 수집한 데이터로 실제 모델을 학습시켜 봅시다. 아래 5단계를 순서대로 따라 하세요.

1단계: 프로젝트 열기

섹션 제목: “1단계: 프로젝트 열기”
  • teachablemachine.withgoogle.com 접속 후 [이미지 프로젝트] → [표준 이미지 모델]을 선택합니다.
  • 지난 차시에 저장한 프로젝트가 있다면 [파일] → [프로젝트 열기]로 불러옵니다.

2단계: 클래스와 데이터 확인

섹션 제목: “2단계: 클래스와 데이터 확인”
  • 각 클래스에 데이터가 충분히(권장 30장 이상) 들어 있는지 확인합니다.
  • 클래스 이름이 명확한지 점검합니다. (예: “Class 1”이 아니라 “마스크착용”)

3단계: 학습 실행

섹션 제목: “3단계: 학습 실행”
  • 가운데 [학습(Training)] 패널의 [모델 학습시키기] 버튼을 클릭합니다.
  • 진행 막대가 끝날 때까지 브라우저 탭을 닫지 않고 기다립니다.

Teachable Machine은 2017년 구글이 처음 공개했습니다. 당시 목표는 “코딩을 모르는 사람도 몇 분 안에 머신러닝을 체험하게 하자”는 것이었습니다. 웹캠 앞에서 손 모양을 바꾸며 실시간으로 반응하는 데모는 전 세계 교실로 퍼졌습니다.

이 도구가 특별한 이유는 학습 과정을 브라우저 안에서 처리한다는 점입니다. 여러분이 촬영한 이미지는 서버로 전송되지 않고 컴퓨터 안에서만 계산됩니다. 개인정보 보호와 AI 교육을 동시에 잡은 셈입니다.

심화 (사고력·서술형)

섹션 제목: “심화 (사고력·서술형)”

4. 데이터를 각 클래스 5장으로 학습한 모델과 30장으로 학습한 모델의 신뢰도가 달랐습니다. 이 차이가 왜 생기는지 [인공지능]의 지도학습 원리로 설명하고, [정보]의 데이터 관점에서 개선 방법을 함께 서술하세요.

정답 확인

1. ② 라벨

2. ② 모델이 두 클래스를 헷갈리고 있다 (두 클래스의 특징이 겹쳐 경계를 명확히 긋지 못하는 상태)

3. (예시) 다양한 밝기 조건에서 촬영한 데이터를 추가로 수집해 각 클래스에 입력한 뒤 다시 학습시킨다. 어두운 방, 밝은 방, 역광 등 조건을 다양화한다.

4. (예시 답안) 지도학습에서 컴퓨터는 라벨이 붙은 데이터의 특징을 계산해 클래스 간 경계를 찾는다. 데이터가 5장뿐이면 특징의 사례가 부족해 경계가 부정확하고, 조금만 조건이 달라져도 신뢰도가 흔들린다. 30장이면 다양한 특징을 학습해 경계가 안정적이므로 신뢰도가 높고 일관된다. [정보]의 관점에서는 밝기·각도·배경이 다양한 데이터를 충분히 수집·입력하여 데이터의 양뿐 아니라 질도 높이는 것이 개선 방법이다.
