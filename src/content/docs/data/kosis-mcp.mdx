## 1. 오늘 사용할 데이터 길

이번 시간의 중심 도구는 KOSIS MCP입니다. 다만 모든 생활 데이터가 KOSIS에 있는 것은 아닙니다. 데이터의 성격에 따라 다른 공식 사이트나 직접 수집 자료를 함께 확인합니다.

| 데이터 길 | 예 | 사용 방법 |
| --- | --- | --- |
| KOSIS MCP | 인구, 고용, 물가, 사회조사, 청소년·가구 관련 국가통계 | Claude에 연결한 KOSIS MCP로 통계표 후보를 찾고, KOSIS 원자료에서 조건과 수치를 확인한다 |
| 공식 데이터 포털 | 급식, 날씨, 영화, 교통, 관광, 경제지표 | 해당 공식 사이트에서 검색하거나 파일을 내려받고, AI는 검색어 정리·표 구조 이해·그래프 아이디어에 활용한다 |
| 직접 수집 데이터 | 우리 반 설문, 직접 조사한 번역 사례, 학교생활 기록 | 수집 기준을 먼저 정하고, 개인정보가 들어가지 않도록 익명화한다 |

KOSIS MCP는 국가통계포털(KOSIS)의 통계와 설명을 생성형 AI와 연결하여, 사용자가 일상어로 질문하면 관련 통계표를 찾아볼 수 있도록 제공되는 시범서비스입니다.

KOSIS MCP 시범서비스 안내는 [KOSIS 공지사항](https://kosis.kr/serviceInfo/noticeDetail.do?boardIdx=2553)에서 확인할 수 있습니다.

| 구분 | 영문 이름 | 의미 |
| --- | --- | --- |
| KOSIS | Korean Statistical Information Service | 국가통계포털 |
| API | Application Programming Interface | 서로 다른 프로그램이 데이터나 기능을 요청하고 주고받도록 만든 연결 창구 |
| MCP | Model Context Protocol | 생성형 AI가 외부 데이터나 도구를 공통된 방식으로 연결하여 활용하도록 돕는 표준 규약 |
| KOSIS MCP | KOSIS + Model Context Protocol | 생성형 AI가 KOSIS 통계 도구를 활용해 관련 통계를 찾아볼 수 있게 하는 시범서비스 |

<Callout kind="caution" title="KOSIS MCP와 공식 포털을 구분합니다">KOSIS MCP는 KOSIS 통계표를 찾는 데 유용합니다. 급식·영화·날씨처럼 별도 공식 포털이 있는 자료는 해당 사이트에서 원자료를 확인합니다. AI는 자료 후보를 찾고 기준을 정리하는 도구로 사용합니다.</Callout>

<Callout kind="caution" title="AI 답변은 원자료와 비교합니다">KOSIS MCP를 사용해도 생성형 AI 답변에는 오류나 부정확한 내용이 포함될 수 있습니다. 중요한 판단을 하기 전에는 반드시 KOSIS 원자료에서 통계표 이름, 기간, 지역, 단위, 수치를 다시 확인합니다. AI의 분석이나 해석은 참고용입니다.</Callout>

## 2. Claude에 KOSIS MCP 연결하기

이번 실습은 **Claude에 KOSIS MCP를 직접 연결한 뒤 질문하는 방식**으로 진행합니다. 아래 순서는 KOSIS 공식 설정 가이드의 Claude 연결 절차를 학생용으로 풀어 쓴 것입니다. 화면 이름이나 메뉴 위치는 서비스 업데이트에 따라 조금 달라질 수 있습니다.

### 실습 전 준비

- PC에서 Claude 웹 또는 앱을 엽니다.
- Claude에 로그인할 Google 계정 또는 이메일 계정을 준비합니다.
- 아래 KOSIS MCP 서버 주소를 복사해 둡니다.

<Callout kind="concept" title="입력할 KOSIS MCP 서버 주소"><code>https://kosismcp2026.vercel.app/api/mcp</code></Callout>

<Steps>
<Step title="Claude에 로그인하기">

Claude 초기 화면에서 **Google로 계속하기** 또는 **이메일로 계속하기**를 선택하여 로그인합니다. 처음 이용하는 학생은 화면의 안내에 따라 회원가입을 먼저 완료합니다.

</Step>

<Step title="설정 메뉴 열기">

로그인한 뒤 화면 **왼쪽 아래의 계정 아이콘**을 누릅니다. 이름, 이니셜 또는 프로필 그림으로 표시될 수 있습니다. 펼쳐진 메뉴에서 **설정**을 클릭합니다.

</Step>

<Step title="커넥터 맞춤 설정 열기">

설정 창의 왼쪽 메뉴에서 **커넥터**를 선택한 뒤 **맞춤 설정**을 클릭합니다.

</Step>

<Step title="더하기 버튼 누르기">

</Step>

<Step title="커스텀 커넥터 추가 선택하기">

커스텀 커넥터 추가 창에 다음 내용을 입력합니다.

- **이름:** KOSIS MCP 또는 kosismcp
- **원격 MCP 서버 URL:** <code>https://kosismcp2026.vercel.app/api/mcp</code>

주소 앞뒤에 공백이나 줄바꿈이 들어가지 않았는지 확인한 뒤 **추가** 버튼을 클릭합니다. 이 주소는 채팅창이 아니라 커넥터 설정 창에 입력해야 합니다.

</Step>

<Step title="사용 권한을 항상 허용으로 바꾸기">

추가된 KOSIS MCP 커넥터에서 **승인 필요**를 클릭하고 **항상 허용**으로 변경합니다. 이렇게 설정하면 통계 도구를 사용할 때마다 승인 버튼을 반복해서 누르지 않아도 됩니다.

</Step>

<Step title="채팅 화면으로 돌아가기">

화면 왼쪽 위의 **← 뒤로 가기**를 눌러 Claude 채팅 화면으로 돌아갑니다. 필요한 경우 새 채팅을 엽니다.

</Step>

<Step title="KOSIS MCP로 첫 질문하기">

질문 첫 문장에 **“KOSIS MCP를 사용하여”**라고 명확히 적습니다. 아래 연결 확인용 프롬프트를 복사하여 입력합니다.

</Step>
</Steps>

### 연결이 잘되었는지 확인하기

답변이 나왔다고 바로 연결에 성공한 것은 아닙니다. Claude가 일반 지식으로 답한 것이 아니라 KOSIS 통계 도구를 사용했는지 다음 항목을 확인합니다.

| 확인할 것 | 확인 방법 |
| --- | --- |
| MCP 도구 사용 | 답변을 만드는 과정에 KOSIS MCP 도구 사용이 표시되는지 확인한다 |
| 통계표 이름 | 어떤 KOSIS 통계표를 사용했는지 답변에 포함되어 있는지 확인한다 |
| 기간 | 요청한 2020년부터 2025년까지의 값이 있는지 확인한다 |
| 단위 | 지수, %, 명, 원 등 값의 단위를 확인한다 |
| 출처 | 통계를 작성하거나 제공한 기관을 확인한다 |
| 원자료 | KOSIS 원자료에서 통계표와 수치를 다시 확인한다 |

### 연결이 잘되지 않을 때

| 문제 상황 | 해결 방법 |
| --- | --- |
| 설정 메뉴를 찾기 어렵다 | 화면 왼쪽 아래의 계정 아이콘을 다시 확인하고, 가능하면 PC 웹 화면에서 진행한다 |
| + 버튼이 보이지 않는다 | **설정 → 커넥터 → 맞춤 설정** 순서로 이동했는지 확인한다 |
| 추가 버튼이 활성화되지 않는다 | 이름과 원격 MCP 서버 URL을 모두 입력했는지 확인한다 |
| 연결 오류가 나타난다 | URL의 공백, 오탈자, 줄바꿈을 확인한 뒤 주소를 다시 붙여 넣는다 |
| 질문해도 일반적인 설명만 나온다 | 질문 첫 문장에 **“KOSIS MCP를 사용하여”**라고 적고, 커넥터가 추가되어 있는지 확인한다 |
| 사용할 때마다 승인을 요구한다 | 커넥터 설정에서 **승인 필요 → 항상 허용**으로 변경한다 |
| 원하는 통계를 찾지 못한다 | 주제, 지역, 기간, 연령 조건을 한 번에 하나씩 더 구체적으로 적는다 |
| 결과가 예상과 다르다 | 통계표 이름, 기간, 지역, 단위를 KOSIS 원자료와 비교한다 |

<Callout kind="caution" title="개인정보는 입력하지 않습니다">통계 탐색에는 이름, 주민등록번호, 전화번호, 주소 같은 개인정보가 필요하지 않습니다. 개인을 식별할 수 있는 정보는 AI 채팅창에 입력하지 않습니다.</Callout>

<Callout kind="caution" title="AI의 답이 곧 국가통계는 아닙니다">KOSIS MCP와 연결되어 있어도 Claude가 자료를 잘못 선택하거나 내용을 부정확하게 해석할 수 있습니다. 답변을 그대로 믿지 말고 **통계표 이름·기간·지역·단위·수치**를 KOSIS 원자료에서 다시 확인합니다.</Callout>

## 3. 공통 실습으로 도구 사용 익히기

먼저 모두 같은 질문으로 KOSIS MCP 사용법을 짧게 연습합니다. 이 단계의 목표는 정답을 빨리 쓰는 것이 아니라, AI가 찾은 통계표의 이름·기간·단위·값을 원자료와 비교하는 방법을 익히는 것입니다.

<Callout kind="think" title="공통 실습 질문">최근 10년간 서울의 15~19세 인구는 어떻게 변했을까?</Callout>

이 질문은 시간에 따른 변화가 잘 보이고, 이후 청소년 시설, 교육 프로그램, 진로·문화 활동 같은 주제로 확장할 수 있습니다.

<CopyPrompt title="함께 실습하는 KOSIS MCP 프롬프트" content={kosisClassPrompt} />

AI가 답변하면 바로 결론을 쓰지 않고, 아래 순서로 확인합니다.

<Steps>
<Step title="통계표 이름 확인">AI가 어떤 통계표를 사용했는지 확인합니다.</Step>
<Step title="조건 확인">기간, 지역, 연령 또는 집단 조건이 질문과 맞는지 확인합니다.</Step>
<Step title="단위 확인">값의 단위가 명, %, 건, 원 중 무엇인지 확인합니다.</Step>
<Step title="그래프 선택">연도별 변화라면 선그래프가 적절한지 판단합니다.</Step>
<Step title="말할 수 있는 것 구분">감소·증가 같은 사실과 원인 추측을 구분합니다.</Step>
</Steps>

### 함께 찾아보기 좋은 질문 후보

아래 질문은 수업에서 함께 시도해 볼 수 있는 후보입니다. 실제로 어떤 통계표를 사용할지는 KOSIS MCP가 찾은 결과와 KOSIS 원자료를 기준으로 확인합니다.

| 질문 후보 | 왜 볼 만한가 | 어울리는 그래프 |
| --- | --- | --- |
| 최근 10년간 서울의 15~19세 인구는 어떻게 변했을까? | 청소년 관련 교육·문화·복지 수요를 생각해 볼 수 있다 | 선그래프 |
| 최근 5년간 20~29세 고용률은 성별로 어떻게 달라졌을까? | 진로·취업 문제를 데이터로 살펴볼 수 있다 | 선그래프 또는 묶은 막대그래프 |
| 최근 10년간 시도별 인구 변화는 어떻게 다를까? | 지역별 변화와 격차를 비교할 수 있다 | 막대그래프 또는 선그래프 |
| 최근 몇 년간 소비자물가 관련 지표는 어떻게 변했을까? | 생활비와 경제 변화를 통계로 연결할 수 있다 | 선그래프 |

좋은 질문은 그래프를 그린 뒤에도 더 묻게 만듭니다. 예를 들어 청소년 인구가 줄어드는 변화가 보인다면, 바로 “문제다”라고 단정하기보다 어느 지역에서 더 빠른지, 어떤 시설이나 정책과 함께 봐야 하는지 다음 질문을 만들 수 있습니다.

## 4. 관심 주제와 데이터 출처 연결하기

먼저 질문의 데이터 길을 고릅니다. 국가가 정기적으로 조사하는 사회 현상은 KOSIS MCP로 통계표 후보를 찾고, 특정 기관이 운영하는 생활 자료는 해당 공식 포털에서 원자료를 확인합니다.

| 질문의 성격 | 먼저 사용할 곳 | 예 |
| --- | --- | --- |
| 국가가 정기적으로 조사하는 사회 통계 | KOSIS MCP → KOSIS 원자료 | 인구, 고용, 물가, 사회조사, 사교육비 |
| 기관이 운영하는 생활 자료 | 해당 공식 포털 | 급식 NEIS, 영화 KOBIS, 날씨 기상자료개방포털 |
| 우리 반이나 우리 학교의 상황 | 직접 수집 자료 | 익명 설문, 학교 제공 파일, 직접 정리한 표 |

그 다음, 학생 관심 주제를 데이터 질문으로 바꿉니다. KOSIS 밖 자료는 KOSIS MCP가 아니라 해당 공식 포털이나 제공 파일에서 원자료를 확인합니다.

| 학생 관심 주제 | 데이터로 확인할 질문 예시 | 먼저 확인할 곳 |
| --- | --- | --- |
| 학습·시험 도우미 | 공부 시간, 사교육비, 진로 준비 관련 지표는 어떻게 변했을까? | KOSIS 사회조사·사교육비 통계, 우리 반 설문 |
| 외국어·번역·뉘앙스 | 전공어 관련 국가의 관광객이나 유학생 수는 어떻게 변했을까? | KOSIS 관광·출입국 관련 통계, 한국관광데이터랩 |
| 영화·음악·게임·콘텐츠 | 해외에서 더 많이 팔리는 한국 콘텐츠는 게임일까, 음악일까? | KOSIS 콘텐츠산업조사, KOBIS 박스오피스 |
| 사회문제·딥페이크·허위정보 | 디지털 범죄나 저작권 침해 관련 지표는 어떻게 변했을까? | KOSIS 범죄·사회 통계, 경찰청·저작권 관련 공개자료 |
| 심리·상담·스트레스 | 청소년 스트레스, 수면, 우울감 관련 지표는 어떻게 변했을까? | 청소년건강행태조사, KOSIS 보건·사회조사 |
| 경제·환율·물가·투자 | 내가 자주 사는 품목의 소비자물가지수는 얼마나 변했을까? | KOSIS 소비자물가지수, 한국은행 ECOS |
| 환경·기후 | 평균기온, 강수량, 폭염일수는 어떻게 변했을까? | 기상자료개방포털, KOSIS 환경 통계 |
| 학교생활 | 우리 학교 급식이나 일정에는 어떤 패턴이 있을까? | NEIS 교육정보 개방 포털, 학교 제공 파일, 우리 반 설문 |
| 진로·직업 | 우리 또래는 직업을 고를 때 무엇을 중요하게 생각할까? | KOSIS 사회조사, 고용 관련 통계 |
| 스포츠·게임 | 경기 기록이나 팀 성적은 어떤 패턴을 보일까? | 공개 경기 기록, 직접 수집한 표, 관련 기관 공개자료 |

<Callout kind="concept" title="일상 데이터 찾는 법">생활과 가까운 데이터는 먼저 공식 출처를 확인합니다. 급식은 NEIS 교육정보 개방 포털, 날씨는 기상자료개방포털, 영화는 KOBIS, 공공 API는 공공데이터포털에서 찾을 수 있습니다. 사이트에서 내려받은 파일이나 표를 사용할 때도 출처, 기간, 단위, 수집 기준을 함께 기록합니다.</Callout>

## 5. 유의미한 질문으로 바꾸기

좋은 통계 질문은 막연한 느낌을 바로 결론으로 말하지 않습니다. **대상, 기간, 지역이나 집단, 확인할 지표**가 들어가야 통계로 확인하기 쉬워집니다.

| 막연한 질문 | 통계로 확인하기 쉬운 질문 |
| --- | --- |
| 학생 수가 줄었어? | 최근 10년간 서울의 고등학교 학령인구는 어떻게 변했을까? |
| 청년 취업이 어려워? | 최근 5년간 20~29세 고용률은 성별로 어떻게 달라졌을까? |
| 우리 지역은 살기 좋아졌어? | 최근 10년간 우리 지역 인구와 주요 생활시설 수는 어떻게 변했을까? |
| 문화생활이 늘었어? | 최근 5년간 지역별 공연장 또는 도서관 이용 관련 지표는 어떻게 달라졌을까? |
| 급식이 비슷하게 반복돼? | 최근 한 달 동안 NEIS 또는 학교 제공 급식 파일에서 같은 메뉴 또는 비슷한 메뉴가 몇 번 나왔을까? |

## 6. KOSIS MCP에 질문하기

KOSIS 국가통계로 확인할 질문일 때 아래 프롬프트를 사용합니다. 급식, 날씨, 영화처럼 KOSIS 밖의 생활 데이터는 먼저 해당 공식 포털에서 원자료를 찾고, AI에게는 검색어 정리, 표 구조 이해, 그래프 방법을 묻습니다.

<CopyPrompt title="KOSIS MCP 통계표 찾기 프롬프트" content={kosisQuestionPrompt} />

AI가 답변하면 먼저 통계표 이름과 조건을 확인합니다.

| 확인할 것 | 확인 이유 |
| --- | --- |
| 통계표 이름 | AI가 어떤 원자료를 사용했는지 확인한다 |
| 제공 기관 또는 출처 | 자료를 만든 기관과 신뢰할 수 있는 출처인지 확인한다 |
| 기간 | 질문에서 정한 기간과 실제 조회 기간이 맞는지 확인한다 |
| 지역 또는 집단 조건 | 전국, 서울, 연령대, 성별 등 조건이 질문과 일치하는지 확인한다 |
| 단위 | 명, %, 건, 원, 지수처럼 값의 의미를 확인한다 |
| 원자료 수치 | AI가 제시한 값 중 일부를 KOSIS 원자료에서 다시 대조한다 |

## 7. 유의미한 그래프 찾기

유의미한 그래프는 예쁜 그래프가 아니라 질문에 맞는 그래프입니다. 먼저 내가 보려는 것이 변화인지, 비교인지, 구성인지 정합니다.

| 보고 싶은 것 | 어울리는 그래프 | 예 |
| --- | --- | --- |
| 시간에 따른 변화 | 선그래프 | 연도별 청소년 인구 변화 |
| 지역이나 집단 비교 | 막대그래프 | 지역별 고용률 비교 |
| 전체 안의 비율 | 막대그래프 또는 원그래프 | 연령대별 인구 구성 |
| 두 값의 관계 | 산점도 | 지역별 시설 수와 이용자 수의 관계 |

## 8. 그래프를 읽을 때 조심할 점

그래프는 현상을 쉽게 보여 주지만, 원인을 자동으로 증명하지는 않습니다. 그래프를 읽을 때는 사실, 해석, 확인 필요를 구분합니다.

| 구분 | 예 |
| --- | --- |
| 사실 | 2015년보다 2025년의 값이 낮다 |
| 해석 | 이 기간에 감소하는 경향이 보인다 |
| 확인 필요 | 왜 감소했는지는 다른 자료가 더 필요하다 |

<Callout kind="concept" title="그래프가 말해 주는 것과 말해 주지 못하는 것">통계표와 그래프는 변화와 차이를 보여 줄 수 있습니다. 하지만 그 변화의 원인, 개인의 경험, 앞으로 반드시 일어날 일까지 자동으로 말해 주지는 않습니다.</Callout>

## 9. 다음 실습으로 연결하기

이번 한 차시는 팀을 바로 정하기보다, 관심 주제를 데이터 질문으로 바꾸고 그래프까지 읽어 보는 탐색 시간입니다. 다음 차시에는 KOSIS 밖 생활 데이터가 웹앱으로 들어오는 방식, 즉 Open API를 짧게 실습합니다. 그다음 차시에는 실제 파일을 사용해 작은 웹앱 제작 흐름을 연습합니다.

KOSIS MCP는 국가통계를 찾는 도구입니다. 다음 실습에서 다룰 급식 데이터처럼 KOSIS 밖에 있는 생활 데이터는 해당 공식 포털이나 제공 파일에서 원자료를 확보한 뒤 사용합니다. MCP로 자료를 조회하거나 AI에게 코드를 요청하는 것은 그 자체로 모델을 새로 학습시키는 활동은 아닙니다.

**관심사 탐색 → 데이터 질문·그래프 해석 → Open API 맛보기 → 공통 웹앱 제작 → 팀 프로젝트 기획·구현** 순서로 진행합니다.
