# School Image Lab 전시 기록

2026-11-03 제공받은 9월 제출 자료를 정리해 공개한다. AI × DATA 전시는 보류 상태를 유지한다.

- 총 47팀: 6반 9팀, 7반 9팀, 8반 9팀, 9반 10팀, 10반 10팀.
- 중복 제출(7반 예예, 10반 오서연윤서하·해결해조·서듀 등)은 한 팀으로 합쳤다.
- 6반 동채팀은 뒤에 별도로 제출된 전체 URL을 반영했다.
- 10반 해결해조는 9월 11일의 완전한 GitHub Pages 주소를 반영했다.
- 7반 예서현의 호스트 끝 마침표는 제거했다. 원문 주소는 submittedUrl 필드에 보존했다.
- 학생 학번은 공개 전시 데이터에 넣지 않았다. 팀명과 이름은 제공 자료를 따랐다. 6반 바른자세 팀의 원문 학번 불일치는 이름과 반을 변경할 근거로 사용하지 않았다.
- 원본 웹앱 HTML에서 확인한 표제를 작품명으로 사용했다. 제목이 ‘프로젝트명’이거나 페이지를 읽을 수 없는 경우 팀명 기반 표제로 표시했다.
- 짧은 소개는 원본 웹앱의 소개·표제를 요약했다. 소개가 확인되지 않는 라을라·졸리당은 임의 내용을 작성하지 않았다.
- 2026-11-03 HTTP 요청에서 46팀 페이지 응답 200, 8반 졸리당은 404였다. 404 작품도 전시에 보존한다.
- HTTP 200을 카메라·모델·결과의 정상 작동으로 표현하지 않는다. 제출 당시 학생 보고와 현재 페이지 응답을 별도 표시한다.
- 아직 제공되지 않은 네 질문의 답변과 검증 결과는 꾸며 넣지 않는다. 학생 작성 후 데이터 파일의 question/dataFinding/demonstration/verification 필드를 채울 수 있다.

## 위치

작품 데이터: src/data/school-image-lab.json

교과서 상단 SiteTitle 옆에 작은 ‘학생 작품’ 링크를 둔다. 교과서 목차·수업 순서는 바꾸지 않는다. 전시는 별도 레이아웃이며, 등록·평가·GitHub 이슈 연동을 추가하지 않는다. 학생 웹앱은 외부 새 창으로 열고 iframe으로 자동 실행하지 않는다.
