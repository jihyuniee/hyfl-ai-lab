4. 데이터에서 공공데이터까지

DATA EXPLORATION · PUBLIC DATA
오늘의 질문우리가 직접 모으지 않은 데이터로도 현실의 현상을 살펴볼 수 있을까?

School Image Lab에서는 사진·음성·포즈 데이터를 직접 모아 AI 모델을 학습시켰습니다. 이번에는 학교 밖으로 시야를 넓혀 봅니다. 이미 공개되어 있는 데이터를 찾아보고, 그 데이터가 어떤 현상을 보여 줄 수 있는지 살펴봅니다.

🎯 오늘의 미션

공공데이터가 무엇인지 이해하고, 관심 분야와 관련된 공공데이터를 직접 찾아 출처·형식·기준 시점·주요 항목을 기록합니다.

1. 직접 모은 데이터와 공개된 데이터

섹션 제목: “1. 직접 모은 데이터와 공개된 데이터”

지난 프로젝트에서는 우리 팀이 필요한 데이터를 직접 모았습니다. 사진을 찍고, 음성을 녹음하고, 포즈를 촬영해 모델이 학습할 사례를 만들었습니다.

하지만 세상의 모든 데이터를 우리가 직접 모을 수는 없습니다. 인구, 날씨, 교통, 문화, 교육, 경제처럼 이미 기관에서 조사하거나 관리한 자료를 활용하면 더 넓은 현상을 살펴볼 수 있습니다.

구분지난 프로젝트이번 단원
데이터 출발점우리가 직접 수집한 사진·음성·포즈공공기관이 공개한 자료
주로 살핀 것모델이 입력을 잘 분류하는가데이터가 어떤 현상을 보여 주는가
먼저 확인할 것클래스, 사례 수, 오류 사례출처, 기준 시점, 항목, 단위, 한계

2. 공공데이터란 무엇일까?

섹션 제목: “2. 공공데이터란 무엇일까?”

공공데이터는 공공기관이 업무를 하며 만들거나 관리하는 데이터 중 시민이 활용할 수 있도록 공개한 데이터입니다. 인구, 교육, 기상, 교통, 환경, 보건, 경제, 문화 등 여러 분야의 자료가 공개되어 있습니다.

공공데이터라고 해서 자동으로 좋은 데이터라는 뜻은 아닙니다. 어떤 기관이, 어떤 기준으로, 언제의 자료를 제공하는지 확인해야 합니다.

⚠️ 출처부터 확인합니다

데이터를 찾으면 가장 먼저 제공 기관, 기준 시점, 수집 또는 집계 기준, 이용 조건을 확인합니다. 제목만 보고 바로 결론을 내리지 않습니다.

공공데이터를 볼 때 묻는 질문

섹션 제목: “공공데이터를 볼 때 묻는 질문”
  • 누가 제공하는 데이터인가?
  • 언제 기준의 데이터인가?
  • 어떤 기준으로 수집하거나 집계했는가?
  • 어떤 항목과 단위가 들어 있는가?
  • 이 데이터로 직접 알 수 있는 것은 무엇인가?
  • 이 데이터만으로 알 수 없는 것은 무엇인가?

3. 어디에서 찾아볼 수 있을까?

섹션 제목: “3. 어디에서 찾아볼 수 있을까?”

공공데이터는 여러 사이트에서 제공됩니다. 같은 주제라도 기관마다 제공하는 항목, 기간, 지역 단위가 다를 수 있습니다.

찾아볼 곳살펴볼 수 있는 자료 예
공공데이터포털여러 공공기관의 파일 데이터와 오픈 API
KOSIS 국가통계포털인구·경제·사회·교육 등 국가 통계
기상자료개방포털기온·강수량 등 기상 관측 자료
NEIS 교육정보 개방 포털학교 기본 정보·급식·학사 일정 등 교육 관련 API
영화진흥위원회 KOBIS박스오피스·영화·상영 정보
지방자치단체 또는 공공기관 홈페이지지역별 행정·교통·환경·문화 관련 공개 자료

검색어를 바꿔 가며 찾기

섹션 제목: “검색어를 바꿔 가며 찾기”
관심 분야검색어 예시
학교생활학교 급식 공공데이터, 학사 일정 API, 학교 기본 정보
문화영화 관객 수 통계, 공연 시설 현황, 도서관 대출 통계
환경미세먼지 관측 자료, 기온 변화 데이터, 생활 폐기물 통계
교통교통사고 통계, 지하철 승하차 인원, 버스 정류장 위치
진로·직업직업별 고용 통계, 자격시험 통계, 산업별 취업자 수
지역사회인구 변화, 청소년 인구, 공공시설 현황

4. 데이터는 어떤 모양으로 제공될까?

섹션 제목: “4. 데이터는 어떤 모양으로 제공될까?”

공공데이터는 모두 표처럼 보이지 않습니다. 어떤 데이터는 파일로 내려받을 수 있고, 어떤 데이터는 웹 화면에서 조회하거나 API로 받을 수 있습니다.

데이터 형태특징예
정형 데이터행과 열이 정해져 있는 표 형태CSV, XLSX, 통계표
반정형 데이터구조는 있지만 고정된 표 모양은 아닌 형태JSON, XML, API 응답
비정형 데이터정해진 행과 열 구조가 없는 자료이미지, 음성, 영상, 문서 본문

지난 프로젝트의 사진·음성·포즈는 주로 비정형 데이터였습니다. 공공데이터를 탐색할 때는 표 형태의 정형 데이터와 API 응답 같은 반정형 데이터를 자주 만나게 됩니다.

5. 데이터를 만나는 방법

섹션 제목: “5. 데이터를 만나는 방법”

데이터를 찾을 때는 자료가 어떤 방식으로 제공되는지 확인합니다. 방법마다 장점과 확인할 점이 다릅니다.

방법의미확인할 것
파일CSV·XLSX 등을 내려받아 확인한다파일명, 출처, 다운로드 날짜, 열 이름, 단위
API조건을 넣어 필요한 데이터를 응답으로 받는다요청 주소, 변수, 인증키 필요 여부, 응답 항목
웹 화면통계표나 검색 화면에서 조건을 선택해 조회한다조회 조건, 기간, 지역, 단위, 표 제목
AI 도구 활용검색어를 넓히거나 자료 후보를 정리하는 데 도움을 받는다AI가 제시한 출처가 실제로 존재하는지, 조건과 단위가 맞는지

AI 도구는 데이터를 대신 검증해 주는 출처가 아닙니다. 공공데이터를 더 빠르게 찾고 이해하도록 돕는 보조 도구로 사용합니다.

6. 오늘 활동 · 공공데이터 탐색 미션

섹션 제목: “6. 오늘 활동 · 공공데이터 탐색 미션”

선생님이 제시한 미션 또는 자신의 관심 분야 중 하나를 골라 공공데이터를 찾아봅니다. 중요한 것은 멋진 주제를 정하는 것이 아니라, 실제로 존재하는 데이터를 찾아 그 구조를 확인하는 것입니다.

  1. 미션 또는 관심 분야 고르기

    교육·문화·환경·교통·진로·지역사회 등 탐색할 분야를 정합니다.

  2. 검색어 만들기

    분야 이름에 공공데이터, 통계, API, CSV, 현황 같은 말을 붙여 검색합니다.

  3. 공식 출처 찾기

    공공데이터포털, KOSIS, 공공기관 홈페이지 등 공식 자료를 우선 확인합니다.

  4. 데이터 후보 기록하기

    데이터 이름, 제공 기관, 제공 방식, 기준 시점 또는 갱신일을 적습니다.

  5. 쓸 수 있는지 판단하기

    이 데이터로 알 수 있는 것과 알 수 없는 것을 구분합니다.

미션 예시

섹션 제목: “미션 예시”
미션찾아볼 데이터 예
학교 급식 데이터를 찾아라학교 급식 식단 정보, 영양 정보
우리 지역의 변화를 찾아라인구 변화, 청소년 인구, 공공시설 현황
날씨와 생활을 연결해 보라기온, 강수량, 미세먼지 관측 자료
문화생활 데이터를 찾아라영화 관객 수, 공연장, 도서관 이용 자료
안전과 관련된 데이터를 찾아라교통사고, 재난 안전, 보행 환경 자료

7. 생성형 AI 활용하기

섹션 제목: “7. 생성형 AI 활용하기”

생성형 AI는 검색어를 넓히고, 데이터 설명을 이해하고, 기록을 정리하는 데 도움을 줄 수 있습니다. 단, AI가 말한 데이터 이름과 수치는 실제 사이트에서 다시 확인합니다.

8. 오늘의 완료 기준

섹션 제목: “8. 오늘의 완료 기준”

☑️ 수업이 끝날 때 남길 것

  • 공공데이터의 의미를 자신의 말로 설명할 수 있다.
  • 관심 분야 또는 미션과 관련된 공공데이터를 하나 이상 찾았다.
  • 데이터 이름, 제공 기관, 제공 방식, 기준 시점 또는 갱신일을 기록했다.
  • 주요 항목과 단위를 확인했다.
  • 이 데이터로 알 수 있는 것과 알 수 없는 것을 구분했다.
  • AI가 제안한 내용 중 실제 사이트에서 확인해야 할 항목을 표시했다.

다음 시간에는 오늘 찾은 데이터 중 하나를 더 자세히 살펴보고, 데이터가 어떤 질문에 답할 수 있는지 정리해 봅니다.
