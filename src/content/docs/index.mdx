## 이 과목에서 배우는 것

인공지능의 개념과 머신러닝의 원리를 이해하고, AI의 결과가 만들어지는 과정과 한계를 분석합니다. 생성형 AI를 목적에 맞게 활용하고, 데이터와 근거를 바탕으로 실제 문제를 해결하는 방법을 익힙니다.

수업은 짧은 이론과 직접 해보는 실습을 연결하여 진행합니다. 실습 결과가 예상과 다를 때는 실패로 끝내지 않고 원인을 찾고 다시 개선합니다.

<Callout kind="concept" title="수업의 기본 흐름">
질문과 사례로 시작하고, 학습 목표와 이전 내용을 확인합니다. 필요한 이론을 배운 뒤 직접 실습하고, 결과를 비교·분석한 후 형성 평가로 이해를 점검합니다.
</Callout>
