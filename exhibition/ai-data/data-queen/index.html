01 · 문제와 사용자

누구의 어떤 문제를
해결하려 했나요?

사용하지 않는 옷을 편리하고 환경친화적으로 처리하려는 시민을 위한 프로젝트입니다. 팀은 의류수거함의 위치를 찾기 어렵고, 어떤 옷을 어떻게 배출해야 하는지 한 번에 파악하기 어렵다는 점에 주목했습니다.

“시민들과 환경을 위한 데이터 기반 프로그램을 만들고자 함.”

처음에는 수거함의 위치와 분포를 살펴보는 데서 출발했습니다. 이후 위치 안내와 함께 올바른 배출 기준을 제공하고, 의류수거업체와 사용자를 연결하는 방향으로 설계를 구체화했습니다.

학생들이 기록한 선택

수거함 수가 많다는 것만으로 폐의류 문제가 해결되는 것은 아니라는 생각에서, 위치 정보에 배출 방법과 수거 경로 안내를 더하고자 했습니다.

학생의 문제의식과 설계 판단을 활동지에서 정리한 내용입니다. 수거함 수와 폐의류량 사이의 관계를 통계적으로 입증했다는 뜻은 아닙니다.

어떤 의류를 넣을 수 있는지 확인하기 어렵다.품목별 배출 가이드와 검색가이드 화면과 ‘솜이불’ 검색 결과 확인.
수거함 외의 처리 경로도 알고 싶다.업체 안내·연결과 질문 인터페이스활동지에 업체 조사·추천 기능 설계 기록. 실제 추천 품질과 연결 결과는 추가 확인 필요.
배출 기준을 이해하고 기억할 방법이 필요하다.상식 퀴즈3문제 퀴즈 안내와 시작 화면 확인.

공공데이터를 조사한 내용과 현재 앱에 실제 연결된 데이터는 구분합니다. 이 작품은 조사·설계를 웹앱으로 옮기며 보완하고 있는 단계입니다.

03 · 실제 작동

무엇을 입력하면
어떤 결과가 나오나요?

직접 따라 해 볼 입력 예시

  1. 웹앱에서 배출 가이드를 엽니다.
  2. 품목 검색에 ‘솜이불’을 입력하고 확인을 누릅니다.
  3. ‘수거 불가 솜이불’과 관할 구청의 처리 안내를 확인하라는 설명이 표시됩니다.

이 결과는 2026년 11월 3일 전시 준비 과정에서 화면 동작을 확인한 예시입니다. 지자체의 공식 배출 기준과 일치하는지 검증한 결과로 소개하지는 않습니다.

함께 살펴볼 화면

  • AI 검색: 의류의 종류와 상태를 입력하는 질문 화면이 있습니다. 생성형 AI 연결과 답변 정확도는 이 전시에서 검증하지 않았습니다.
  • 수거함 지도: 현재 화면이 직접 안내하듯, 실제 카카오맵 대신 샘플 목록을 보여줍니다.
  • 상식 퀴즈: 배출 가이드 내용을 바탕으로 3문제를 푸는 시작 화면이 있습니다.

04 · 검증과 한계

어떤 도움이 되며,
무엇을 더 확인해야 하나요?

팀이 기대하는 도움

배출 가능 품목과 처리 경로를 한곳에서 살펴보게 해, 헌옷을 처리할 때 겪는 정보 탐색의 불편을 줄이고자 합니다.

현재 기록과 앞으로의 확인

  • 활동지의 검증 기록: STEP 3-2의 원자료·앱 결과 비교표와 사용자 테스트 기록은 아직 작성되지 않았습니다.
  • 데이터 연동: 지도 화면의 샘플 목록을 실제 위치 자료와 대조하고 공공데이터로 교체할 필요가 있습니다.
  • 배출 기준: 지역·수거업체에 따라 다른 기준을 공식 안내와 대조해야 합니다.
  • 사용자 관점: 실제 사용자가 원하는 정보를 찾는지, 안내를 이해하는지 확인할 기록이 필요합니다.

쓰레기나 폐의류량 감소, 재활용 증가, 탐색 시간 단축 등의 효과는 아직 검증된 성과로 제시하지 않습니다. 앞으로의 수정과 테스트 기록을 이 작품 페이지에 이어서 남길 수 있습니다.
