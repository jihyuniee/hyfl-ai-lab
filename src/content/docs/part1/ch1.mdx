## 생각을 여는 질문

<Callout kind="question">
인공지능은 복잡한 문제를 해결할 때 어떤 일을 할 수 있으며, 사람은 무엇을 결정해야 할까요?
</Callout>

데미스 허사비스는 인공지능을 단순히 답을 만드는 도구가 아니라 과학과 사회의 복잡한 문제를 탐구하는 도구로 활용해 왔습니다. 영상을 보며 다음 두 가지를 찾아보세요.

- AI가 많은 자료를 바탕으로 찾아내거나 예측한 것은 무엇인가?
- 사람이 문제를 정하고 판단한 것은 무엇인가?

## 학습 목표

1. 인공지능의 개념을 설명할 수 있다.
2. 인공지능이 수행하는 지능적 활동을 사례와 연결할 수 있다.
3. 문제 해결 과정에서 AI와 사람의 역할을 구분할 수 있다.

## 인공지능은 무엇인가

인공은 사람이 만들었다는 뜻이고, 지능은 상황을 인식하고 배우며 판단하여 문제를 해결하는 능력을 뜻합니다.

<FlowDiagram items={[{ ko: '인식', en: '대상과 상황을 알아보기' }, { ko: '학습', en: '데이터에서 패턴 찾기' }, { ko: '추론·예측', en: '새로운 결과 판단하기' }, { ko: '문제 해결', en: '목표에 맞는 결과 만들기' }]} />

<Callout kind="concept" title="인공지능의 정의">
인공지능(AI)은 컴퓨터가 인식, 학습, 추론·예측, 문제 해결처럼 인간의 지능과 관련된 활동을 수행하도록 만든 기술입니다.

인공지능이 인간과 같은 방식으로 생각한다는 뜻은 아닙니다. AI는 규칙, 계산, 확률, 데이터의 패턴 등을 이용하여 주어진 목적에 맞는 결과를 만듭니다.
</Callout>

예를 들어 번역 AI는 문장을 분석하고 많은 언어 자료에서 찾은 패턴을 바탕으로 번역문을 만듭니다. 추천 AI는 이용 기록과 콘텐츠의 특징을 분석하여 사용자가 관심을 가질 가능성이 높은 항목을 제시합니다.

## 자동으로 작동하면 모두 AI일까

정해진 시간에 울리는 알람은 사람이 설정한 규칙을 그대로 실행합니다. 반면 사용자의 수면 기록을 분석하여 기상 시간을 추천하는 서비스는 데이터에서 패턴을 찾고 새로운 결과를 예측합니다.

따라서 자동으로 작동한다는 사실만으로 인공지능이라고 판단할 수는 없습니다. 다음 질문을 살펴보아야 합니다.

- 입력된 대상이나 상황을 인식하는가?
- 데이터나 경험에서 패턴을 찾는가?
- 새로운 상황에 대한 판단이나 예측을 만드는가?
- 목표에 맞는 결과를 선택하거나 생성하는가?

AI와 일반 프로그램의 경계가 언제나 분명한 것은 아닙니다. 서비스의 이름보다 결과가 만들어지는 방식을 근거로 판단해야 합니다.

## AI가 잘하는 일과 사람이 해야 하는 일

AI는 많은 자료를 빠르게 처리하고, 반복되는 패턴을 찾고, 여러 가능성을 비교하는 데 강점이 있습니다. 그러나 해결할 문제의 의미와 결과의 영향을 스스로 책임질 수는 없습니다.

| AI가 도울 수 있는 일 | 사람이 해야 하는 일 |
| --- | --- |
| 많은 자료를 분류하고 요약하기 | 누구의 어떤 문제를 해결할지 정하기 |
| 패턴을 찾아 예측·추천·생성하기 | 자료와 결과가 타당한지 검토하기 |
| 여러 해결 방안을 빠르게 비교하기 | 가치, 맥락, 위험을 고려해 결정하기 |
| 반복 작업을 자동화하기 | 결과를 적용하고 그 영향에 책임지기 |

문제의 위험이 클수록 사람의 확인과 전문적 판단이 더 중요합니다. 의료 진단, 진로 추천, 복지 대상 선정처럼 사람의 삶에 큰 영향을 주는 결과는 AI의 제안만으로 결정해서는 안 됩니다.

## 핵심 정리

<Callout kind="concept" title="오늘 기억할 세 문장">
1. 인공지능은 인간의 지능과 관련된 활동을 컴퓨터가 수행하도록 만든 기술이다.
2. 인공지능인지 판단할 때는 자동화 여부보다 결과를 만드는 방식에 주목해야 한다.
3. AI는 분석과 예측을 도울 수 있지만, 사람은 문제를 정하고 결과를 검토하며 결정에 책임져야 한다.
</Callout>
