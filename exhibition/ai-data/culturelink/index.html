01 · 문제와 사용자

지역에 따라 달라지는
문화 경험의 기회

다른 지역에 사는 친구들이 문화생활을 위해 오랜 시간 이동한다는 경험에서 출발했습니다. 지역별 문화시설의 수와 종류를 살펴보고, 거주 지역에 따라 문화 경험의 기회가 어떻게 달라질 수 있는지 탐구했습니다.

처음에는 문화시설 격차를 시각화하는 앱을 구상했습니다. 이후 문화공간을 만들려는 기획자와 투자자·공공기관을 연결하는 프로젝트 커뮤니티로 방향을 발전시켰습니다. 팀명 ‘주민문화’에는 주민 누구나 문화를 누리기를 바라는 뜻과 두 팀원의 이름을 담았습니다.

02 · 공공데이터 활용

시설 수에서 출발해
유형별 분포 살펴보기

팀은 시설 총수만으로 문화 접근성을 설명하기 어렵다고 보았습니다. 공공 문화시설과 영화관 등 시설 유형별 분포, 인구 대비 시설 수를 함께 살펴보며 처음의 문제 인식을 구체화했습니다.

조사한 자료활용 방식
지역문화통합정보시스템 · 지역별 시설종류별 문화시설 수시설 유형별 지역 분포와 수도권·비수도권의 차이를 살펴보는 근거로 활용했습니다.
문화체육관광부 · 2025 전국 문화기반시설 자료인구 대비 시설 수를 비교하고, 현재 앱에서는 기관·시설 이름과 주소를 검색하는 내장 데이터로 활용했습니다. 앱의 기준일 표시는 2025-01-01입니다.
영화진흥위원회 · 2025년 전국극장조사공공 문화시설과 영화관의 지역별 분포를 비교하는 탐구 자료로 활용했습니다.
KOSIS · 권역별 백화점 수(2016~2019년)민간시설 분포를 조사하는 과정에서 참고했습니다. 다른 자료와 기준연도가 다릅니다.

자료는 활동지에 기록된 제목·기관을 기준으로 소개했습니다. 원자료 파일과 개별 수치를 독립 대조한 결과는 아니며, 서로 다른 집계 범위와 기준연도의 자료를 같은 통계로 합치지 않았습니다.

AI에게 도움받고 직접 결정한 것

생성형 AI에 주제 탐색, 데이터 수집 경로, HTML·JavaScript 코드 작성과 수정을 요청했습니다. 팀은 직접 파일을 실행하고, 임의로 제시된 지도를 카카오맵 연결로 바꾸며, 시설 검색과 기획서 검색 등 사용자가 필요한 기능을 구체화했다고 기록했습니다.

03 · 사용 예시

시설을 찾고
문화공간 제안 살펴보기

  1. 지역·시설 데이터에서 기관·시설 검색에 ‘국립중앙도서관’을 입력하고 기관 검색을 누릅니다. 이름·유형·지역·주소를 확인할 수 있습니다.
  2. 프로젝트 커뮤니티에서 시·도, 시설 유형, 진행 단계와 검색어로 기획서를 탐색합니다. 초기 화면의 기획서는 ‘시연용 예시’로 표시되어 있습니다.
  3. 기획서 등록에서 프로젝트명·지역·시설 유형·사업 규모·기획 개요와 파일 첨부 항목을 살펴봅니다. 체험에는 실제 연락처 대신 가상 정보를 사용하세요.

투자자 등록·목록·연락함 화면도 구성했습니다. 현재 공개 코드는 브라우저의 IndexedDB에 정보를 저장하는 구조이므로, 서로 다른 사용자의 기기 사이에서 기획서나 연락 요청이 공유되는 서비스로 확인된 것은 아닙니다.

04 · 검증과 개선

만들며 확인하고
다음 단계로 남긴 것

직접 써 보고 고친 점

팀은 기획서 게시·투자자 등록·시설 이름과 위치 검색이 동작한다고 활동지에 기록했습니다. 기획 개요의 글자 수 제한을 늘리고, 원하는 분야의 기획서를 찾을 수 있도록 검색 기능을 추가했습니다.

현재 웹앱에서 확인한 범위

2026-11-09에 ‘국립중앙도서관’을 검색했을 때 검색 결과 1개와 서울특별시 서초구 반포대로 201이라는 주소가 표시되었습니다. 기획서 등록 화면의 텍스트·파일 입력 항목과 시연용 기획서도 확인했습니다. 실제 게시나 연락 요청은 전송하지 않았으며, 지도 위치 정확성과 원자료 수치 전체의 일치 여부를 검증한 결과는 아닙니다.

앱은 내장 데이터 3,551개를 표시하며 지역 선택 항목에는 ‘광역 합계’·‘기초 합계’도 포함되어 있습니다. 이 표시를 실제 개별 시설의 확정 개수로 해석하려면 집계 행과 중복 여부를 추가 확인해야 합니다.

남은 한계와 개선 방향

시설 수만으로 주민 수요, 이동 편의, 운영 프로그램이나 사업성을 단정할 수 없습니다. 팀은 주민 수요 조사와 임대료·유동 인구·주민 선호도 같은 추가 정보가 필요하다고 정리했습니다.

AI 기획서 분석과 실제 투자 성사·공공기관 지원 연계는 구상한 확장 방향입니다. 현재 확인한 기능만으로 실제 AI 분석이나 투자·지원이 이루어진다고 소개하지 않습니다. 여러 사용자가 함께 이용하려면 공유 저장소와 이용자 확인, 연락 정보 접근 권한도 마련해야 합니다.

팀 활동지와 현재 웹앱을 바탕으로 정리했습니다.
팀이 기록한 결과와 현재 확인한 구현 범위를 구분해 소개합니다.
