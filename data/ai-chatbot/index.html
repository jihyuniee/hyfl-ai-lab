AI 기능 넣기(선택)

앱 안에 AI 기능이 필요한 팀만 사용하는 선택 도움말입니다. 예를 들어 사용자가 글을 넣으면 요약하거나, 질문과 관련 자료를 보내면 설명을 돌려주는 기능입니다. 기존 검색·표·지도 기능은 유지합니다.

1. 입력과 결과 한 가지 정하기

섹션 제목: “1. 입력과 결과 한 가지 정하기”
사용자가 넣을 것AI가 할 일화면에 보여 줄 것
공개된 행사 안내 글핵심 요약일정·장소·준비물
공개 자료와 질문자료에 근거해 설명답변과 참고한 원자료 링크
번역할 안내문과 언어번역번역문

처음에는 글 붙여 넣기 → 버튼 누르기 → 결과 표시부터 완성합니다. PDF·사진·엑셀 업로드는 파일에서 내용을 읽는 기능도 필요하므로 별도 확장입니다. 파일 선택 버튼만 만든다고 GPT가 파일을 읽는 것은 아닙니다.

2. 왜 서버와 API 키가 필요한가요?

섹션 제목: “2. 왜 서버와 API 키가 필요한가요?”

사용자 입력 → 우리 서버 → GPT API → 우리 서버 → 결과 화면 순서입니다.

  • 화면은 자료와 질문을 받고 답변을 보여 줍니다.
  • 서버는 비밀 API 키로 GPT에 요청하고 답변을 돌려줍니다. 이 예제에서는 Vercel이 서버 코드를 실행하므로 컴퓨터에 서버를 직접 설치할 필요는 없습니다.
  • 환경변수는 키처럼 코드 밖에 보관할 설정값입니다. 화면 코드에 키를 쓰면 앱 이용자가 찾아 사용할 수 있으므로 서버 설정에 넣습니다. 카카오 지도의 브라우저용 JavaScript 키와 구분합니다.

GitHub는 코드를 저장하고, Vercel은 화면과 서버를 실행합니다. GitHub Pages에서는 이 예제의 서버가 실행되지 않습니다. GitHub를 GPT에 연결해 코드를 수정하는 것과, 완성된 앱이 GPT API를 호출하는 것은 별도 작업입니다.

API 이용 권한·모델·비용은 선생님과 확인합니다. ChatGPT 대화 화면에서 쓰는 기능과 API의 사용 설정·과금은 구분해 확인하세요. 공용 연결 서버는 준비 전이며, 아래는 팀별 서버를 배포하는 방법입니다.

3. 시작 파일을 기존 앱에 연결하기

섹션 제목: “3. 시작 파일을 기존 앱에 연결하기”

챗봇 시작 파일 ZIP을 내려받아 압축을 풉니다. 현재 앱 파일과 압축을 푼 시작 파일을 함께 코드를 수정할 AI에 제공합니다. 저장소를 연결했다면 최신 파일을 읽게 합니다.

기존 앱에 실제 AI 기능 연결하기 표시된 부분을 우리 팀의 내용으로 바꾸세요.
프롬프트 구조와 각 부분이 필요한 이유 보기

역할·프로젝트 맥락은 AI가 어떤 관점에서 어느 팀의 문제를 다루는지 정합니다.

과업·필수 기능은 만들어야 할 결과와 빠뜨리면 안 되는 동작을 정합니다.

화면·디자인·기술 조건은 실제 사용자와 실행 환경의 제약을 전달합니다.

오류 처리·검증 기준은 실패했을 때의 안내와 완성 여부를 판단하는 기준입니다.

최신 앱과 첨부한 챗봇 시작 파일을 읽고 실제 AI 기능을 연결해줘.
사용자 입력: {{자료와 질문}}
AI가 할 일·결과 형식: {{예: 안내문을 세 줄로 요약}}
유지할 기능: {{기존 검색·지도 등}}

기존 화면·데이터·파일 구조를 유지하며 시작 예제의 /api/chat 요청과 서버를 통합해줘.
입력 자료가 실제 요청에 포함되고 결과가 화면에 표시되게 해줘. 빈 입력·처리 중·실패·중복 클릭도 처리해줘.
비밀키는 서버 환경변수로만 읽고, 이용 코드 확인과 입력 제한을 유지해줘. 실제 키·개인정보는 요구하지 마.
바꾼 파일, 내가 설정할 값, 배포 순서와 시험 방법을 짧게 알려줘. 모르는 설정은 추측하지 마.
서버 설정 전 화면은 ‘예시 답변 · 실제 AI 연결 전’으로 표시하고 실제 연결로 꾸미지 마.
시작 파일역할
index.html이용 코드·참고 자료·질문 입력과 답변 표시
api/chat.js화면이 요청하는 /api/chat 서버 주소
server/chat.js이용 코드 확인, 입력 제한, AI 호출·오류 처리
package.json, vercel.json실행 환경과 배포 설정

기존 앱의 index.html을 예제 파일로 덮어쓰지 않습니다. 기존 package.json이나 배포 설정이 있으면 필요한 내용을 합칩니다. 수정 파일을 GitHub에 저장하는 방법은 코드 수정·배포를 참고하세요.

자료 연결도 확인합니다. 사용자가 붙여 넣은 글은 참고 자료로 보내고, 파일·API 자료를 이미 읽는 앱은 질문에 필요한 부분만 골라 보냅니다. 시작 예제의 참고 자료 한도는 6,000자입니다. 웹사이트 주소만 보내면 그 페이지를 자동으로 읽는 구조가 아닙니다.

4. Vercel에 배포하고 설정하기

섹션 제목: “4. Vercel에 배포하고 설정하기”
  1. 수정한 화면·api·server 폴더와 설정 파일을 같은 GitHub 저장소에 올립니다.
  2. Vercel에서 Add New → Project로 저장소를 가져옵니다. 이 시작 예제 그대로라면 Framework Preset: Other, Root Directory: 예제 파일이 있는 폴더를 선택합니다. Build·Install Command는 빈 값, Output Directory는 .입니다. 기존 프레임워크 앱은 원래 설정을 유지합니다.
  3. Environment Variables에 아래 값을 등록합니다. 이미 배포했다면 Settings → Environment Variables에서 등록합니다. 실제 키는 선생님과 서버 설정에 직접 입력하고 AI 대화에 붙여 넣지 않습니다.
이름GPT 사용 시 입력할 값
AI_PROVIDERopenai
AI_MODEL사용 권한을 확인한 정확한 API 모델 ID
OPENAI_API_KEY해당 프로젝트의 비밀 API 키
CHAT_ACCESS_CODE무작위 영문·숫자·_·-로 만든 16~128자 앱 이용 코드
CHAT_SYSTEM_PROMPT (선택)예: 제공된 글을 세 줄로 요약하고, 없는 사실은 추가하지 마.
  1. 사용할 배포 환경에 적용하고 Deploy합니다. 환경변수를 나중에 바꿨다면 Redeploy합니다.
  2. Vercel이 제공한 HTTPS 웹앱 주소를 엽니다. 카카오 지도도 있다면 새 주소의 도메인을 카카오 설정에 추가합니다.

앱 이용 코드는 시험할 사용자에게 따로 전달하고 HTML·공개 저장소에 넣지 않습니다. 비밀 API 키와는 다른 값입니다. 팀별 사용량·비용과 사용 기간은 선생님과 정하고, 오류나 한도 안내가 나오면 반복 전송을 멈추고 문의합니다. 자세한 설정은 ZIP의 README.md에도 있습니다.

5. 실제 답변인지 확인하기

섹션 제목: “5. 실제 답변인지 확인하기”
  1. 배포된 앱에 이용 코드를 입력합니다.
  2. 함께 참고할 자료에 짧은 공개 안내문을 넣고 “이 글을 세 줄로 요약해 줘”라고 요청합니다.
  3. 답변이 나오면 원문과 비교합니다. 원문의 날짜나 장소를 바꾸어 다시 요청해 답변도 달라지는지 확인합니다.
  4. 자료에 없는 것을 물었을 때 모른다고 안내하는지, 빈 입력·잘못된 이용 코드·연속 클릭에서 적절히 안내하는지 확인합니다.
  5. 기존 검색·표·지도도 다시 실행합니다. 이 결과는 기존 활동지 STEP 3에 기록합니다.

연결 전이라면 ‘예시 답변 · 실제 AI 연결 전’이라고 표시합니다. 실제 GPT 답변을 받기 전까지 연결 성공으로 기록하지 않습니다. 이름·학번·연락처·상담 내용 같은 개인정보를 입력하거나 전송하지 않습니다. 시작 예제는 질문·참고 자료·최근 대화를 AI 제공사로 보냅니다.

6. 안 되면 이곳 확인하기

섹션 제목: “6. 안 되면 이곳 확인하기”
화면의 상황먼저 확인할 것
/api/chat에서 404 또는 HTML 응답GitHub Pages가 아닌 Vercel 주소인지, 서버 폴더가 함께 배포됐는지
이용 코드 확인 안내입력 코드와 서버의 CHAT_ACCESS_CODE
서버 AI 연결 설정 안내필수 환경변수·모델 ID·이용 코드 형식, 변경 후 Redeploy 여부
AI 연결 권한 안내API 키와 해당 프로젝트의 모델 사용 권한
이용 한도·처리량 안내제공사 사용량·결제·요청량 상태
답변이 원자료와 다름자료가 요청에 포함됐는지, AI 역할 지시가 맞는지

Vercel 프로젝트의 Logs에서 실패한 요청을 확인할 수 있습니다. 도움을 요청할 때는 실제 비밀 API 키·이용 코드·개인정보를 가리고 앱 주소와 오류 문구를 제공합니다.

AI 연결 오류 수정하기 표시된 부분을 우리 팀의 내용으로 바꾸세요.

앱·저장소: {{주소 또는 첨부}}

실제 비밀키는 요구하지 말고, 실행하지 못한 부분은 미검증으로 표시해줘.
