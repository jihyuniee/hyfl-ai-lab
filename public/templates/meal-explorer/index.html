1. 데이터와 출처 준비하기

필수 열: 날짜, 학교명, 식사명, 메뉴. UTF-8 CSV를 권장합니다. 최대 2MB, 20,000개 기록입니다. 이 기본 앱은 선택한 파일을 브라우저에서만 처리하며 서버에 전송하거나 저장하지 않습니다.

파일 형식과 계산 기준

날짜는 20250901 또는 2025-09-01 형식을 사용합니다. NEIS의 급식일자·요리명 열이나 MLSV_YMD·SCHUL_NM·MMEAL_SC_NM·DDISH_NM 열도 인식합니다.

중식 기록만 사용합니다. 같은 학교·날짜의 중복 기록은 메뉴를 모아 하루로 셉니다. 날짜·학교명·식사명·메뉴가 없거나 잘못된 기록은 제외 이유를 표시합니다. 메뉴는 입력한 문자열의 포함 여부로 검색하며, 비슷한 음식 이름을 자동 분류하지 않습니다. 알레르기 표시는 원문에 남겨 둡니다.

아직 데이터가 없습니다. 실제 공공데이터 파일을 선택하세요.
먼저 기능만 점검하기 · 실제 공공데이터 아님
