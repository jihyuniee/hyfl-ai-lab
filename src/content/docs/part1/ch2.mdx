지난 시간에 AI를 "인식·학습·추론·예측·문제 해결과 같은 지능적 활동을 컴퓨터가 수행하도록 만든 기술"이라고 정의했습니다. 이번 시간은 설명을 듣는 대신, 실제 AI 서비스를 직접 분류하며 확인합니다.

<Callout kind="lab" title="실생활 AI 카드 분류하기">
아래 AI 서비스를 모둠 친구들과 나눠 갖고, 각 서비스가 주로 어떤 능력(인식/학습/추론·예측/문제 해결)을 사용하는지 분류해보세요. 하나의 카드가 여러 능력에 해당될 수 있습니다 — 정답은 하나가 아니며, 왜 그렇게 분류했는지 근거가 더 중요합니다.

얼굴 인식 · 음성 인식 · 번역 · 유튜브 추천 · 넷플릭스 추천 · 날씨 예측 · 스팸메일 분류 · ChatGPT · 자율주행

각 카드마다 다음 문장을 완성하세요.

> 이 AI는 [ ]을(를) 인식해서, [ ]을(를) 학습했고, 그 결과 [ ]을(를) 예측/문제 해결한다.

예시 — 스팸메일 분류: "메일의 단어와 발신자 패턴을 인식해서, 사람이 스팸이라고 표시한 수백만 개의 메일을 학습했고, 새 메일이 스팸일 확률을 예측한다."
</Callout>

<Callout kind="discuss">
카드를 분류하다 보면 하나의 AI가 여러 능력에 걸쳐 있다는 걸 알게 됩니다. 유튜브 추천은 여러분의 시청 기록을 학습하는 동시에, 다음에 볼 만한 영상을 예측합니다. 모둠에서 "이 카드는 능력이 두 개 이상 겹친다"고 생각되는 사례를 하나 찾아 이유를 설명해보세요.
</Callout>

## 핵심 메시지

> 하나의 AI가 모든 지능을 가진 것은 아니다.

번역 AI는 번역만 잘하고, 자율주행 AI는 운전만 잘합니다. 이건 1차시에서 배운 약인공지능 개념과 정확히 연결됩니다. 지금의 AI는 각자 맡은 좁은 영역 안에서 필요한 능력을 조합해서 쓰는 '전문가'에 가깝습니다.

## 자동화와 AI는 어떻게 다를까

전자레인지가 "3분 뒤 정지"하는 것도 똑똑해 보이지만, AI는 아닙니다.

| | 자동화 | AI |
| --- | --- | --- |
| 판단 기준 | 사람이 미리 정한 규칙을 그대로 실행 | 데이터에서 패턴을 스스로 학습해 판단 |
| 새로운 상황 | 규칙에 없으면 처리 못 함 | 학습한 패턴을 바탕으로 추론 가능 |
| 예시 | 전자레인지 타이머, 신호등 | 스팸 필터, 추천 시스템 |

## 입력 → AI의 판단 → 출력

이제 지금까지 다룬 AI 하나를 골라 다음 구조로 표현해보세요.
