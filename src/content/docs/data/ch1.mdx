이미지 분류 프로젝트에서는 사진·음성·포즈를 모아 AI가 분류하도록 했습니다. 이제 표 형태의 데이터를 이용해 현실과 사회에서 어떤 현상이 나타나는지 살펴봅니다.

<Callout kind="think" title="AI가 할 수 있어도, 내가 배워야 하는 이유">
AI가 파일을 읽고 그래프와 코드를 빠르게 만들 수 있어도 데이터의 의미를 이해하는 공부는 필요합니다. 그래야 AI가 잘못된 열·단위·처리 방법을 선택했을 때 알아차리고, 결과를 고치며, 다음 문제에 배운 것을 사용할 수 있습니다.

이제부터는 결과물을 빨리 받았는지만 보지 않고 **AI의 도움을 받으며 나도 데이터와 문제를 더 잘 이해하게 되었는지** 함께 확인합니다.
</Callout>

<Callout kind="mission" title="오늘의 미션">같은 내용이 담긴 CSV와 XLSX 파일을 직접 열어보고, 데이터의 구조와 분석 전에 확인해야 할 문제를 찾아봅니다.</Callout>

## 1. 데이터는 모습이 다르다

| 구분 | 의미 | 예시 |
| --- | --- | --- |
| 정형 데이터 | 행과 열처럼 정해진 구조로 정리된 데이터 | 인구 통계, 기온, 설문 선택형 응답, 매출표 |
| 비정형 데이터 | 표 하나로 바로 정리하기 어려운 데이터 | 글, 뉴스, 사진, 음성, 영상, 자유서술 응답 |

AI는 정형 데이터만 학습하지 않습니다. 이미지 분류 모델은 사진을, 음성 인식 모델은 소리를, 생성형 AI는 많은 글과 이미지를 학습할 수 있습니다. 다만 분석이나 학습을 위해서는 파일 형식, 라벨, 단위, 수집 기준처럼 데이터를 해석할 정보가 필요합니다.

## 2. CSV와 XLSX를 비교해보자

| 구분 | CSV | XLSX |
| --- | --- | --- |
| 저장 방식 | 값을 쉼표 등으로 구분한 텍스트 파일 | 엑셀 통합문서 파일 |
| 담을 수 있는 것 | 주로 하나의 표와 값 | 여러 시트·수식·서식·그래프 |
| 장점 | 구조가 단순하고 여러 분석 도구에서 다루기 쉬움 | 사람이 읽고 편집하기 편리함 |
| 확인할 점 | 한글 인코딩, 구분 기호 | 제목 행, 병합 셀, 숨긴 행, 여러 시트 |

확장자만 바꾼다고 파일 형식이 변하는 것은 아닙니다. 같은 데이터를 두 형식으로 열어 값·시트·서식이 어떻게 달라지는지 확인합니다.

## 3. 표에서 찾아야 할 것

<Steps>
<Step title="한 행의 의미 확인">한 행이 한 사람·지역·날짜·사건 중 무엇을 나타내는지 설명합니다.</Step>
<Step title="열과 단위 확인">각 열이 무엇을 기록했고 명·원·℃·% 중 어떤 단위를 사용하는지 확인합니다.</Step>
<Step title="자료형 확인">문자·날짜·수치·범주 중 어떤 형태이며 계산할 수 있는 값인지 살펴봅니다.</Step>
<Step title="품질 문제 표시">결측치·중복값·이상치를 찾되 바로 삭제하지 않고 생긴 이유를 먼저 생각합니다.</Step>
<Step title="분석 질문 만들기">기간·대상·비교 기준이 드러나는 질문 하나를 만듭니다.</Step>
</Steps>

## 4. 데이터 분석은 무엇을 하는 일일까?

데이터 분석은 그래프를 만드는 일만을 뜻하지 않습니다.

```text
질문 세우기 → 출처·수집 맥락 확인 → 구조·품질 확인 → 전처리
→ 비교·시각화·관계 확인 → 관찰한 사실 → 가능한 해석 → 한계와 판단
```

<Callout kind="concept" title="사실·해석·원인 가설을 구분합니다">
**사실**은 표와 그래프에서 직접 확인할 수 있는 내용입니다.<br />
**해석**은 그 사실이 의미할 수 있는 것을 설명한 생각입니다.<br />
**원인 가설**은 왜 그런 현상이 나타났는지에 대한 추측이며 추가 자료가 필요합니다.

두 변수가 함께 움직인다고 해서 하나가 다른 하나의 원인이라고 단정할 수 없습니다.
</Callout>

## 이 순간의 AI 활용

먼저 파일을 직접 열어본 뒤 AI에게 파일을 제공합니다. 다음 요청처럼 **상황·자료·할 일·결과 형식·주의점**을 알려줍니다.

```text
이 파일은 [기관]에서 내려받은 [데이터명]이며, [기간]의 자료입니다.
1. 각 열의 의미와 자료형을 표로 정리해줘.
2. 결측치·중복값·이상치 후보를 찾아줘.
3. 값을 바로 삭제하지 말고 확인해야 할 점을 먼저 설명해줘.
4. 분석 가능한 질문 세 가지를 제안하되, 사용해야 할 열도 함께 알려줘.
파일에 없는 내용은 추측하지 말고 확인이 필요한 부분으로 표시해줘.
```

AI는 여러분의 머릿속 목적이나 열의 실제 의미를 자동으로 알지 못합니다. 맥락과 판단 기준을 제공해야 더 적절한 분석을 제안할 수 있습니다. AI가 말한 열 이름·행 수·단위는 원파일에서 직접 확인합니다.

<Callout kind="checklist" title="AI와 함께 성장했는지 확인하기">
- AI가 사용한 행·열·단위를 내 말로 설명할 수 있는가?
- AI의 제안 중 받아들인 것과 거부한 것을 구분할 수 있는가?
- 오류가 생기면 원파일의 어느 부분부터 확인할지 알고 있는가?
- 다음에 비슷한 파일을 만나면 혼자 먼저 확인할 수 있는 것이 늘었는가?
</Callout>

<Callout kind="concept" title="오늘 기억할 내용">데이터는 현실 전체가 아니라 특정 목적과 방법으로 기록한 일부입니다. 분석의 시작은 계산이 아니라 **무엇을 어떻게 기록한 자료인지 확인하는 것**입니다.</Callout>
