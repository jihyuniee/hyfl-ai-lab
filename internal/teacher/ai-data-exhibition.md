# AI × DATA 첫 작품 전시 — DATA QUEEN

사용자 요청으로 9반2팀 DATA QUEEN의 Re:Cloth를 첫 사례로 전시한다. 제공된 활동지에서 공개용 내용을 별도로 정리했으며 원문 파일을 웹사이트에 복사하지 않는다. 원문에 포함된 비밀정보·학번을 공개 변경 파일에서 제외했으며 키 폐기·재발급을 사용자에게 안내했다. 원문 인증 문자열을 이 기록에도 남기지 않는다.

## 위치와 연결

- 작품집: /hyfl-ai-lab/exhibition/ai-data/
- 작품 상세: /hyfl-ai-lab/exhibition/ai-data/data-queen/
- 기존 첫 프로젝트 전시와 두 번째 작품집은 프로젝트 선택 링크로 연결한다.
- 교과서 8단원의 끝에 굵은 작품 보기 링크를 둔다. 목차 항목은 추가하지 않는다.
- 현재 한 팀만 전시하며 다른 반·팀·수상 결과를 가상으로 만들지 않는다.

## 근거 범위

- 팀명·반·번호·이름·역할·문제 정의·조사 데이터·설계 요청·10/15~10/28 진행 기록은 제공된 활동지를 요약했다.
- KOSIS 링크는 활동지에 적힌 원문을 그대로 연결했다. 지역·기간·단위·수치의 독립 검증이 끝난 자료로 표현하지 않았다.
- 의류수거함이 많다는 것과 폐의류가 적다는 것의 관계는 통계적으로 입증된 결론으로 제시하지 않는다.
- 폐의류 수치 증가, 업체 수거 요금·조건, 재활용 증대 같은 독립 검증되지 않은 수치·효과는 전시의 성과로 옮기지 않았다.
- 활동지 STEP 3-2의 원자료 비교·사용자 테스트, 정식 AI 활용 기록은 비어 있다. 원문 설계 요청과 학생 선택은 소개하되 검증 완료로 꾸미지 않는다.

## 현재 웹앱 확인 2026-11-03

https://dataqueen.vercel.app/ 접속 및 Re:Cloth 제목, 배출 가이드·지도·퀴즈·질문 화면 확인.

배출 가이드에서 ‘솜이불’ 입력 → ‘수거 불가 솜이불’과 관할 구청 처리 안내 메시지 표시를 확인했다. 이는 화면 동작 확인이며 지자체 원자료와의 정확성 대조는 아니다.

지도는 카카오맵 연동 예정이라는 안내와 샘플 수거함 목록을 보여준다. 실시간 지도나 실제 수거함 데이터가 연결되었다고 쓰지 않는다. 퀴즈는3문제 안내와 시작 화면을 확인했다. 생성형 AI 답변·추천 API는 검증하지 않았다. 작품은 ‘제작 중’으로 표시한다.

공개용 소개는 학생의 질문과 의사결정이 중심이 되며 수상·점수·사용자 효과를 임의로 부여하지 않는다. 활동지 내용과 현재 구현은 구분한다. 댓글·심사·등록 폼은 이번 요청 범위에 포함하지 않는다.

### 수업 전에 준비

1. 구글클래스룸에 **AI × DATA 전시관 제출** 과제를 만든다. 팀당 한 명이 제출하도록 안내한다. 학생 전체가 볼 수 있는 스트림이나 공유 폴더 대신 과제 제출 기능을 사용한다. 이 PR은 클래스룸 과제를 자동 생성하지 않는다.
2. 학생에게 `/hyfl-ai-lab/exhibition/ai-data/submit/` 주소를 안내한다.
3. 공개되는 항목은 반·팀 번호, 팀명, 웹앱 이름, 실행 주소, 해결하려는 문제, 우리 팀이 결정한 것, 실제 구현한 기능, 직접 확인한 방법과 결과뿐이다. 활동지 전체는 제출하지 않는다.

### 학생 안내

팀이 함께 짧게 작성하고 **제출 파일 받기**를 누릅니다. 받은 JSON을 클래스룸의 전시관 제출 과제에 첨부하고 **제출**합니다. 파일을 내려받는 것만으로는 제출되지 않습니다. 교사 확인 후 공개됩니다. 확인하지 못한 것은 그대로 적습니다. 이름·학번·연락처·키를 적지 않습니다. 입력 내용은 서버나 브라우저 저장소에 저장하지 않으므로 새로고침 전에 파일을 받습니다.

### 교사 검수와 게시

1. 과제로 받은 파일은 **저장소 밖**에 내려받는다. 공개 이슈, PR 첨부, `public/` 또는 저장소 안에 원본 파일을 올리지 않는다.
2. `/hyfl-ai-lab/exhibition/ai-data/review/`에서 파일을 연다. 이 도구는 누구나 열 수 있지만 제출 목록이나 게시 권한은 없으며 파일을 서버에 전송하지 않는다. 교사가 직접 작성해 대리 등록할 수도 있다.
3. 학생이 작성한 문장만 확인·축약한다. 이름, 학번, 개인정보, 활동지 원문, API 키가 없는지 직접 검수한다. 자동 탐지는 보조일 뿐 모든 이름·키를 찾지 못한다. 문장에 개인정보가 있다면 지우거나 학생에게 수정 요청한다. 연결 웹앱의 공개 화면도 확인한다. 주소는 공개 HTTPS로, 인증정보·쿼리·프래그먼트 없이 받는다. 새 창 링크만 제공하며 학생 웹앱을 자동 실행하거나 서버에서 가져오지 않는다.
4. 공개 확인 체크 후 **검수 완료 파일 받기**를 누른다. `reviewed` 표시는 작업 확인용이며 인증 수단이 아니다. 학생이 이를 임의로 만들어도 저장소 쓰기 권한 없이는 게시할 수 없다.
5. 교사 작업 브랜치에서 `npm run exhibition:publish -- /저장소밖/ai-data-8-1-reviewed.json`을 실행한다. 미승인·잘못된 형식은 거절된다. 중복은 거절되며 기존 일반 제출 수정은 `--replace`를 명시한다. DATA QUEEN 기존 편집 기록은 이 도구로 덮어쓰지 않는다. 갱신 시 교사가 별도 PR에서 기존 상세 페이지와 데이터를 함께 검수한다.
6. `git diff -- src/data/ai-data-projects.json`으로 **공개될 모든 문장과 주소**를 확인한다. `npm run test:exhibition`과 `npm run build`를 통과한 뒤 PR을 만든다. PR에는 공개 승인한 데이터만 포함한다. main 병합 후 기존 Pages 배포로 공개된다. 제출 원본·검수 파일은 커밋하지 않는다.

### 범위와 보안 경계

비공개 보관과 제출자 확인은 기존 클래스룸 과제, 게시 권한은 GitHub 저장소가 담당한다. 새 백엔드·DB·로그인·API 키는 필요 없다. 웹 화면만으로 즉시 공개하는 기능은 없다. 공개 데이터에는 검수된 문장만 저장하며 AI 자동 요약·보완·검증 결과 생성은 하지 않는다. 원본 다운로드 파일에는 작성한 공개 항목만 있고 활동지·이름 필드가 없다. 기존 DATA QUEEN 기록과 School Image Lab은 그대로 보존한다. 기존 DATA QUEEN의 승인된 이름 기록은 이번 신규 제출 스키마에 포함시키지 않는다.
