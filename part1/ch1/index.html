1. 인공지능이란 무엇일까?

오늘의 질문

섹션 제목: “오늘의 질문”

💭 오늘의 질문

얼굴 인식, 추천, 번역, 내비게이션, 생성형 AI는 서로 다른데 왜 모두 인공지능이라고 부를까요?

사람은 어떻게 지능을 사용할까?

섹션 제목: “사람은 어떻게 지능을 사용할까?”

사람은 주변의 정보를 알아보고, 경험에서 배우며, 상황을 추론하고 판단하여 문제를 해결합니다.

📚 인공지능(AI)

인공지능은 인식, 학습, 추론, 예측, 판단, 생성, 문제 해결처럼 인간의 지능과 관련된 기능을 컴퓨터 시스템이 수행하도록 구현하는 기술과 연구 분야입니다.

이 말이 AI가 인간과 똑같이 생각하거나 이해한다는 뜻은 아닙니다. 실제 AI 시스템은 사람이 설계한 규칙, 데이터에서 학습한 패턴, 통계와 확률, 계산과 여러 도구를 이용하여 결과를 만듭니다.

생활 속 사례AI가 수행하는 기능
얼굴·사물 인식이미지의 특징을 찾아 인식·분류
콘텐츠 추천이용 정보와 패턴으로 선호 가능성 예측
내비게이션위치·교통 정보로 경로와 도착 시간 예측
번역입력된 언어의 내용을 다른 언어로 변환
생성형 AI학습된 패턴으로 글·이미지·코드 등 생성

작동 방식은 서로 다르지만, 모두 인간이 지능을 사용해 하던 활동의 일부를 컴퓨터가 수행한다는 공통점이 있습니다.

자동으로 작동하면 모두 AI일까?

섹션 제목: “자동으로 작동하면 모두 AI일까?”

오전 7시에 울리도록 설정한 알람은 사람이 정한 조건을 그대로 실행합니다. 자동으로 작동하지만 일반적으로 AI라고 부르지는 않습니다.

AI를 구현하는 방법에는 사람이 지식과 판단 규칙을 직접 설계하는 규칙 기반 방식과, 데이터를 이용해 패턴을 학습하게 하는 학습 기반 방식이 있습니다. 최근의 이미지 인식, 추천, 번역, 생성형 AI에는 머신러닝과 딥러닝이 널리 활용됩니다.

⚠️ 한 가지 기준으로 단정하지 않기

모든 AI가 반드시 데이터를 학습하는 것은 아닙니다. 중요한 것은 단순히 자동으로 실행되는지를 보는 것이 아니라, 어떤 정보와 방법으로 어떤 지능적 기능을 수행하는지 살펴보는 것입니다.

AI·머신러닝·딥러닝의 큰 지도

섹션 제목: “AI·머신러닝·딥러닝의 큰 지도”
  • 인공지능은 가장 넓은 기술 분야입니다.
  • 머신러닝은 사람이 모든 판단 규칙을 직접 작성하는 대신 데이터에서 패턴을 학습하게 하는 방법입니다.
  • 딥러닝은 여러 층의 인공신경망을 이용하는 머신러닝의 한 방법입니다.

지금은 용어를 모두 외울 필요가 없습니다. 오늘 기억할 흐름은 이것이면 충분합니다.

AI의 결과에서 사람은 무엇을 할까?

섹션 제목: “AI의 결과에서 사람은 무엇을 할까?”

AI는 데이터를 빠르게 처리하고 패턴을 찾아 결과를 제시할 수 있습니다. 그러나 그 결과가 현재 상황에서 무엇을 의미하는지, 실제로 사용해도 되는지는 자동으로 결정되지 않습니다.

  • 어떤 데이터로 학습했는가?
  • 처음 보는 상황에서도 잘 작동하는가?
  • 의도한 대상이 아니라 배경이나 엉뚱한 특징을 본 것은 아닌가?
  • 잘못 판단했을 때 누구에게 어떤 문제가 생기는가?
  • 이 결과를 실제 상황에 사용해도 되는가?

📚 이번 학기의 중요한 관점

AI는 패턴을 찾고 결과를 제시할 수 있습니다. 사람은 목적과 질문을 세우고, 결과를 맥락 속에서 해석·검증하며, 최종 사용 여부를 판단합니다.

설명은 여기까지, 직접 확인하기

섹션 제목: “설명은 여기까지, 직접 확인하기”

컴퓨터가 데이터에서 패턴을 학습한다는 말은 설명만으로 이해하기 어렵습니다. 이제 직접 두 가지 이미지를 구분하는 작은 모델을 만들고, 익숙한 조건과 처음 보는 조건에서 결과를 비교합니다.

✏️ 실험에서 찾을 것

모델을 멋지게 만드는 것보다 언제 틀리는지, 왜 틀렸는지, 데이터를 어떻게 바꾸면 결과가 달라지는지 찾는 것이 중요합니다.
