7. API 키로 바이브코딩하기

VIBE CODING · OPEN API
오늘의 질문API 키로 받은 데이터를 웹앱으로 어떻게 바꿀까?

지난 시간에는 NEIS 급식 API 요청 주소를 만들고 JSON 응답에서 필요한 값을 찾았습니다. 이번 시간에는 그 값을 사용해 작은 HTML 웹앱을 만들고, 실행하면서 생성형 AI와 함께 수정합니다.

🎯 오늘의 미션

NEIS 급식 API 키를 사용해 각자 원하는 기능의 작은 HTML 앱을 만듭니다. 앱을 실행해 본 뒤 결과를 확인하고, 생성형 AI에게 한 번에 하나씩 수정 요청하며 개선합니다.

1. 오늘 만들 수 있는 작은 앱

섹션 제목: “1. 오늘 만들 수 있는 작은 앱”

급식 API에서 받는 값은 같아도 앱의 기능은 다르게 만들 수 있습니다. 오늘은 작게 시작하고, 실행 결과를 보며 필요한 부분만 고칩니다.

만들 기능사용자가 입력할 값화면에 보여 줄 결과
메뉴 이름 검색메뉴 이름해당 메뉴가 나온 날짜, 식사명, 메뉴
칼로리 기준으로 찾기칼로리 기준값기준보다 높은 날짜, 칼로리, 메뉴
알레르기 번호 찾기알레르기 번호해당 번호가 들어간 메뉴와 날짜
날짜별 영양정보 보기날짜 또는 기간날짜, 식사명, 영양정보

예를 들어 “급식에 카레가 언제 나왔는지 찾고 싶다”, “칼로리가 높은 날을 보고 싶다”, “땅콩 알레르기 번호가 들어간 메뉴를 확인하고 싶다”처럼 시작할 수 있습니다.

2. API 키가 코드에서 쓰이는 위치

섹션 제목: “2. API 키가 코드에서 쓰이는 위치”

HTML 앱은 JavaScript 코드 안에서 API 주소를 만들고 데이터를 요청합니다. 지난 시간에 확인한 값이 코드의 재료가 됩니다.

사용자가 화면에서 날짜나 검색어를 입력하면, 앱은 그 값을 API 요청 주소에 넣습니다. 서버가 JSON 응답을 보내면 앱은 row 안에서 MLSV_YMD, DDISH_NM, CAL_INFO 같은 값을 찾아 화면에 표시합니다.

⚠️ 수업용 API 키 사용 범위

수업용 API 키는 교사가 안내한 범위에서 사용합니다. 오늘 제출 파일은 교실 안에서 확인하고, 공개 GitHub Pages나 공개 저장소에 올릴 때는 실제 키를 가리거나 다른 방식을 사용합니다.

확인할 기능테스트 방법

섹션 제목: “5. 바이브코딩 수정 요청하기”

바이브코딩은 작게 만들고, 실행하고, 고쳐 가는 반복입니다. AI에게 요청할 때는 현재 상태, 바꾸고 싶은 점, 유지할 기능, 테스트 방법을 함께 적습니다.

요청에 넣을 내용예시

바꾸고 싶은 점결과를 날짜별 카드로 정리
유지할 기능API 요청, 메뉴 줄바꿈, 출처 표시
테스트 방법같은 기간에서 같은 검색어로 다시 확인

7. 작업 방식 선택하기

섹션 제목: “7. 작업 방식 선택하기”

오늘은 누구나 할 수 있는 방식으로 시작합니다. 도구가 준비된 팀은 연결형 방식으로 확장할 수 있습니다.

방식오늘 할 일어울리는 상황
기본 방식AI가 준 코드를 복사해 index.html에 붙여 넣고 브라우저로 실행짧은 시간에 첫 앱을 확인할 때
수정 반복 방식실행 결과를 보고 AI에게 한 부분씩 수정 요청기능을 조금씩 바꿔 보고 싶을 때
연결형 방식GitHub, Codespaces, Claude Code, Codex 같은 도구로 파일을 직접 수정팀 프로젝트에서 여러 번 고칠 때

연결형 방식은 계정, 권한, 저장소 설정이 필요할 수 있습니다. 오늘은 index.html 파일을 완성하고 실행 결과를 확인하는 것을 목표로 합니다.

9. 팀 프로젝트로 이어가기

섹션 제목: “9. 팀 프로젝트로 이어가기”

오늘의 급식 앱은 팀 프로젝트의 작은 연습입니다. 최종 프로젝트에서는 문제를 정하고, 데이터 길을 선택하고, 사용자가 실제로 쓸 수 있는 웹앱으로 발전시킵니다.

출발점데이터 활용 방식앱형 프로젝트 예시
평소 불편함이 있다KOSIS나 공공데이터로 실제 현황 확인청소년 여가, 진로, 사교육, 지역 격차 데이터를 바탕으로 정보 안내 앱 만들기
KOSIS 탐색 중 문제를 발견했다국가통계로 문제의 규모와 변화 확인지역별 문화시설 차이를 보고 우리 지역 활동 추천 앱 만들기
조건별로 조회되는 생활 데이터가 필요하다Open API로 날짜, 지역, 학교 같은 조건별 데이터 요청급식 조회, 메뉴 검색, 알레르기 확인, 날씨 기반 추천 앱 만들기
공식 데이터에 없는 학교 안 문제가 있다직접 설문조사로 우리 학교 데이터를 수집학습 습관, 급식 만족도, 진로 관심, 학교생활 불편을 반영한 맞춤 안내 앱 만들기
