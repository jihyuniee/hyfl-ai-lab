# 교과서 점검 기록 · 2026-10-28

## 수업 흐름 기준

사용자가 확인한 진행은 2주차 데이터, 3주차 바이브코딩, 4주차 앱 테스트이다. 12차시·기존 STEP·활동지·제출 기준은 유지한다. 2주차에도 자료의 단위·출처·계산·해석은 확인한다. 앱 동작을 다양한 조건에서 시험하는 것은 4주차 초점이며, 구현 중 실행 확인을 미루라는 뜻이 아니다. 파일과 API는 동등한 자료 확보 경로이다. NEIS 실습을 이미 경험했으므로 6·7장은 프로젝트에서 필요한 부분을 다시 참고한다.

## 이번에 수정한 내용

- 홈/8장: 주차별 초점을 기존 STEP에 연결하고 2주차 전체 앱 구현 요구로 읽힐 표현을 완화.
- 6장: 실제 요청용 날짜 예시의 과거 연도를 제거. 설명용 과거 JSON은 편집 예시 표시를 유지.
- 5장: Claude 커넥터 추가 경로와 대화 활성화 안내, 무조건 ‘항상 허용’ 대신 도구를 확인한 선택 승인. 문제해결표도 함께 수정.
- 5장: 다음 공통 실습이 영화·날씨·스포츠 전부인 것처럼 보이던 문구를 실제 NEIS 예시와 팀별 탐색으로 구분.
- 2·3장: 클래스 예측 확률을 실제 정답률·이미지 유사도와 구분.
- 3장: 기존 GitHub 배포 링크의 옛 앵커를 유지하는 호환 앵커 추가.
- 9~11장: 현재 목차와 제목 번호 정합화. 잠긴 선택 표현/이전 기획 원고는 현재 8장 제출 기준을 대체하지 않도록 명시. 공개 잠금은 변경하지 않음.
