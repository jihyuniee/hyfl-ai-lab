## AI, 머신러닝, 딥러닝의 관계

    인공지능
     └─ 머신러닝
         └─ 딥러닝

- 인공지능은 컴퓨터가 지능적 활동을 수행하도록 만드는 기술 전체를 가리킵니다.
- 머신러닝은 인공지능을 구현하는 방법 가운데 하나로, 컴퓨터가 데이터에서 판단에 필요한 패턴을 찾게 하는 방식입니다.
- 딥러닝은 머신러닝의 한 방법으로, 여러 층의 인공신경망을 이용하여 복잡한 패턴을 학습합니다.

이미지 인식, 음성 인식, 자연어 처리와 생성형 AI에는 딥러닝이 널리 사용됩니다. 그러나 모든 AI가 머신러닝인 것은 아니며, 모든 머신러닝이 딥러닝인 것도 아닙니다.

## 규칙과 학습은 어떻게 다른가

규칙 기반 스팸 필터는 “제목에 ‘무료’가 포함되면 스팸으로 분류한다”처럼 사람이 판단 기준을 직접 작성합니다. 머신러닝 스팸 필터는 스팸과 정상 메일의 여러 사례에서 단어, 문장 구조, 발신 정보 등에 나타나는 패턴을 찾습니다.

| 비교 항목 | 규칙 기반 프로그램 | 머신러닝 |
| --- | --- | --- |
| 판단 기준 | 사람이 규칙을 직접 작성 | 데이터에서 패턴을 학습 |
| 새로운 상황 | 정해진 규칙의 범위에서 처리 | 학습한 패턴을 바탕으로 예측 |
| 개선 방법 | 규칙을 추가하거나 수정 | 데이터, 학습 방법, 모델을 개선 |
| 주의할 점 | 예상하지 못한 경우를 놓칠 수 있음 | 데이터의 오류와 편향을 따라갈 수 있음 |

두 방식 중 하나가 언제나 더 좋은 것은 아닙니다. 해결하려는 문제, 사용할 수 있는 데이터, 오류가 미치는 영향, 설명 가능성 등을 고려해 적절한 방식을 선택해야 합니다.

## 머신러닝은 어떻게 결과를 만드는가

<FlowDiagram items={[{ ko: '문제 정의', en: '무엇을 예측할 것인가' }, { ko: '데이터 준비', en: '필요한 사례를 모으고 정리' }, { ko: '학습', en: '데이터에서 패턴 탐색' }, { ko: '모델', en: '학습된 판단 구조' }, { ko: '예측·생성', en: '새로운 입력에 결과 제시' }, { ko: '평가·개선', en: '오류를 확인하고 수정' }]} />

모델은 데이터에서 학습한 패턴을 이용하여 새로운 입력에 대한 결과를 만드는 프로그램입니다. 학습에 사용하지 않은 데이터로 성능을 평가해야 실제 상황에서도 잘 작동하는지 확인할 수 있습니다.

성능이 낮다고 해서 데이터의 양만 늘리면 해결되는 것은 아닙니다. 자료가 정확한지, 다양한 상황과 집단을 포함하는지, 해결하려는 문제와 관련이 있는지를 함께 살펴야 합니다.

## 생활 속 사례에 적용하기

<Callout kind="lab" title="조사한 AI의 작동 원리 설명하기">

1. 문제: 이 AI는 무엇을 분류·예측·추천·생성하려는가?
2. 데이터: 어떤 사례와 정보가 학습에 필요할까?
3. 패턴: 데이터에서 어떤 관계를 찾아야 할까?
4. 결과: 새로운 입력에 어떤 결과를 만드는가?
5. 평가: 좋은 결과인지 어떤 기준으로 확인할 수 있는가?
6. 위험: 데이터가 부족하거나 치우치면 누구에게 어떤 문제가 생길 수 있는가?

서비스가 실제로 사용하는 학습 데이터가 공개되지 않았다면, 필요한 데이터를 근거를 들어 제안하되 실제 사용 사실과 구분하여 표현합니다.
</Callout>

### 적용 예시: 외국어 표현 추천 AI

- 문제: 상황에 자연스러운 외국어 표현을 추천한다.
- 데이터: 다양한 상황의 대화, 화자의 관계, 지역과 문화적 맥락이 포함된 언어 자료가 필요하다.
- 패턴: 같은 의미라도 상황과 관계에 따라 달라지는 어휘와 말투의 관계를 찾는다.
- 결과: 사용자의 문장과 상황에 맞는 표현을 제시한다.
- 평가: 문법뿐 아니라 의미, 자연스러움, 문화적 적절성을 확인한다.
- 위험: 특정 지역이나 집단의 표현이 부족하면 부자연스럽거나 편향된 결과가 나올 수 있다.

## 핵심 정리

<Callout kind="concept" title="오늘 기억할 세 문장">
1. 머신러닝은 인공지능을 구현하는 방법이며, 딥러닝은 머신러닝의 한 방법이다.
2. 머신러닝은 사람이 모든 규칙을 직접 작성하는 대신 데이터에서 판단에 필요한 패턴을 학습한다.
3. 머신러닝의 결과는 문제 정의와 데이터의 질, 평가 기준에 따라 달라지므로 반복적인 검토와 개선이 필요하다.
</Callout>
