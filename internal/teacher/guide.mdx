## 수업 철학

이 교재는 설명식 교과서가 아니라 **AI Lab Book**입니다.

```
개념을 이해한다 → 바로 해본다 → 실패한다 → 왜 그런지 생각한다 → 필요한 이론을 다시 배운다 → 개선한다
```

이론을 몇 주 동안 먼저 배우고 나중에 실습하는 구조를 의도적으로 피했습니다. 학생이 먼저 예측하고 실험한 뒤, 그 경험에 정확한 AI 개념을 붙이는 순서로 설계되어 있습니다. (예: Teachable Machine에서 자기 사진으로는 성공하지만 친구 사진에서는 실패하는 경험 → "왜 틀렸을까?" → 훈련/테스트 데이터, 일반화, 과적합, 데이터 편향)

## 프로젝트 평가 관점

| 평가 요소 | 무엇을 보는가 |
| --- | --- |
| 문제 정의 | 문제와 대상 사용자가 구체적인가 |
| 데이터·근거 | 데이터(또는 근거)를 충분히, 다양하게 확보했는가 |
| 실험과 검증 | 공정하게 테스트하고, AI의 결과를 검증했는가 |
| 문제 해결 | 실패 원인을 분석하고 실제로 개선했는가 |
| AI 협업 | AI에게 던진 질문과 검토 과정이 드러나는가 |
| 성찰과 책임 | 한계를 정직하게 설명하고, AI와 인간의 역할을 구분했는가 |

## 교사의 핵심 발문

Lab 활동 중 학생이 막히거나 결과만 보고 넘어가려 할 때 아래 질문을 던지세요.

- AI는 무엇을 입력받고 무엇을 출력했나요?
- 어떤 데이터를 학습했을까요?
- 성공보다 실패에서 무엇을 발견했나요?
- 바꾼 조건은 하나인가요?
- 공정하게 비교했나요?
- AI의 설명을 무엇으로 확인했나요?
- AI가 한 일과 여러분이 판단한 일은 무엇인가요?

참고: [교육과정·개념 연결표](/hyfl-ai-lab/teacher/curriculum-map/)에서 참고 교과서의 어떤 개념이 어느 챕터에 반영되었는지 확인할 수 있습니다.
