시작한 이유데이터에서 발견한 것직접 써 보세요만들어 가는 이야기
01 / 시작한 이유

왜 이 문제에 관심을 갖게 되었나요?

저희는 휠체어·유모차 이용자나 보행이 불편한 어르신에게 계단의 유무, 엘리베이터 위치, 경사로 정보가 이동 경로를 결정하는 데 중요하다는 점에 주목했습니다. 평소 당연하게 이용하던 길도 누군가에게는 이동하기 어려운 경로가 될 수 있다고 생각했습니다. 이동 약자의 입장에서 더 편리하고 안전한 길을 안내하는 서비스를 만들고 싶어 프로젝트를 시작했습니다.

02 / 데이터에서 발견한 것

어떤 공공데이터를 활용했고, 무엇을 확인했나요?

공공데이터포털의 대중교통 공공데이터와 국가교통정보센터의 교통 관련 정보를 조사했습니다. 역사별 엘리베이터 현황과 국토교통부 TAGO의 지하철정보 서비스 등을 살펴보고, 지하철역 검색과 교통정보 연동을 시도했습니다. 이를 통해 사용자가 입력한 정보에 따라 교통정보를 제공하는 서비스로 발전시킬 수 있다는 가능성을 확인했으며, 이동 편의시설 정보도 경로 안내에 활용할 수 있도록 고려했습니다.

03 / 직접 써 보세요

우리 웹앱으로 무엇을 할 수 있나요?

휠체어 이용자, 장애인, 유모차 이용자 등 이동에 불편을 겪는 사람들을 위한 교통 경로 안내 웹앱입니다. 출발지와 목적지를 입력하고 이동 조건을 선택해 자신에게 맞는 경로를 확인할 수 있도록 기획했습니다. 이동 약자의 접근성과 편의성을 중요하게 생각했으며, 앞으로 엘리베이터와 경사로 등 편의시설 정보를 연계해 더 적합한 경로를 안내하는 것을 목표로 합니다.

04 / 만들어 가는 이야기

만드는 과정에서 가장 기억에 남는 일은 무엇인가요?

가장 기억에 남는 일은 API를 연동한 뒤에도 웹앱에서 검색 결과가 제대로 표시되지 않는 문제를 해결하려고 노력했던 과정입니다. 처음에는 AI가 제공한 코드를 적용하면 기능이 작동할 것이라고 생각했지만, 실제로는 예상과 다른 결과가 나타났습니다. 코드를 여러 차례 수정하고 API 연결 상태와 데이터가 전달되는 과정을 확인하며 문제를 해결하고자 했습니다. HTML 파일을 GitHub에 올리고 Vercel로 배포하는 과정까지 직접 진행하면서, 아이디어를 실제 서비스로 구현하려면 반복적인 점검과 수정이 필요하다는 점을 배웠습니다.

전시 운영 참고 · 구현 상태 확인

2026년 11월 17일 점검에서 첫 화면, 출발지·목적지 입력과 이동 조건 선택 화면을 확인했습니다. 앱에는 ‘실제 교통 API 미연결’로 표시되며, 경로 검색 시 서버 주소와 API 인증 설정이 필요하다는 안내가 나옵니다. 실제 경로 계산과 엘리베이터·경사로 등 접근성 정보의 연동은 아직 확인되지 않았습니다.
