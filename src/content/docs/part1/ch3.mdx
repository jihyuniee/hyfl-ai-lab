<Callout kind="question">

## 큰 지도부터 보기

    인공지능 AI
     ├─ 사람이 규칙을 설계하는 방식
     └─ 머신러닝
         └─ 딥러닝

- **인공지능**은 가장 큰 개념입니다.
- **머신러닝**은 AI를 만드는 여러 방법 중 하나로, 데이터에서 패턴을 학습하게 합니다.
- **딥러닝**은 머신러닝의 한 방법으로, 여러 층의 인공신경망을 이용해 복잡한 패턴을 학습합니다.

<Callout kind="concept" title="포함 관계">
AI ⊃ Machine Learning ⊃ Deep Learning

모든 AI가 머신러닝인 것은 아니고, 모든 머신러닝이 딥러닝인 것도 아닙니다.
</Callout>

## 왜 머신러닝이 필요해졌을까?

사람이 직접 규칙을 만들기 쉬운 문제도 있습니다.

예를 들어 학교 출입 시스템에서 “등록된 카드 번호이면 문을 연다”는 규칙은 사람이 명확히 정할 수 있습니다.

하지만 고양이 사진과 강아지 사진을 구별하는 문제는 어떨까요?

- 귀가 뾰족하면 고양이?
- 수염이 있으면 고양이?
- 털 색이 이러면 강아지?

현실의 사진은 각도, 배경, 조명, 크기, 자세가 모두 달라서 사람이 모든 경우의 규칙을 만들기 어렵습니다.

그래서 접근을 바꿉니다.

> 규칙을 사람이 일일이 작성하는 대신, 많은 사례를 보여주고 컴퓨터가 구별에 필요한 패턴을 찾게 하자.

이것이 머신러닝의 핵심 아이디어입니다.

## 규칙 기반과 머신러닝 비교

| 비교 | 규칙 기반 | 머신러닝 |
| --- | --- | --- |
| 판단 기준 | 사람이 규칙을 작성 | 데이터에서 패턴을 학습 |
| 새로운 상황 | 미리 정한 규칙 안에서 처리 | 학습한 패턴을 이용해 예측 |
| 개선 방법 | 규칙 수정·추가 | 데이터·모델·학습 방법 개선 |
| 위험 | 예상하지 못한 경우를 놓침 | 데이터의 오류와 편향을 배움 |

어느 한쪽이 항상 더 좋은 것은 아닙니다. 문제의 성격과 데이터, 오류의 위험에 따라 적절한 방법을 선택해야 합니다.

여기서 중요한 단어가 **모델(model)**입니다. 모델은 데이터를 학습한 뒤 새로운 입력에 결과를 만들 수 있게 된 학습 결과물입니다.

## 딥러닝은 왜 중요할까?

이미지, 음성, 자연어처럼 복잡한 데이터에서는 사람이 중요한 특징을 모두 직접 정하기 어렵습니다. 딥러닝은 여러 층의 인공신경망을 이용해 이런 복잡한 데이터에서 필요한 특징과 패턴을 학습하는 데 강점을 보여왔습니다.

이미지 인식, 음성 인식, 번역, 생성형 AI와 대규모 언어 모델도 이런 딥러닝의 발전과 연결되어 있습니다.

<Callout kind="think" title="다음 단원을 위한 연결">
우리가 사용하는 ChatGPT 같은 생성형 AI도 갑자기 등장한 마법이 아닙니다.

**AI → 머신러닝 → 딥러닝 → 대규모 언어 모델**이라는 기술 발전의 흐름 위에 있습니다.

그렇다면 단순히 사진을 분류하던 AI가 어떻게 글을 쓰고, 코드를 만들고, 이미지까지 이해하는 AI로 발전했을까요? 뒤에서 다시 연결합니다.
</Callout>

## 데이터가 바뀌면 판단도 바뀐다

머신러닝은 데이터에서 패턴을 배우기 때문에 데이터가 곧 모델의 경험이 됩니다.

- 한 사람의 사진만 학습하면 다른 사람에게 약할 수 있습니다.
- 한 배경에서만 학습하면 배경을 대상의 특징으로 잘못 배울 수 있습니다.
- 특정 집단이 부족하면 그 집단에서 성능이 떨어질 수 있습니다.

그래서 좋은 AI를 만들려면 데이터의 **양**뿐 아니라 **다양성·정확성·대표성**을 함께 살펴야 합니다.

## 핵심 정리

<Callout kind="concept" title="오늘 기억할 세 문장">
1. AI는 가장 큰 개념이고, 머신러닝은 AI를 구현하는 방법 중 하나이며, 딥러닝은 머신러닝의 한 방법이다.
2. 머신러닝은 사람이 모든 규칙을 직접 작성하는 대신 데이터에서 판단에 필요한 패턴을 학습한다.
3. AI의 판단은 데이터와 학습의 영향을 받기 때문에 결과가 틀렸다면 데이터와 학습 과정을 함께 살펴야 한다.
</Callout>
