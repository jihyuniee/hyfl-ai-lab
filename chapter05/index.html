Part 2. 머신러닝과 데이터 리터러시 — 5차시

이 챕터의 교과 결합

섹션 제목: “이 챕터의 교과 결합”

이 챕터는 정보 교과의 “알고리즘·데이터 처리” 사고와 인공지능 교과의 “학습 방식 구분” 관점을 결합합니다. 정보 교과는 “데이터를 어떻게 처리하고 분류하는 절차를 만들까”를 묻고, 인공지능 교과는 “기계가 그 절차를 스스로 만들어내는가”를 묻습니다. 두 질문이 만나는 곳이 바로 머신러닝입니다.

🤔 생각 열기

섹션 제목: “🤔 생각 열기”

여러분이 스마트폰 사진첩을 열면, 앱이 알아서 “강아지” 사진끼리, “음식” 사진끼리 모아줍니다. 누가 사진 한 장 한 장에 “이건 강아지”라고 이름표를 붙여준 걸까요? 아니면 앱이 스스로 “비슷하게 생긴 것끼리” 묶은 걸까요?

또 이런 경험도 있습니다. 유튜브가 여러분이 좋아할 만한 영상을 귀신같이 추천합니다. 넷플릭스는 여러분이 다음에 볼 영화를 예측합니다. 이 서비스들의 공통점은 하나입니다. 누군가 규칙을 일일이 정해준 것이 아니라, 데이터를 보고 스스로 패턴을 찾아냈다는 점입니다.

오늘의 질문: 기계는 어떻게 “가르쳐 주지 않은 것”을 알아낼까요?

🎯 이 단원의 학습 목표

섹션 제목: “🎯 이 단원의 학습 목표”
  • 머신러닝의 정의와 ‘데이터 → 패턴 → 예측’의 학습 원리를 설명할 수 있다.
  • 지도학습과 비지도학습의 차이를 실제 사례로 구분할 수 있다.

📚 선수학습 확인

섹션 제목: “📚 선수학습 확인”
  • 알고리즘 [정보]: 문제를 해결하기 위한 정해진 절차. 지금까지 우리는 사람이 직접 규칙을 짜 넣는 프로그램을 배웠습니다.
  • 데이터와 속성 [정보]: 데이터는 여러 개의 속성(특징)으로 이루어집니다. 예를 들어 학생 데이터는 ‘키, 몸무게, 성적’ 같은 속성을 가집니다.
  • 인공지능의 정의 [인공지능]: 인간의 학습·추론·판단을 컴퓨터가 흉내 내는 기술. 머신러닝은 그중 “학습”에 집중한 방법입니다.

🔬 탐구 활동

섹션 제목: “🔬 탐구 활동”

탐구: 규칙을 짜는 사람 vs 패턴을 찾는 기계

섹션 제목: “탐구: 규칙을 짜는 사람 vs 패턴을 찾는 기계”
  • 준비물: 아래 과일 데이터 표, 필기도구, 모둠(3-4명)

우리는 두 가지 방식으로 “이 과일이 사과인지 오렌지인지” 맞히는 방법을 만들어 봅니다.

[표 1] 과일 데이터 (일부 이름표가 빠져 있습니다)

번호무게(g)색(빨강 정도, 0-10)이름표
11508사과
22002오렌지
31409사과
42103오렌지
51607?
61952?

과정

  1. [정보] 사람이 규칙 만들기: 1번부터 4번 데이터를 보고, “만약 ~라면 사과/오렌지”라는 규칙을 직접 문장으로 써 보세요. (예: “빨강 정도가 5보다 크면 사과”)
  2. 여러분이 만든 규칙으로 5번과 6번의 이름표를 채워 보세요.
  3. [인공지능] 데이터가 규칙 만들기: 이번엔 규칙을 미리 정하지 말고, 1-4번 데이터의 숫자 분포만 관찰하세요. 사과들과 오렌지들이 각각 어떤 값 근처에 모여 있나요?
  4. 두 무리의 “경계선”이 어디쯤 그어지는지 표시하고, 그 경계로 5번과 6번을 분류하세요.
  5. 1번 방식과 3번 방식의 결과가 같은지 비교하세요.

결과 예측: 두 방법 모두 5번은 사과, 6번은 오렌지로 분류할 가능성이 높습니다. 하지만 “규칙을 누가 만들었는가”가 완전히 다릅니다.

토의

  • 사람이 만든 규칙과 데이터가 스스로 드러낸 경계선 중, 데이터가 100개, 1000개로 늘어나면 어느 쪽이 더 유리할까요?
  • 만약 이름표가 하나도 없었다면, 여러분은 어떻게 두 무리로 나눌 수 있었을까요?

탐구에서 확인한 것처럼, 머신러닝은 사람이 규칙을 짜 넣는 대신 데이터 스스로 규칙(패턴)을 드러내게 하는 방식입니다. 그리고 이름표가 있느냐 없느냐에 따라 학습 방법이 갈립니다.

💡 핵심 개념

섹션 제목: “💡 핵심 개념”

개념 1. 머신러닝 — 데이터에서 패턴을 찾아 예측하기 [정보] [인공지능]

섹션 제목: “개념 1. 머신러닝 — 데이터에서 패턴을 찾아 예측하기 [정보] [인공지능]”
  • 정의: 머신러닝(기계학습)은 사람이 규칙을 직접 프로그래밍하지 않고, 데이터를 통해 컴퓨터가 스스로 패턴을 찾아 새로운 상황을 예측·판단하게 하는 방법입니다.
  • 비유: 머신러닝은 마치 많은 문제집을 푼 학생과 같습니다. 공식을 통째로 외운 게 아니라, 수많은 문제를 풀며 “이런 유형엔 이런 답”이라는 감(패턴)을 익혀, 처음 보는 문제도 풀어냅니다.

전통적인 프로그래밍과 머신러닝의 방향은 정반대입니다. 전통 방식은 “규칙 + 데이터 → 답”을 계산하지만, 머신러닝은 “데이터 + 답 → 규칙”을 찾아냅니다. 찾아낸 규칙을 모델이라고 부릅니다.

flowchart LR
  subgraph 전통 프로그래밍
    A1[규칙] --> C1[답 출력]
    B1[데이터] --> C1
  end
  subgraph 머신러닝
    A2[데이터] --> C2[패턴/모델 학습]
    B2[답/예시] --> C2
    C2 --> D2[새 데이터 예측]
  end

머신러닝의 핵심 흐름은 세 단계입니다. 데이터 → 패턴(학습) → 예측. 좋은 데이터가 많을수록, 찾아낸 패턴이 더 정확해집니다. 이것이 “데이터가 곧 힘”인 이유입니다.

개념 2. 지도학습 vs 비지도학습 — 이름표가 있느냐 없느냐 [인공지능]

섹션 제목: “개념 2. 지도학습 vs 비지도학습 — 이름표가 있느냐 없느냐 [인공지능]”

머신러닝을 나누는 가장 중요한 기준은 정답 이름표(라벨)의 유무입니다.

  • 지도학습(Supervised Learning): 데이터에 정답 이름표가 붙어 있는 경우입니다. 탐구의 1-4번 과일처럼 “이건 사과”, “이건 오렌지”라는 답을 함께 주고 학습시킵니다. 마치 답지가 있는 문제집으로 공부하는 것과 같습니다.

    • 대표 작업: 분류(사과/오렌지 구분), 회귀(집값 예측처럼 숫자 맞히기)

  • 비지도학습(Unsupervised Learning): 데이터에 이름표가 없는 경우입니다. 정답을 알려주지 않고 “비슷한 것끼리 알아서 묶어라”라고 시킵니다. 마치 답지 없이 비슷한 문제끼리 스스로 분류하는 것과 같습니다.

    • 대표 작업: 군집화(클러스터링) — 비슷한 데이터를 무리(군집)로 묶기
flowchart TD
  A[머신러닝] --> B{정답 이름표가<br/>있는가?}
  B -->|있다| C[지도학습]
  B -->|없다| D[비지도학습]
  C --> C1[분류: 사과/오렌지]
  C --> C2[회귀: 집값 예측]
  D --> D1[군집화: 비슷한 것끼리 묶기]

[표 2] 지도학습과 비지도학습 비교

구분지도학습비지도학습
이름표(라벨)있음없음
목표정답 예측숨은 구조/무리 발견
비유답지 있는 문제집답지 없는 분류 놀이
대표 예스팸 메일 분류, 시험 점수 예측고객 그룹 나누기, 사진 자동 묶기

생각 열기의 사진첩 예를 다시 봅시다. 사람이 사진마다 “강아지”라고 이름표를 붙여 학습시켰다면 지도학습이고, 앱이 스스로 “비슷하게 생긴 것끼리” 묶었다면 비지도학습입니다.

🌉 교과 간 연결 다리

섹션 제목: “🌉 교과 간 연결 다리”

정보의 ‘분류 알고리즘’이 인공지능의 ‘지도학습’을 만나다

섹션 제목: “정보의 ‘분류 알고리즘’이 인공지능의 ‘지도학습’을 만나다”

[정보] 교과에서 우리는 조건문(if-else)으로 데이터를 분류하는 알고리즘을 배웠습니다. “빨강 정도가 5보다 크면 사과”라는 규칙은 사람이 손으로 짠 분류 알고리즘입니다.

[인공지능] 교과의 지도학습은 이 경계선(5라는 기준값)을 데이터가 스스로 정하게 합니다. 사람은 데이터와 정답만 주고, 최적의 경계선은 기계가 찾습니다. 즉 정보 교과의 ‘규칙 설계’가 인공지능 교과에서는 ‘규칙 학습’으로 진화한 것입니다. 탐구 활동에서 여러분이 손으로 그은 경계선이, 실제 머신러닝에서는 자동으로 계산됩니다.

새뮤얼은 머신러닝을 “명시적으로 프로그래밍하지 않고도 컴퓨터가 학습할 수 있게 하는 연구 분야”라고 정의했습니다. 60여 년 전의 이 정의가, 오늘날 여러분의 사진첩과 추천 영상 뒤에서 그대로 작동하고 있습니다.
