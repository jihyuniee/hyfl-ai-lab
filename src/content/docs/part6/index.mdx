지금까지 모델과 데이터를 다루고 생성형 AI와 협업했습니다. 이제 기술을 잠시 내려놓고 **나 → 학교 → 지역사회 → 사회와 세계**로 시선을 넓힙니다.

## 문제를 보는 다섯 렌즈

| 렌즈 | 질문 |
| --- | --- |
| WHO | 누가 어려움을 겪고 있는가? |
| WHEN | 어떤 상황에서 문제가 나타나는가? |
| WHY | 원인과 맥락은 무엇인가? |
| NOW | 지금은 어떻게 해결하고 있는가? |
| GAP | 현재 방법으로도 남아 있는 어려움은 무엇인가? |

외국어·교육·진로·경제·환경·문화·접근성·정보 격차·학교생활처럼 자신의 관심에서 출발해도 좋습니다. 관찰, 인터뷰, 간단한 설문, 공공데이터, 신뢰할 수 있는 보고서로 내 추측이 실제 경험과 맞는지 확인합니다.

## 넓은 관심을 문제 상황으로 바꾸기

**넓은 관심**: 외국어 공부가 어렵다.<br />
**대상 추가**: 혼자 공부하는 외국어 초급 학습자가 자료를 고르기 어렵다.<br />
**상황과 영향 추가**: 자신의 수준을 판단하기 어려운 초급 학습자가 너무 쉽거나 어려운 자료를 반복해 선택하고 학습을 포기하기도 한다.

<Callout kind="caution" title="아직 AI를 넣지 마세요">문제 문장에 AI·챗봇·앱·웹사이트를 먼저 넣지 않습니다. 당사자의 실제 필요를 이해한 뒤 다음 단계에서 AI가 필요한지 판단합니다.</Callout>

## 문제를 선택하는 기준

- 실제 사람이 겪는 구체적인 상황인가?
- 해결되면 의미 있는 변화가 있는가?
- 당사자나 근거를 통해 문제를 더 알아볼 수 있는가?
- 한 학기 안에 핵심을 탐구할 수 있는 범위인가?
- 내가 관심을 가지고 끝까지 질문할 수 있는가?

<Callout kind="concept" title="DISCOVER의 결과">완성된 서비스 아이디어가 아니라 **누가, 어떤 상황에서, 왜 어려움을 겪으며, 기존 방법의 어떤 빈틈이 남아 있는지** 설명하는 문제 정의입니다.</Callout>
