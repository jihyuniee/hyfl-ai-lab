# AI × DATA 평가 및 공감상 운영

## 운영 원칙

- 프로젝트 전시는 교사가 활동지와 실행 결과를 확인해 일괄 등록한다. 학생 작성·로그인·수정 메뉴를 추가하지 않는다.
- 대상은 아래의 증거 기반 평가로 선정한다. 공감상은 학교 계정 투표로 별도 선정하며 득표를 대상 점수에 합산하지 않는다.
- 이 표는 프로젝트 전시·선정의 기준이다. 교과 성적에 적용하려면 기존 평가계획과 일치하는지 먼저 확인한다.
- API 연결 여부, 기능 수, 화려한 디자인 자체에는 가점을 주지 않는다. 분석해 문제·개발 근거로 쓴 팀과 앱에 직접 연결한 팀을 동등하게 평가한다.

## 평가표 (100점)

각 기준 25점, 아래 확인 항목별 5점으로 채점한다. 항목마다 증거가 없으면 0점, 일부 확인되었으나 오류·누락이 남으면 2점, 제시된 증거와 실행·설명이 일치하면 5점으로 기록한다. 점수 옆에 활동지 위치나 실행 사례를 남긴다. 주요 항목은 다른 교사와 함께 확인할 수 있다. 판정은 성취기준 및 기존 평가계획과 함께 검토한다.

| 기준 | 5점씩 확인할 다섯 항목 |
| --- | --- |
| 문제와 데이터의 연결 | 대상 사용자와 구체적 상황 / 데이터로 확인할 질문 / 질문에 맞는 자료 선택 / 데이터가 보여주는 사실과 해석 구분 / 근거가 앱의 기능 설계로 이어지는 설명 |
| 데이터 활용의 정확성 | 추적 가능한 원자료 출처 / 기간·지역·단위 등 필요한 조건 명시 / 필요한 전처리·계산 또는 자료 선택 과정 설명 / 원자료와 분석·표시 내용의 대조 / 확인한 사실과 추정·한계 구분 |
| 핵심 기능의 작동 | 설명한 사용 절차 재현 / 정상 사례에서 기대 결과 확인 / 다른 조건·입력의 결과 확인 / 빈 입력·결과 없음·실패 등 해당하는 예외 안내 / 배포 주소에서 다른 기기로 핵심 기능 사용 |
| 검증과 개선 | 시험 입력과 조건 기록 / 기대 결과의 근거 명시 / 실제 결과와 일치 여부 기록 / 발견한 오류 또는 한계와 개선 조치 / 개선 후 재시험 또는 미해결 항목과 다음 검증 계획 |

해당하지 않는 기술을 억지로 요구하지 않는다. 예를 들어 지역 선택이 없는 앱은 실제로 제공하는 다른 입력 조건을 시험한다. 분석 근거형 앱은 분석 결과를 원자료와 대조하고, 기능의 출력은 해당 서비스의 설명·설계 기준과 대조한다. 실제 사용자 효과와 화면 작동 확인은 구분한다. 점수가 같으면 검증과 개선 → 데이터 활용의 정확성 순으로 비교하며, 그래도 같으면 공동 선정한다. 공식 시상 여부 및 명칭은 학교 계획에 따른다.

## 학생에게 받는 최소 증거

기존 활동지 STEP 3·5를 사용하며 중복 보고서를 요구하지 않는다.

1. 핵심 기능 테스트: 입력·선택 조건 / 기대 결과와 근거 / 실제 결과 / 일치 여부. 정상·조건 변경·예외 등 성격이 다른 사례를 가능한 범위에서 포함한다.
2. 개선 사례: 발견한 문제 / 수정 전후 / 다시 확인한 결과. 고치지 못했다면 한계와 다음 확인 방법을 적는다.
3. 개인별 기여: 실제로 한 일 / 중요한 판단 / 직접 대조·시험한 내용. 팀 산출물을 모든 팀원의 동일한 성취로 간주하지 않는다.

수업의 개인별 판단·검증·개선 과정은 교사가 직접 확인해 누가 기록한다. 대회 참여·성적·수상 기록을 세특에 옮기지 않는다. 수업 활동과 별도 대회의 경계는 현행 기재요령과 학교 담당자에게 확인한다.

## 공감상 투표

- 모든 팀이 등록된 뒤 동일한 기간에 투표를 시작한다. 시작·마감 일시는 아직 정하지 않았다.
- 학교 Google Workspace 계정당 1팀에 1표. 마감 전 변경·취소 가능. 서버에서 검증된 계정 식별값으로 제한한다.
- 로그인은 투표할 때만 요구한다. 전시 열람은 공개한다. 투표는 하트 버튼으로 표시하며 득표수는 마감 후 공개한다.
- 로그인은 계정당 한 표를 보장하는 수단이다. 개인이 학교 계정을 여러 개 갖고 있는 경우까지 1인 1표로 판별하지는 않는다.
- 동점은 공동 공감상으로 선정한다. 0표만 있는 경우 공감상을 선정하지 않는다.
- 실명·이메일·개인별 투표 내역은 공개하지 않는다. 원래 계정 식별값 대신 서버 비밀키로 변환한 값과 선택 팀만 저장한다. 투표 기록은 마감 30일 후 자동 삭제한다.
- 공지 문구: “프로젝트 소개와 웹앱을 살펴보시고, 공공데이터를 의미 있게 활용해 사용자에게 도움이 된다고 생각하는 한 팀에 투표해 주세요. 최다 득표 팀은 공감상으로 선정합니다. 대상은 별도의 평가 기준으로 선정합니다.”

## 개발·연결 상태

학교 계정 확인·투표 저장 API와 전시 버튼을 구현했다. Google 로그인 클라이언트와 저장소를 실제 연결하기 전까지는 준비 중으로 표시한다. 설정 및 시험 방법은 `services/ai-data-voting/README.md`를 따른다. 실제 학교 계정 로그인·배포 저장소·중복 투표·마감 검증을 마친 뒤에만 연다.
